# Windows V1候选版需求审计

本表区分实现覆盖和发布验收，最终结果以[验证报告](verification-report.md)为准。候选范围由用户明确限定为Windows；不改变PRD的双平台正式V1标准。

| 需求 | 实现与本轮补齐 | 验证关注 |
|---|---|---|
| FR-001 | 快速连续录入、上下文日期/归属、应用内新建；补托盘与组件入口 | 失败保留、20项与重启 |
| FR-002 | CRUD、终态、软删撤销、自定义排序；补批量完成/项目/开始日/标签、紧凑密度 | 整批冲突与后续SQL失败零修改 |
| FR-003 | Today/今晚、独立排序、桌面同源、日期与完成计数、移出提示 | 跨日与日期优先级 |
| FR-004 | Upcoming日期分组、后续30天、独立截止、改期/拖到今天 | 不复制实体 |
| FR-005 | Anytime/Someday/Logbook；补归属分组、今日标记、一键激活、近7/30天 | 项目有效性与恢复 |
| FR-006 | 领域/项目/Heading、项目日期描述与终态、迁出软删、颜色；补组织排序、领域归档/恢复 | 事务与重启、schema1备份升级为2 |
| FR-007 | 共享草稿的宽窄详情、日期/只读时间/归属/提醒 | 显式保存沿用ADR-009；防抖为PRD允许选项 |
| FR-008 | 清单创建、勾选、重排、删、Enter；补清单内容搜索 | 主任务完成不自动勾选 |
| FR-009 | Unicode折叠唯一、多标签、上下文筛选 | ID/归属完整性 |
| FR-010 | 月42格、双标记、当天议程、创建、单字段改期；已完成开关、未排期入口、直接完成/恢复、宽窄/大字议程 | 冲突回滚、合并字段选择、同id同步与草稿保护 |
| FR-011 | 七日全天列、周首日、翻周、改期 | 无小时轴；隐藏条目可从当日完整列表访问 |
| FR-019（追加） | 本地全天/定时事件、UTC/IANA时区、准备/跟进多对多关联、独立改期/软删/8秒撤销、schema003及JSON兼容 | DST/跨日/排他结束、CAS/SQL回滚、旧库先快照、双方删除不级联、10k事件索引 |
| FR-012 | Floating/Mini/整窗穿透/恢复、背景alpha、几何锁定；补主窗/录入入口和摘要标题 | 真正多屏/焦点/穿透尚需人工 |
| FR-013 | 托盘恢复/退出/单实例/关闭策略；补首次托盘关闭提示 | 真实托盘操作待人工 |
| FR-014 | UTC一次认领、最多10条汇总、应用内记录；补系统提交开关 | OS送达不可观测，不冒充送达 |
| FR-015 | 每日/N日/周/月/年/完成后N日，幂等及手改保护 | 月末/闰日/重启 |
| FR-016 | 防抖全局标题/备注、历史与标签；补清单搜索 | 10k数据基准不等于UI帧率 |
| FR-017 | WAL一致快照、导入预览/事务/替换双确认、JSON/CSV；补备份周期 | 旧数据升级/无效文件零修改 |
| FR-018 | 主题/文字/周首日/窗口与组件、关闭；补Windows用户级开机启动、实色组件 | 自动测试不修改真实启动项 |

导航补齐折叠恢复、每视图位置、Ctrl/Cmd+1～5与设置快捷键；输入框/模态工具内禁用快捷导航。UI-06完整可访问性、真实用户动作评估、系统高对比、原生输入法与多屏未因源码实现自动通过。

发布外部门槛：macOS全套构建/签名/平台实测、两平台8h与睡眠多屏、独立干净系统、公开分发许可及Windows签名仍待验收。候选包供本地试用；不能称为这些门禁全部完成。
