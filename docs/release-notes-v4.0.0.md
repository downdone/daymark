# Daymark 4.0.0

Windows托管更新包由受保护流水线发布。此版本统一了主窗、小窗和日历的任务安排。

- 小窗左栏默认显示全部分类，可收起并搜索。使用右键或 Alt+↑ / ↓ 调整同级顺序，主窗和小窗共用排序。
- 「安排」集中设置开始、结束、时段、周期与提醒。下拉列表按内容展开，到达屏幕工作区边界后才滚动。
- 本地资料中的周期任务沿用同一个任务。完成后记录本轮，下轮开始时原任务恢复待办。可在详情查看完成历史，旧周期可手动转换。
- 在一个界面保存后，其他界面会自动刷新。正在编辑的草稿会保留，可按提示重新载入已保存版本。

任务库升级到 schema 12，升级前会备份。3.2.0 及更早版本请使用完整安装包手动升级。旧更新器会拒绝自动安装这个跨格式版本。账号资料继续使用现有 HTTP JSON v1 同步，新任务周期目前仅支持本地资料。

Windows 安装包及便携包采用项目固定指纹自签名和独立 P-256 更新签名。项目自签名未获得 Windows 公共发布者信任。macOS 和 Linux 提供源码。默认图形后端的小窗活动提取候选编辑，以及物理多屏、混合 DPI 和读屏未完成验证，详情见仓库的 `docs/PROGRESS.md`。
