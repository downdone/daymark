# Daymark 4.0.3

Windows托管更新包由受保护流水线发布。

- 将 Windows 的 Qt 运行时更新到 6.10.3，并用原 MSVC 构建环境验证桌面渲染。
- 账号任务可在「安排 → 周期」配置重复。各设备同步同一条任务的周期、下次日期和完成记录。无网络时仍可编辑，连接后再同步。
- 初次同步账号周期后，旧设备须升级才能继续同步。保留原有任务、完成记录和待传修改。本版客户端数据库仍为 schema 12，沿用现有 Windows 在线更新路径。
- Windows x64 发行沿用项目自签名和独立 P-256 更新签名。物理多屏、辅助技术、macOS 和 Linux 桌面版本未验证。版本及验收状态见 [PROGRESS](PROGRESS.md)。
