# ADR-018：任务父子限制两层

日期2026-10-25。用户指出子任务不应再包含子任务，明确收敛正常关系为根任务及直接子任务。本裁决追加FR-032，覆盖ADR-016/017中允许任意深度创建/调整的部分；完成、删除、分类移动仍联动后代。

创建与改父在TaskService校验：父项必须是未删除根任务，带下级任务不能作为另一个任务的子项；防环和版本保护保持，拒绝零修改。选择器仅展示合法根任务。子任务列表点击直达详情，子项不展示空的下级入口；返回父项列表保护草稿。

不迁移/扁平化旧用户关系，不更改历史migration。既有深层任务允许编辑原关系、访问真实下级、软删/恢复、JSON往返；只能通过显式脱离/重新归属减少层级，不能再新增深度。旧多层恢复及事务回归继续保留，使用真实Repository旧关系fixture。无schema变更或新依赖。
