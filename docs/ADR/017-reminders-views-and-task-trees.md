# ADR-017：提醒事项式视图与父子联动

日期：2026-10-25。用户在UI30实施中提供macOS提醒事项五张截图，明确要求按其逻辑组织面板，并再次明确“全面跟随：父子完成、删除和移动联动”。本裁决替代ADR-016及UI27～30中父子独立完成/删除/分类移动和智能视图自动补入子树的部分；其他时间、循环、分类两级、离线及安全约束保留。

官方依据：[Mac子任务](https://support.apple.com/zh-hans/guide/reminders/remn32a9622b/mac)明确普通列表展开，智能列表通过蓝色子任务数量进入；父项完成、删除和移动会联动子项。[Mac删除与恢复](https://support.apple.com/guide/reminders/delete-reminders-remna83c9566/mac)提供最近删除与恢复。截图用于面板层级和布局，未展示的细节不从图片推断。

采用今天、计划、全部、特别关注、已完成五个主要自动视图；收集箱是未分类任务的默认归属入口，分类/标签与智能视图分开。今天按时段，计划按日期/月份，全部按分类，已完成按完成日期组织。智能视图精确匹配；子任务数量链接可就近进入任务的子任务面板，普通列表保留树和折叠。旧随时可做/以后再说/即将到来代码仅兼容既有数据与命令，不常驻主导航。

父项完成处理全部未完成后代；分类移动处理全部未删除后代；删除软删整棵未删除子树。所有操作在单一Repository事务中，校验源版本和所有写入版本，失败全部回滚。恢复只恢复本次删除的同组成员，不能误恢复此前独立删除的子项；重新打开只处理本次联动完成的成员，保留先前已完成的子项。跨分类移动某个子任务将其从原父项中移出，同时带走其子树；日期与提醒不自动继承。

新增schema009保存删除组和完成组ID，避免拿UTC时间戳猜测一组操作。先WAL一致备份再迁移，旧迁移不改写；JSON9输出，JSON1～8升级补空组，严格校验和失败零修改。最近删除可恢复，无后台永久清理；永久清除需要另外的显式设计和确认，不因参考Apple而自动删除用户旧数据。完成/恢复/移动保留原有循环实例、提醒认领、历史及手工改动保护，不引入账户、云或外部服务。

验证先服务/事务/迁移/导入，后五视图和每种树入口/菜单/紧凑布局。原有与独立父子语义冲突的断言按本裁决替换，保留失败、版本、撤销、数据完整性和缩放门禁，不将旧版本PASS挪到新行为。
