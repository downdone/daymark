# ADR-034：离线时间识别只作为新建草稿适配

状态：接受（2026-11-06，用户授权设计评审后实施）。

## 决策

采用Qt6.10.2/C++纯规则解析与可注入时钟/时区，主窗/小窗共用。解析结果不落库、不发网络，UI预览不可成为可信事实；提交端重新解析或校验明确手工override，原子创建任务/提醒。原create/edit/导入/同步仍接字面标题，不扫描历史。用户手工选择高于建议，忽略本条最高优先；既有入口范围只提供默认时间、分类和标签保持。

日期、截止、提醒与时段分开：只有日期默认无提醒；具体时刻生成UTC提醒，不猜结束时长；不提醒时原文保留时刻，结构化事实只保存日。无年日期显示推导的完整年份；多时间/过去时刻/DST缺失或重复墙钟不猜。细节见[契约](../design/task-time-recognition.md)。

## 备选和取舍

云端模型增加隐私/离线/成本和不确定性；第三方自然语言库增加依赖/许可/语言覆盖差异，当前有限语法无需引入。仅QML正则无法统一时间语义和保存校验；解析全部create/edit会误改导入和历史，均不采用。无新RPC/服务端接口，无schema迁移：复用schema10原有日期/UTC提醒字段及同步v1；偏好为本地ui.ini。

## 后果

支持语法有明确边界，复杂循环/时间区间先提示手选。用户能保存原文并忽略建议；无需网络许可/登录。自动识别不是系统后台唤醒承诺。规则、事务、真实QML/IME/缩放分层验证；物理IME/读屏/多屏及其他OS保持未验证时如实记录。
