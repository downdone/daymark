# ADR-008：骨架与平台能力分别验收

日期：2026-10-22。状态：已接受，实施顺序细化，无 V1 需求削减。

用户当前要求先工程骨架、方法和详细计划。本轮只建立可编译 QML 双窗口、脚本和运行时探针，不提前实现数据库业务、托盘或真实穿透。应用明确显示“工程预览”，不展示虚构任务。

当前关闭主窗口直接退出，避免在未实现托盘时留下无法退出的驻留进程；这符合 PRD 无托盘时退出的安全方向，不是最终关闭策略。M0 的托盘切片与 M1 单实例落地后，才启用可配置的关闭到托盘行为。当前不启用鼠标穿透。

SQLite 测试只证明 QSQLITE Kit 和临时库事务可用，不等于 M1-04 MigrationManager 已完成。原计划 M0/M1 各项仍按原门禁验收。
