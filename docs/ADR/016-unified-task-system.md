# ADR-016：两级分类与统一任务系统

2026-10-25，已接受（用户明确变更产品定义）。依据[UI-27分析与设计](../design/unified-task-system.md)及FR-024～029。

项目/领域合并为可升降级的两级分类。普通任务、带时间日程和循环日程统一为可完成Task；时间/循环是可选属性，不再维护两份可写事件与任务。删除检查清单概念，旧项迁成真正子任务；详情/子任务使用不同tab及独立编辑面板。特别关注表达重要性，置顶表达显示顺序，均与分类、今天/今晚安排独立。

用户进一步明确Daymark结合iOS/macOS日历与提醒事项的体验。取消侧栏规划分组；日历作为查看方式，通过顶部列表/日历图标切换，循环任务仅作普通列表筛选。主窗与独立日历打开同一Task详情，后续循环实例具有独立Task ID。迁移后的旧表冻结为历史兼容，不进行双向同步。

新需求明确替代ADR-013/014关于独立事件实体、ADR-015“任务无小时安排”及原项目/领域/清单的用户概念边界；原日期/UTC、单一ID、离线、CAS/事务、备份、历史保护和平台验证纪律继续有效。不能仅合并入口或改名冒充对象统一。追加schema迁移并兼容历史导入；无外部服务、新依赖或真实用户库自动操作。
