# ADR-021：小时轴投影与改期命令

2026-10-25。用户已授权完整实现UX-34；落实FR-034、P-04/05、UX-06/07/11。

小时轴的坐标表示显示时区中当天起点后的真实分钟。一天由QDate.startOfDay及下一日边界确定，DST日可以23或25小时；刻度显示当地时刻与必要UTC偏移，绝不用86400秒构造下一日。跨午夜任务按各日真实边界裁剪，结束为排除边界。重叠按时间区间分组分配列，不以冲突拒绝合法并行安排。

命令区分整体move、start/end边缘及未安排任务排入时段。整体移动保持UTC真实时长；边缘只改该端点；显示时区坐标先转换UTC，保留任务原时区供详情输入。原UI-33日期字段改期仍按原任务时区墙钟，不与小时轴命令混用。所有命令经TaskService.edit统一校验、CAS、相对提醒与循环本次覆盖；不改变分类/父子关系。非法端点零修改，Esc不发命令。单次拖动默认只改本次，系列后续操作继续从任务循环选项显式执行。

界面15分钟吸附仅用于指针新位置；精确时间编辑不受限制。无时段任务新排入采用60分钟可调整默认值，预览起止；不是Apple规定数值。年导航不请求全年实例物化。无需schema或新依赖。
