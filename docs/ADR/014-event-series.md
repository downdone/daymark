# ADR-014：事件系列与提醒记录

状态：采用；2026-10-23用户授权，扩展ADR-013、FR-021。

事件保存系列锚点、NONE/DAILY/WEEKLY/MONTHLY/YEARLY、间隔、可选包含结束日期及提前提醒分钟。可见实例在C++ EventService按范围生成，不复制任务规则、不在QML裁决循环。不支持单次例外，编辑和删除明确作用整个系列。

定时按所属时区墙钟重复，全天按本机日历日；无效月日、闰日及DST不存在/歧义实例跳过。Qt无效本地QDateTime须在toUTC之前检查。跨日结束按原本地日差及时间投影。循环时长上限366天；日期查询有界，不从多年前锚点逐日生成历史。

schema4追加004，schema1–3开库前WAL一致快照；失败不迁移。事件提醒历史以event+UTC实例开始+提前量唯一，先事务记录再提交系统提醒，保障重复检查/重启去重，不能保证OS恰好一次展示。最近24小时到期实例在启动/恢复检查时补报，退出期间无服务。全天09:00为提醒基准，事件删除后不再检查，历史保留供撤销去重。

JSON schema4含完整规则/提醒历史，旧schema1–3导入补NONE/1/null/-1默认；替换和错误回滚沿用原事务/备份。旧程序无法打开schema4；回退须关闭程序并在独立目录使用升级前快照，不覆盖运行中的库。系统通知送达、macOS、辅助技术仍须平台实测。
