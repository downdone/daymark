# ADR-015：任务日期范围与明确导航移动

2026-10-24；已接受：用户截图明确要求任务跨天横条、导航拖放及安排生效。新增行为见PRD FR-023；不是数据库迁移。

原FR-010仅在开始/截止日投影任务，连续事件条由CAL-06A实现。现增加任务开始日至截止日的可视范围：本地日历日含两端，跨周分段且引用原task.id。它表示可行动至截止的范围，不表示全天占用、每日副本或小时排程；不改变Today/Upcoming成员、持续关注或提醒瞬间。起止标记在议程保持具体语义，CalendarService负责统一范围有效性，QML仅绘制。

侧栏任务目的地是显式移动意图，由TaskService统一构造Patch并先验证目标可达，随后CAS落库；目标被项目/领域状态阻止时不显示成功。有安排的任务移回收集箱需要明确清除日期/关注，否则既有自动ACTIVE规则会让移动无效；拖放即时提交先确认，详情仅修改可放弃草稿并说明。即将到来要求用户选择未来日，保留并校验原截止，不暗改。

不新增云、依赖、任务状态、schema或任务副本。保持导出/备份兼容、原本地日期和UTC提醒边界；失败零修改。完整交互和验收见[UI-23A](../design/direct-task-actions.md)。
