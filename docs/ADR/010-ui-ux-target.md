# ADR-010：Things与Apple原则指导的独立桌面UI目标

日期：2026-10-22。状态：已接受，依据用户要求建立项目UI/UX目标。

## 背景

BASIC-01已形成可用任务闭环，但以默认控件为主，导航、行操作、模态详情及字号状态尚无统一设计系统。用户要求调研Things 3并参考Apple原则，形成后续目标。

## 决策

采用 [UI/UX基准](../design/ui-baseline.md) 及 [验收](../design/ui-acceptance.md) 作为后续界面设计与评审入口；研究事实、来源年代与独立解释见 [调研](../design/ui-research.md)。以内容优先、渐进呈现、直接操作、恢复能力和平台熟悉感为目标，数值token由Daymark自行定义并验证。

复用当前C++服务/数据边界，按Today样板→导航→详情→复杂列表→日历/组件逐批迁移。原PRD业务语义和范围不变；设计目标不是现有UI已验收声明。

## 限制与替代方案

不采用Things逐像素复制、官方专有资源、第三方非官方Things设计包。Apple Liquid Glass不作为跨平台强制实现，先实现实色可访问基础，原生材质仅作为可用时增强；不复制Apple字体或默认跨平台分发SF Symbols。不新增第三方UI框架。

相比一次重写，渐进组件化可保留CRUD、草稿保护与已验证数据库流程；代价是过渡期存在视觉差异，需按切片明确未覆盖页面。相比仅改色圆角，本决策把导航、键盘、错误恢复、文本缩放及辅助技术纳入同一门禁。
