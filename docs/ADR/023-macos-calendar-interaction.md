# ADR-023：日历核心桌面操作对齐macOS Calendar

2026-10-26。状态：用户明确要求，接受实施。对应FR-038，覆盖UX-35/FR-036“日空白单击直接新建”的旧约定；不改数据模式。

事项单击选择，双击或键盘编辑；日期数字双击钻取，月空白双击新建；小时轴单击只定位、双击/Return或拖选释放新建。New、日周月年、今天、跳日期与前后导航依据当前日历窗口路由；Qt便携Ctrl在macOS表达Command，不能误用Meta。关闭详情/新建后回到日历键盘上下文，输入字段中的Delete/方向键保留编辑作用。

所有创建仍是一份原子草稿，任务编辑、软删、树联动、拖动CAS、DST、循环实例和离开保存门继续适用。没有引入Apple专有资源、系统日历/账号或云同步。实现关系和未覆盖能力见[UX-39](../design/macos-calendar-interaction.md)，实际证据只见PROGRESS；不据Windows合成输入宣称macOS实机通过。
