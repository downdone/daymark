# Daymark 4.0.1

Windows托管更新包由受保护流水线发布。

- 修复「安排」中的提醒下拉。展开到面板外的选项可以点击，Esc 先收起下拉并保留草稿。
- 服务器同步协议不兼容时暂停自动同步，保留待传修改。可备份并重新检查协议。兼容协议内需要重建同步基线时，会先请用户确认，再备份和合并。冲突由用户在两个版本之间选择。
- 退出账号后，可从账号页打开独立的「仅本机资料」设置任务周期。原账号资料与待传修改保留。

客户端数据库仍是 schema 12，账号同步仍使用 HTTP JSON v1。4.0.0 使用现有 Windows 在线更新链。3.2.0 及更早版本需通过完整安装包升级。任务周期暂限本机资料，跨协议的 DTO 1→2 迁移尚未提供。

Windows 安装包及便携包采用项目固定指纹自签名及独立 P-256 更新签名。项目自签名未获得 Windows 公共发布者信任。macOS 和 Linux 提供源码。物理多屏、混合 DPI 和读屏暂未验证。
