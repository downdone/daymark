# 账号同步实现与验收契约

SYNC-07/UX-61更新：登录、注册和账号管理已改由主窗独立入口及AccountWindow承载，设置中移除。现行操作链、布局及实现前评审见[独立账号窗口](account-window.md)；下文SYNC-06设置表单仅保留作技术演进追溯，其服务器/密码/保存门规则继续有效。

FR-042；延续客户端模块契约。

注册补充（SYNC-06）：设置表单提供登录/注册切换；注册多一个确认密码，显式“注册并同步”授权后走同一草稿保存门。两次密码一致、至少8个Unicode字符且不超过1024 UTF-8字节；服务端最终校验。服务器/账号只在打开表单时预填，后台状态刷新不覆盖正在输入的内容。模式切换/关闭清空密码，发送后清空，忙碌禁止切换/提交，Tab按服务器→账号→密码→确认→提交→切换；确认框Enter同一提交，错误保留服务器/账号。沿用共享字号/滚动，UX-07/09/11覆盖失败/200%/键盘，原生平台未测不标通过。

POST /v1/auth/register使用RegistrationRequest（protocol_version/login/password），204不区分新建/已存在且不创建会话；客户端随后独立登录并同步。重复提交不会覆盖密码、恢复已删账号或生成第二个dataset，丢注册响应可用登录确定结果。旧配置registration_enabled默认false，示例显式true；metadata.registration_enabled不改变DTO1封闭features；旧服务器缺字段视为不支持。注册入口在KDF前按IP每分钟5次、全进程每分钟20次限制，IP只取socket地址，不信任转发头。已有登录限流与Argon2并发门继续生效。此用户名不是已验证邮箱，不提供邮件找回。依据[OWASP认证建议](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)的通用错误/限流及[HIG账号管理](https://developer.apple.com/design/human-interface-guidelines/managing-accounts)；平台交互沿项目HIG映射。

未登录保留本地业务；绑定账号后退出仍记录该资料的离线修改。账号、服务器或实例不同使用独立数据库，不重标已有资料归属。系统凭据保存令牌，数据库/导出/偏好不保存密码或令牌。

设置入口放在「通用／账号与同步」，沿用 SettingsGroup、共享文字与滚动槽。按 P-13 的 HIG 内容优先、用户控制、一致性和可访问性，默认仅显示本地/连接状态及适用动作；登录才展开服务器、账号、密码；忙碌禁用重复提交；错误保留服务器和账号，密码发送或关闭窗口即清除。相关 UX-01/02/07/09/10/11：Tab 按字段→登录/退出→冲突选择顺序，密码可 Enter 提交，Esc 关闭设置，大字时正文自然增高并滚动；浅深主题复用语义颜色，不用颜色单独表达结果。

账号登录、资料切换和冲突决定经 Main.navigateSafely 保存现有草稿后执行。切换保留旧文件和待传队列，资料入口可离线重开。冲突保存完整候选及相关批次，选择作用于该组，不单独截取一个字段破坏关系。服务器恢复/epoch 变化先创建一致备份并保留原冻结队列，再进入显式重新合并。

网络协调器只在认证有效时工作，单请求链处理刷新、拉取、发送、回声和作业；生产只允许 HTTPS，测试可注入专用 CA，禁止忽略 TLS 错误。回调携带 profile/generation，退出中止请求并使旧回调失效。业务写入与 outbox 同事务，远端应用不回写 outbox；receipt 不推测实体正文，后继等完整回声落入基线。分批游标仅随该完整批次提交。

测试证据维护在 PROGRESS：共用 77 Schema 样本及 16 编码向量、真实临时 SQLite 的捕获/回滚/冻结/回声/冲突、临时 Go 服务与两个 Qt 工作区真实往返、系统凭据合成条目读写删除；macOS 系统凭据和原生 UI 另列平台验证，不从 Windows 或 mock 推断。

迁移10只新增同步元数据/兼容字段，历史1～9保持原样。`tasks.sync_occurrence_key`承载D:日期或A:前驱ID，`sync_occurrence_on`承载真实日历日；旧`occurrence_on`仍是本机历史唯一槽，同日多个完成后后继可以占不同槽而不改变真实日期。规则时区在创建时固定；非WEEKLY的weekdays_mask出站归零。`Identity`仅在边界翻译任务/父子/链接/实例key/任务排序引用，保留本地编辑与历史的物理ID，不对所有UUID做字符串替换。别名改变时，未冻结意图可重映射；冻结的payload/hash/意图不可重写，需冲突重建新mutation。

重复实例是可预测的派生事实；服务端回声落库后使用服务端完整创建/更新时间。本地候选保护由Journal先裁决，Mapping不以本地预生成时间覆盖已确认事实。批量完成与其后继生成也在同一外层事务，优先使用此次完成的前驱，不以设备时钟大小决定因果顺序。

远端删除与本地未传修改冲突时，Repository产生只读隐藏投影，QueryService统一从主列表/日历及提醒投递中排除；业务候选没有被软删或覆盖，完整内容仍在冲突组中。明确选择本地后按新mutation执行restore及后续patch，选择服务器版本则应用完整远端组。被旧格式/协议拒绝的队列不显示“已同步”，提供保留、导出及更新客户端的提示。

已保存的staged引用到期可更换传输作业重试同一冻结语义；尚未取得可复用引用的上传/快照作业到期或状态失效时，首期采用保守恢复：先一致备份，停止旧作业自动重试，保持会话并显示“备份并重新合并”。用户显式选择后建立新基线/新请求，原冻结字节作为SUPERSEDED证据保留。服务器epoch变化则需重新登录；实际错误码epoch_changed同样进入此分支。备份失败必须显示失败，不能误报“已备份”。

## SYNC-07 协议变更与迁移

1. **功能**。发现服务端已要求更高协议版本，停止自动发送并保留本机编辑。用户可以备份后升级客户端，或在服务恢复兼容后重新检查。已支持协议中的基线变更可以重新合并，同一资料的修改发生冲突时交由用户决定。
2. **选型**。延用受版本约束的 HTTP JSON、Qt 同步协调器、SQLite 事务和现有冲突界面。以服务端能力与实际资料版本门作为依据，应用版本号只用于帮助用户升级。
3. **数据流**。启动与手动复查先校验能力，再拉取变更，最后推送。兼容但基线过期时，用户确认重新合并后拉取快照，比较双方候选并展示冲突。
4. **模块**。Coordinator 暂停或恢复传输，Journal 保存冻结请求和对照版本，AccountWindow 提供备份、复查与确认，TaskWorkspace 继续处理本地编辑。
5. **协议**。现有接口与结构无改动。426 `protocol_upgrade_required`、接口结构或能力不兼容都进入等待状态。每种新旧 DTO 组合需在双端实现明确转换和校验才能开放迁移。
6. **接口**。`syncState.protocol_paused` 表示当前客户端停止自动同步，`syncNow` 重新检查，`syncRebuild` 仅用于已支持协议的基线重建。`syncResolve(id, decision)` 保留现有按冲突组选择的契约。
7. **数据**。本切片无需新表或迁移脚本。冻结请求、修改 ID、散列和待同步队列保留，重启重新协商。以后转换到新协议时，先做一致备份并查询原回执，再按确定的资料范围、epoch 和服务端 head 生成迁移计划。转换后的新请求用新 ID。
8. **体验**。按 P-13、UX-07/09/11，在账号与同步页按当前状态显示动作。备份使用现有页面，支持键盘和换行。重新合并要求确认，冲突显示此设备与服务器的候选，默认不替用户选版本。
9. **可靠性**。暂停期间可继续编辑，网络恢复需显式复查。转换或应用发现资料基线变化时重算，冲突未处理时保留双份候选，任何失败可从备份恢复。日志只记录诊断码、阶段和请求编号。
10. **验收**。真实临时 Go/TLS、Qt 双资料链覆盖协议错误、暂停时持续本地编辑、复查后发送原修改，以及已有的按组冲突决议。QML 检查账号状态、键盘和窄窗动作可达。
11. **自审**。成功响应结构错误也可能发生在服务器已提交之后，因此不能丢弃冻结请求或直接改其正文。同一协议换基线走既有备份与合并，仅在旧回执和转换关系经过验证后支持跨 DTO。
12. **交付边界**。先交付检测、暂停、备份与复查，以及现有协议内的确认恢复。DTO 1→2 和账号任务周期需要独立的双端转换和双设备验证。
