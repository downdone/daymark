# 账号同步实现与验收契约

FR-042；延续客户端模块契约。未登录保留本地业务；绑定账号后退出仍记录该资料的离线修改。账号、服务器或实例不同使用独立数据库，不重标已有资料归属。系统凭据保存令牌，数据库/导出/偏好不保存密码或令牌。

设置入口放在「通用／账号与同步」，沿用 SettingsGroup、共享文字与滚动槽。按 P-13 的 HIG 内容优先、用户控制、一致性和可访问性，默认仅显示本地/连接状态及适用动作；登录才展开服务器、账号、密码；忙碌禁用重复提交；错误保留服务器和账号，密码发送或关闭窗口即清除。相关 UX-01/02/07/09/10/11：Tab 按字段→登录/退出→冲突选择顺序，密码可 Enter 提交，Esc 关闭设置，大字时正文自然增高并滚动；浅深主题复用语义颜色，不用颜色单独表达结果。

账号登录、资料切换和冲突决定经 Main.navigateSafely 保存现有草稿后执行。切换保留旧文件和待传队列，资料入口可离线重开。冲突保存完整候选及相关批次，选择作用于该组，不单独截取一个字段破坏关系。服务器恢复/epoch 变化先创建一致备份并保留原冻结队列，再进入显式重新合并。

网络协调器只在认证有效时工作，单请求链处理刷新、拉取、发送、回声和作业；生产只允许 HTTPS，测试可注入专用 CA，禁止忽略 TLS 错误。回调携带 profile/generation，退出中止请求并使旧回调失效。业务写入与 outbox 同事务，远端应用不回写 outbox；receipt 不推测实体正文，后继等完整回声落入基线。分批游标仅随该完整批次提交。

测试证据维护在 PROGRESS：共用 77 Schema 样本及 16 编码向量、真实临时 SQLite 的捕获/回滚/冻结/回声/冲突、临时 Go 服务与两个 Qt 工作区真实往返、系统凭据合成条目读写删除；macOS 系统凭据和原生 UI 另列平台验证，不从 Windows 或 mock 推断。

迁移10只新增同步元数据/兼容字段，历史1～9保持原样。`tasks.sync_occurrence_key`承载D:日期或A:前驱ID，`sync_occurrence_on`承载真实日历日；旧`occurrence_on`仍是本机历史唯一槽，同日多个完成后后继可以占不同槽而不改变真实日期。规则时区在创建时固定；非WEEKLY的weekdays_mask出站归零。`Identity`仅在边界翻译任务/父子/链接/实例key/任务排序引用，保留本地编辑与历史的物理ID，不对所有UUID做字符串替换。别名改变时，未冻结意图可重映射；冻结的payload/hash/意图不可重写，需冲突重建新mutation。

重复实例是可预测的派生事实；服务端回声落库后使用服务端完整创建/更新时间。本地候选保护由Journal先裁决，Mapping不以本地预生成时间覆盖已确认事实。批量完成与其后继生成也在同一外层事务，优先使用此次完成的前驱，不以设备时钟大小决定因果顺序。

远端删除与本地未传修改冲突时，Repository产生只读隐藏投影，QueryService统一从主列表/日历及提醒投递中排除；业务候选没有被软删或覆盖，完整内容仍在冲突组中。明确选择本地后按新mutation执行restore及后续patch，选择服务器版本则应用完整远端组。被旧格式/协议拒绝的队列不显示“已同步”，提供保留、导出及更新客户端的提示。
