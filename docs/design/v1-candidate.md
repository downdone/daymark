# Windows V1候选版实施契约

用户确认暂时没有macOS，先交付Windows V1候选版。原PRD P0/P1保持基线，候选版不代表M7双平台正式验收完成。

## V1-A 数据与效率

FR-002批量选择及完成/移动项目/开始日/标签替换，最多一次事务。UI发送选中任务ID与rowVersion，任何冲突、无效日期或外键错误必须整批回滚；取消不改库；不提供批量永久删除。Repository控制事务，TaskService复用单任务验证；线程完成后统一刷新模型。

FR-005历史7/30天筛选、FR-008搜索清单、FR-010日历已完成开关及未排期列表，都由C++查询服务提供，不在QML裁决任务归属。默认搜索/日历仍不包含已完成。日期语义维持本地QDate。

FR-006领域归档新增002迁移与schema2，先备份再升级，旧JSON输入兼容规则见[ADR-012](../ADR/012-v1-candidate-and-area-archive.md)。组织同级排序使用版本检测和单事务，不改变任务排序。

## V1-B 导航与设置

补齐每视图列表位置、侧栏折叠、快捷导航（文本输入/弹窗时不抢键）、密度设置、托盘录入、首次关闭到托盘提示；Windows开机启动使用用户级原生Run登记，明确由用户勾选才写入，不在构建/测试时注册；macOS保持未验证。无新增第三方依赖。

窄窗大字时顶部收集/筛选/批量区独立滚动，列表至少保留96 DIP；快捷录入/搜索同时把对应字段滚入可见区域。组件提供主窗/录入/更多入口；Windows时间/设置/恢复广播及应用重新激活触发统一时钟刷新，仍保留低频兜底。

## V1-C 候选交付

版本1.0.0-rc.1，Debug/Release构建和全量CTest、QML lint、Windows原生合成smoke、SDK隔离部署，候选包与校验和、源代码快照和发行说明。真实外部验收未完成时不建立正式v1.0.0标签；不得把代码存在当作真实OS验收通过。
