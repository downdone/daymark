# UX-54：透明桌面组件的实体菜单与来源锚点

## UX-67：动画隔离与原生上层

桌面Window菜单的声明与可视父级必须位于宿主稳定根容器，不能挂在会淡入淡出、裁剪或随形态禁用的内容层。来源按钮仅提供锚点；Window菜单将来源全局坐标转换到宿主contentItem，不继承来源透明度或enabled。打开任务组件菜单前停止并完成当前过渡，按最终稳定形态重新选择锚点；菜单保持期间不自动收起。

Window菜单保留Qt.Popup语义并移除底层标记、补充WindowStaysOnTopHint，实体底色/窗口opacity=1；宿主平台层级恢复后仍须保持其可见Popup位于上层。测试核对实际Popup.Window与有效祖先透明度、菜单项可用性及真实OS层级，不能只检查menu.opacity这个局部值。覆盖展开/收回中开菜单、普通/置顶/桌面层、组件透明度60%、浅深100/200%、键盘Esc与宿主重新激活。物理其他应用遮挡、多屏和macOS分别标验证状态。

FR-024/025，UX-01/05/06/07/09/11；按P-13映射HIG菜单的就近操作、稳定空间关系、清晰层级和键盘可用性。桌面背景透明度只作用于组件表面，不能影响菜单文字或菜单底色。

小窗与Mini可共用菜单内容，每次打开都从当前可见按钮重新确定右下来源坐标，不复用另一模式的锚点；Window菜单使用稳定宿主根容器承载，按钮只负责定位。独立日历设置入口同样使用明确按钮；Qt负责屏幕边缘避让。组件移动、改变大小或切换模式时关闭旧菜单，下一次重新定位。主窗内Item菜单保留原有就近关系。

所有菜单使用共享不透明内容底和正文/辅助字号，不继承组件透明度。需要越出组件边界的独立Popup.Window使用实体窗口清底，避免透明宿主内外混合合成；原窗口保持透明。独立窗口清底优先保证实体一致，系统外沿合成效果须真实桌面另验。取消、Esc、外点关闭、单一高亮和键盘导航保持原协议。

复用desktop_surfaces：小窗→Mini→小窗重复打开、按钮来源/窗口边界、实体底色、200%字级及原有置顶/穿透恢复链。Qt离屏几何/像素证据与Windows合成器实测分开记录，不能用离屏PASS声称DWM已通过。

## UX-63：重复原生尺寸通知

Qt可能在尺寸已应用后补发同值widthChanged/heightChanged。共享Menu记录打开时拥有者窗口的真实矩形；只有x/y/width/height值实际变化才关闭，重复回执保持打开。继续用当前按钮重新锚定，不能用忽略所有尺寸通知掩盖菜单脱离。desktop_surfaces验证同值信号保持及真实移动关闭，浅深/原生Popup边界继续适用。

## 1.8.0屏边原生定位复核

按HIG稳定布局/适应性与UX-10/11/13，在200%文字下菜单可能宽于小窗。水平定位先以来源按钮的全局右下角和所属屏幕6 DIP边距计算目标，再mapFromGlobal回来源坐标；屏边允许偏移以保证完整可见。打开后尺寸重排仅更新位置，不重复调用popup建立新的定位周期。原生100/200%、屏边、Mini切换、重复尺寸通知、真实移动关闭及键盘Esc/菜单命令均继续进入原有探针；真实物理多屏DPI仍单独验收。
