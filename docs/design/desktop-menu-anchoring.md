# UX-54：透明桌面组件的实体菜单与来源锚点

FR-024/025，UX-01/05/06/07/09/11；按P-13映射HIG菜单的就近操作、稳定空间关系、清晰层级和键盘可用性。桌面背景透明度只作用于组件表面，不能影响菜单文字或菜单底色。

小窗与Mini可共用菜单内容，但每次打开都从当前可见按钮重新确定视觉父项和右下来源坐标，不复用另一模式的锚点。独立日历设置入口同样使用明确按钮；Qt负责屏幕边缘避让。组件移动、改变大小或切换模式时关闭旧菜单，下一次重新定位。主窗内菜单保留原有就近关系。

所有菜单使用共享不透明内容底和正文/辅助字号，不继承组件透明度。需要越出组件边界的独立Popup.Window使用实体窗口清底，避免透明宿主内外混合合成；原窗口保持透明。独立窗口清底优先保证实体一致，系统外沿合成效果须真实桌面另验。取消、Esc、外点关闭、单一高亮和键盘导航保持原协议。

复用desktop_surfaces：小窗→Mini→小窗重复打开、按钮来源/窗口边界、实体底色、200%字级及原有置顶/穿透恢复链。Qt离屏几何/像素证据与Windows合成器实测分开记录，不能用离屏PASS声称DWM已通过。
