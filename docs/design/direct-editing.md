# UI-18：就近编辑与渐进呈现

FR-002/007/014/018/019/021，UX-01/04/05/06/07/09/10/11。本轮从用户三张参考图提取交互关系，继承UI-17的圆角、色彩与分组；先定义行为，再实现共享控件及页面迁移。

## HIG映射和取舍

Apple [Pickers](https://developer.apple.com/design/human-interface-guidelines/pickers)允许日期/时间通过键盘和指针选择；[Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)用于互斥选项；[Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)强调明确确认与取消。2026-10-24读取官方页面。Daymark采用直接选择、渐进呈现和用户控制，在Windows保留文本输入及Ctrl习惯，不复制触屏滚轮、专有图标或玻璃材质。

## 全局规则与页面映射

| 参考关系 | Daymark行为 | 覆盖范围 |
|---|---|---|
| 点击任务先快速编辑 | 非模态紧凑编辑卡，标题、自然增长备注和计划日期；“完整详情”继续同一草稿；明确保存/关闭 | 主任务列表；日历/提醒/组件仍直接打开完整详情，避免小窗中套编辑层 |
| 日期开关展开日历 | 计划开始/截止使用开关，开启填今天并展开同组日历，关闭清除该字段并收起空输入；开启后输入框仍可手输；选择后收起 | 任务详情；事件开始/结束为必需日期，只展开日历而不提供清除开关 |
| 点击图标给常用日期 | 日历图标直接给无/今天/明天/一周后/自定义，输入框及Alt+Down打开完整日历 | 所有DateField：任务、日历改期、事件、规则、组织、批量 |
| 时间可选择且可输入 | 共享TimeField小时/分钟选择器和HH:mm输入；提醒使用日期＋时间面板，面板确认后更新草稿 | 任务提醒、事件开始/结束；时区及UTC转换继续由C++处理 |
| 重复/提醒直接选项 | 同行标签＋单选菜单，当前值有勾选；间隔/结束日期仅重复开启时显示 | 事件、重复任务及所有共享ComboBox；仅展示已有服务支持的频率，不伪造每小时/工作日能力 |
| 离开保护 | 继续编辑/明确放弃/保存后继续；破坏性动作文字危险色，取消为安全路径；保存失败保持原草稿 | 快速/完整任务编辑、事件、组织与重复规则 |
| 空间和形状 | 六类编辑/设置/数据弹窗统一灰画布＋浅色白组/深色分组表面；组圆角16、控件8、紧凑卡16；浅深同角色；同组字段同行，200%换行；仅一个正文滚动区，固定提交栏 | 任务、事件、组织、规则、批量、设置、数据；已有只读日历/桌面组件保持安静内容优先 |

快速编辑只映射Main现有基础字段，不建立第二份任务模型。完整归属/清单/今晚/提醒草稿仍一次合成TaskPatch并经原CAS事务提交。快速→完整不重载、不丢输入；切任务、换页、关闭主窗或卡片均走同一离开保护。失败保留所有输入与错误，清除日期只改变指定日期。

展开日历自然参与外层布局，不创建第二滚动轴；同一日期字段最多一个选择面板。快捷菜单只更新草稿，Esc关闭当前选择面板后才退出编辑；重复选择当前值仍保持可辨识。时间选择面板在“使用时间”前不改变字段，取消不写入；非法手输原样保留到服务校验，不静默纠正。面板不靠滚轮修改时分。

## 验收计划

保留202阶段全部草稿/CAS/日期/滚动/归属/200%回归。追加快速编辑→完整保留输入、关闭取消/放弃不写库、实际保存；日期开关展开/选择/清除只改单字段；时分选择及取消/非法输入保留；共享单选当前值勾选。浅深及880×580/200%截图，确认无裁切、固定动作可达。追加长备注＋200%后键盘聚焦日期必须带入同一正文视口，固定操作保持可见，放弃不修改原备注；手动滚动不被旧焦点吸回。自动库QTemporaryDir。

Windows执行scripts/build-windows.ps1、test-windows.ps1及两项QML lint；macOS为bash scripts/build-macos.sh与ctest --preset macos-debug。原生Windows、自动输入与真实物理IME/辅助技术、macOS分别记录，未测不称通过。无schema/依赖变化，不操作真实用户库或旧进程，不远端推送。
