# UX-53：重复周期的预设与自定义面板

FR-035/041、UX-01/05/06/07/09/11，延续P-13及HIG菜单/渐进呈现。解决详情内重复频率、间隔、星期、结束日期、说明和预览同时展开的问题；重复业务语义、范围和历史保护不变。

预设选择后仍是一行摘要，不显示展开箭头或参数表。每天/每周/每月/每年一步选入当前草稿；不重复明确关闭。重复开启时，“结束重复”独立一行显示日期或“永不”，可直接设置或清除。只有“自定义…”打开来源附近的独立面板，保留频率、间隔和按星期选择，隐藏与当前频率无关的参数。面板只有取消/完成，取消或Esc/外点恢复本次打开前的周期参数，不误提交或放弃整个任务；完成一次选入原任务草稿。现有规则修改对后续/历史的影响仍有简短明确提示，原版本与事务保护保留。

自定义面板采用共享PopoverSurface、正文/辅助字级与单轴滚动，浅深/200%适应窗口；不嵌套另一张大表单或复制业务规则。普通重复预设的展开状态不撑长主详情。复用已有日历/详情控件与测试入口，验证预设不展开、取消零改、完成回摘要、结束日期、重复数据保存/停止及旧草稿门；平台读屏/实机仍单独记录。

预设“每周”使用开始日期（未设置则本地今天）的星期，由C++日期接口提供默认集合；已有重复规则切换同样有效。锚点当天的普通每周仍属于预设，额外星期/间隔才视为自定义，月/年继续沿用原服务锚点规则。
