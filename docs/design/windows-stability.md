# V-02W：Windows稳定性与恢复验收基础

对应M7-03/04/05、FR-003/014/015/018、NFR-04/05/06/08/10、TC-040～045。业务已实现，下一阶段补可重复的可靠性证据。此次交付Windows实现及短时实跑，不将短跑或系统消息注入称为8h/真实睡眠/物理多屏通过。

1. 系统事件不在原生回调里执行刷新：时间/设置/恢复消息合并为一次排队回调；激活窗口共用入口。忙碌期间保留一次维护请求，提交完成后补做，不因正在保存而丢掉唤醒处理，也不无限重试失败维护。
2. 主窗与组件响应工作区变化；主窗屏幕移除/可用区域变化后仍可达，不因规范化而显示隐藏窗口或解除最小化。原生消息测试只证明分发/合并，不证明真正唤醒。
3. --soak-seconds/--soak-report仅运行隔离的QTemporaryDir：先完成现有UI smoke，再同进程连续循环创建、完整保存、完成/恢复、软删/撤销、重载、视图切换和组件模式/显隐。禁止指定用户data-dir；不建托盘/真实启动项、不发送系统通知。
4. PowerShell工具默认8h，按5秒采集CPU时间增量、工作集/私有内存和进程存活，结果输出独立新目录；报告不含标题、备注、真实库或设备名。失败/超时非零退出，不能伪造PASS。短跑提供可重复的工具验证；8h、睡眠、多屏门禁仍需真实运行与人工记录。
5. 构建/CTest包含消息类型、事件风暴、析构取消、忙碌时补刷新、几何持久化与销毁安全；短时原生运行验证新工具和退出报告；10k基准继续记录数据层限制。

无需schema变化或新增第三方依赖。远程发布、签名、macOS及干净机保持独立门槛。

## 编辑不中断（UX-05/09/11）

后台维护使用独立的backgroundBusy状态；表单保持可编辑，保存等写入动作仍等待数据库空闲。维护成功保留现有校验错误，失败显示可操作错误。统一详情使用显式Flickable正文，焦点追随同一滚动轴；原生探针在长备注、后台维护、880DIP及200%缩放下验证新增清单字段可见。正文外固定返回/保存区，不新增嵌套滚动或弹层。
