# UX-52：行内留白与启动呈现

FR-002/012/018、UX-01/04/09/10/11/12/14，P-07/08/09/13。依HIG内容优先、一致及低干扰呈现原则，继续使用UX-48视觉源，尺寸为Daymark自主规则。

## 问题与设计

两行任务不应把32 DIP图标命中盒的高度变成标题上内边距。浏览行的标题/备注/时间作为内容块，紧凑双行上下各4 DIP；单行保持现有居中和36 DIP起行高。完成、展开、详情及排序仍有32 DIP起命中，实际图形对齐标题首行，命中盒留在本行内部。简易编辑同样以标题和备注为一个文字列，图标跨两行占位，避免更换编辑状态后文字轴漂移。文字使用自然行高，空备注输入保留紧凑编辑空间；工具仍沿文字左轴，大字换行/滚动、失败与完成反馈保持。

启动当前在QML加载时显示主窗，随后恢复几何/最大化，再读主题，存在可见窗口改尺寸和清屏颜色切换。改为主窗初始隐藏，完成窗口几何、控件/桌面组件设置和主题偏好加载后，在事件循环呈现；最大化恢复只设置窗口状态，不擅自显示隐藏窗口。独立日历关闭状态不能被恢复最大化意外打开。组件同样在偏好加载后首次显示。没有固定睡眠、透明度动画或替换系统窗口框架；数据库初始化失败仍显示可操作错误，不等ready才显示。真实DWM/GPU首帧黑边不能由离屏证明完全消除。
