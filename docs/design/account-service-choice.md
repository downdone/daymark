# UX-78 官方账号与自定义服务

2026-11-05，2.0.0切片。FR-043及账号同步契约延续，协议v1/schema10不变。用户明确要求两种登录入口，官方地址编译时从独立本地文件读取，公开源码只有示例。HIG清晰层级/熟悉选择/用户控制映射UX-01/09～13、P-01/03/07/13～21。

登录/注册页在表单前放置两个同级服务选择：“官方账号登录”和“自定义URL”，默认前者。官方不出现URL输入框或可编辑地址摘要，只说明使用官方同步服务；自定义保留HTTPS地址输入、收起摘要/更改、账号密码及原错误/注册交互。选择有文字、选中态和完整辅助名称，支持Tab、方向键/Enter/Space；忙碌时不能改目的地。切换方式清除密码/确认密码和显示密码状态，保留账号及自定义地址，焦点到新方式的首个需要填写项。

请求源由只读`activeOrigin`决定：官方读取TaskWorkspace的编译配置，自定义使用原输入；注册和登录使用同一选择。继续保持Coordinator的HTTPS/证书验证/账号资料隔离/失败保留语义，不建立第二条网络通路。登录后官方服务标记为“官方账号服务”，自定义显示原服务器来源；退出/资料切换推断当前方式，不能把隐藏的官方地址预填进自定义输入。

本地单一来源为`config/official-service.local.txt`，一行HTTPS源，无账号口令/path/query/fragment，Git忽略；示例为official-service.example.txt。CMake验证并生成构建目录头文件，输出不回显配置内容；缺文件编译为空配置，官方入口显示可操作说明并禁提交，自定义仍可使用。示例文件绝不能自动代替真实官方地址。构建路径参数DAYMARK_OFFICIAL_CONFIG允许独立工作树读取同一个本地文件；实际URL不上传CI/仓库，公开CI可验证未配置分支。本地二进制自然包含连接地址，不把编译配置宣称为地址加密。

验证：配置缺失/合法/非法源及错误输出不泄漏；UI两种方式可辨、官方无URL输入、切换清密码、注册复用所选来源、原错误/忙碌/资料/本地退出不回归；浅深100/200%和窄窗滚动/键盘；真实官方服务的注册/登录和同步用临时资料与随机合成账号单独验证，不将展示状态当网络成功。
