当前任务界面包含侧栏六视图、快速输入/搜索/列表、显式保存及未保存离开保护、错误/空态、8秒软删撤销；组件显示真实Today模型。在[BASIC-01](basic-tasks.md)基础上，按[UI-10统一编辑面板](unified-task-editor.md)使用宽窗并排、窄窗主内容页，完整字段共用单一草稿与正文滚动轴。下面工程预览段落是早期骨架记录，后续M3/M4/M5段落是完整产品目标，不代表全部已交付。

## 本轮骨架（已实施）

目的：验证工程与两个 Qt Quick 窗口。主窗口 1120×720 DIP、最低880×580，显示项目名、工程预览说明、显示/隐藏组件和退出按钮。组件为独立透明背景 Tool 窗口，340×190，明确没有任务数据；其隐藏不退出主窗口。

入口为启动应用；主动作是切换预览；关闭主窗或退出按钮结束应用。组件关闭仅隐藏。当前无持久化写入、未提交草稿和业务 loading。QML 加载错误通过原生错误对话框报告。Controls 使用 Basic 风格，文字用 qsTr，按钮具备 Qt 默认键盘焦点。自动化 smoke 检查两窗口加载和 QML 警告，视觉/DPI/键盘人工验证保持 UNVERIFIED。

## M0 窗口控制设计

### W-01 交互方案（已实现，人工验收待验证）

主窗增加显示/隐藏、Floating/Mini切换及置顶勾选；错误条保持可见并提供关闭。组件Floating为340×190，表头左侧拖动、右侧迷你/隐藏按钮；Mini为260×48，左侧拖动、右侧展开按钮，分开点击与拖动区域，防止拖动误展开。没有任务时显示“暂无任务”，不虚构计数。

模式往返保留当前位置和原Floating尺寸。隐藏时切换模式或置顶不能令窗口出现；用户再次显示才可见。所有窗口命令经WidgetViewModel和IWindowPlatform执行；QML不改flags或窗口几何。通过QWindow.startSystemMove发起系统拖动，不使用定时移动坐标。失败保留旧状态，主窗错误条给恢复建议；未绑定窗口时控件禁用。

本轮不保存设置、不启用穿透/托盘。置顶命令只验证Qt请求状态，真实OS层级、拖动和焦点行为需原生交互测试。

主窗提供 Floating/Mini、置顶、锁定、背景透明度、显示隐藏和重置位置。表头拖动，迷你点击展开。穿透开关说明全窗不可交互，并且先完成托盘和主窗恢复入口才允许启用。用户主动点击输入时可获得焦点；被动展示/刷新不得抢焦点。

托盘菜单：打开主窗口、显示/隐藏组件、关闭/启用穿透、退出。主窗退出与关闭到托盘按设置区分；无托盘立即退出，不能进入无法恢复的隐藏状态。设置失败显示当前实际状态、原因和重试操作。

验收：TC-027/028/029/041 和平台矩阵。每项标明 OS、缩放、屏幕拓扑和真实步骤；offscreen 不代替操作验证。

## M3：任务主链

布局按 PRD 三栏；窄窗详情覆盖呈现。Inbox 输入 → 保存 pending → 落库成功插入列表并清空输入；失败保留输入、显示原因。任务行完成后由同一 TaskService 更新主列表/组件/Logbook。详情防抖400ms，但关闭/切页必须处理未提交输入。

每页设计同时包含空态、新建入口、加载/错误/重试、键盘、DPI、浅深主题。标题和备注无网络请求。日期分别标“计划开始”“截止”，日期冲突就地解释且不提交。

## M4：日历主链

月/周切换复用 CalendarService；点击标记打开同一任务详情。双击空白日期创建 ACTIVE 且预填 startOn；拖动 Start/Deadline 只修改对应字段，同日合并项先选择含义；失败回原日并显示原因。周历为七日全天列，没有小时轴。

## M5：组件业务主链

WidgetTodayModel 与 Today 同源，浮窗最多先呈现8项并可滚动；迷你约260×48。完成需写库成功后同步各视图。暂无任务时给添加入口；写入失败保留任务并允许重试。锁定只禁止拖动，不代替穿透；透明度只调背景，不降低文字可读性。
