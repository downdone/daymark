# CAL-03 独立桌面日历及日历精修

FR-010/012/018/019扩展，UX-01/02/05/06/09/10/11/13；P-13：内容优先、用户控制、稳定导航、适应空间。沿用HIG项目来源，不复制资源。月格今天用数字强调，选中日期用背景，细线分隔周行、周末次级色；导航紧凑，月周分段与新事件/显示工具分层。

独立日历Window与Floating同时存在；独立锚点/模式/选中日期，复用CalendarPanel及C++ CalendarService/EventService映射，不创建第二数据库或TaskWorkspace。任务编辑转主窗并保护原草稿；事件在所属日历窗口编辑。独立窗口关闭仅隐藏，主日历工具/主窗设置可恢复。提供背景50–100%、置顶、重置位置；不使用全窗opacity，文字和输入保持实色。隐藏/透明度/置顶/窗口几何存本机ui.ini，失败保留原设置并显示错误；无穿透或桌面壳嵌入。

先完成日历查询参数化与持久化、再共享面板与独立窗口，最后构建/CTest/lint与原生三窗、独立导航、数据同步、透明/深色/200%截图。Windows窗口原生可调整尺寸，保留系统关闭/键盘习惯；屏幕移除规范化位置。macOS/物理多屏/读屏/真实合成透明效果仍须实机验收。所有自动数据QTemporaryDir。
