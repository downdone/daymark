# UI-19：原行展开、可理解的整理与即时反馈

FR-002/006/007/008/014/018，UX-01/04～11/14，P-13。本轮按用户四张图修订UI-18：快速编辑必须是原任务行展开，不再是覆盖列表的表单；技术测试通过不代表体验已获认可。

依据已读取的Apple HIG Layout、Typography、Buttons、Menus、Motion、Color：内容优先、操作贴近对象、同语义同控件、克制且可减少的动效。Windows继续系统字体与Ctrl习惯，原创图形，不拷贝SF Symbols；以下自主尺寸和色值不是Apple强制值。

## 先定义操作链

| 问题 | 设计及覆盖范围 |
|---|---|
| 快速编辑变成大表单 | 原任务行增高约两行：完成圆＋14DIP标题＋信息图标；下方12DIP单行备注；最后一排日期/截止/标签/项目/提醒图标。图标直接打开锚定选择面板；无“快速编辑”标题、两日期表单和底部三按钮。仅一份共享草稿，详情不重载；保存勾号或Ctrl+Enter提交，Esc/收起走草稿保护。已有多行备注显示摘要，进入详情编辑，禁止用一行覆盖整段。 |
| 字号不统一 | 页面24/详情及弹窗18/分组14半粗/正文和行标题14常规/元信息12，全部跟随同一系统字体及文字比例；快速标题不冒充页面标题。线性图标16～20、统一圆端点，信息i、标签#、项目folder、日历/截止旗/提醒铃语义独立，不展示未实现位置/照片/优先级。 |
| 归属术语无解释与入口 | 改“整理”，明确项目是多步骤目标、领域是长期职责、标签用于跨项目查找，全部可选；项目/领域选择里有新建入口，标签有就近新建。新建独立提交到资料库，成功后加入当前任务草稿，取消任务不删除已经创建的资料条目，界面提前说明。 |
| 返回/保存/危险操作混在底部 | 详情标题左侧返回箭头（名称和快捷键），右侧明确保存；删除/取消作为详情末尾有文字的危险操作，移除底部省略号。固定头部和错误区；清单行删除/移动继续贴近条目。 |
| 列表元信息一长串 | 完成圆与标题基线对齐，元信息用少量图形＋短日期/步骤数；安静选中、缩小行间隙与内缩细分隔；不以整行大焦点框表达选中。 |
| 完成直接消失 | 命令立即提交；仅成功导致列表移除时保留约100ms勾选反馈，再80ms淡出/收拢。失败保持行和错误，不先伪造持久成功。新增显式“减少动态效果”偏好，关闭该反馈动画；原滚动不弹跳。 |
| 菜单迟滞 | 主窗菜单改同窗Overlay层，无新OS窗口启动/淡入等待；小窗/桌面日历保留独立Menu Window避免裁切。移动可用性复用C++当前查询模型，菜单打开不重复排序全任务。记录命令耗时和原生首帧耗时，区分实测与推断，不用tooltip的延迟冒充菜单延迟。 |
| 设置旁三点无信息架构 | 资料库区域明确“项目与标签”；规划下提供“重复规则”；提醒中心独立入口；底部只保留设置与明确“数据与备份”，退出放设置通用页。取消无名称的工具省略号，保留所有旧功能。 |

## 色彩及表面

继承灰画布/白内容组/深色分组表面。以iOS系统蓝、绿、红的色相关系为方向，文字强调蓝选择可读的深蓝，开关可用明亮绿色但勾号位置仍表达状态；文字/必要边界按4.5/3复核，不能直接把低对比系统亮色作为小字。输入默认不堆底线，只在hover/焦点显出编辑关系；快捷行像文档内容，选中和焦点不同。图标同一描绘体系，主题/增强对比度同步。

| 关系 | 浅色 / 深色自主值 | 使用 |
|---|---|---|
| 画布与内容 | #f2f2f7 / #111113；#ffffff / #1c1c1e | 画布退后、内容组前景，不叠加完整外框 |
| 蓝强调 | #0057b8 / #8ebdff | 可操作文字、选中图形、焦点 |
| 选中底色 | #e7f0ff / #243b5b | 列表选择，与键盘轮廓分别表达 |
| 成功文字 / 开关 | #236e46 / #83d6aa；#248a3d / #32d45a | 成功文字保持对比，开关用滑块位置及颜色共同表达 |
| 危险 / 今日 | #b92330 / #ff9ca4；#c22c3b / #f58d96 | 危险动作与今日日期角色独立 |
| 线框 | 默认输入无底线；hover 1px、焦点2px；内缩分隔1px | 装饰线不用作控件可见性的唯一依据 |
| 圆角与图形 | 内容组16、原行展开14、选中行10、图标按钮圆形 | 图形绘制限制在18DIP（放大上限24），不随按钮剩余空间拉伸 |

同窗菜单没有进入/退出过渡；Tooltip的600ms解释延迟独立保留，不是菜单延迟。包含已完成任务的混合列表不开放手动上下移动，避免可见邻居与原排序写入范围不同；已激活任务不再显示无效果的“激活到随时可做”。

菜单性能探针分别记录调用耗时与两次frameSwapped的上界（本机预算100ms）。后者在渲染信号线程取时间，通过原子值传回，采集完成才截PNG，避免截图读回/界面队列污染计时。它记录Qt呈现信号，不等同物理屏幕光子或用户输入端到端延迟；负载/遮挡/设备差异单独记录。

## 草稿与模块

Main继续持有唯一TaskPatch草稿。共享快捷编辑Control视觉重挂到选中的TaskRow，列表自身是唯一滚动轴； delegate销毁/模型刷新时安全转移，找不到任务时转完整详情保留草稿。项目/标签新建走既有CatalogService/Repository，并通过服务成功结果传回ID；失败保留名称/任务草稿。无schema/SQL/外部依赖更改。

## 验收

保留原223阶段数据/草稿/日期/错误回归，但将覆盖式快速卡及长备注内部滚动断言替换为原行嵌入、单行摘要不丢多行内容、同份草稿转移和列表单轴。追加新建项目/标签成功后任务未写库、取消/重复名称失败保留；返回/保存位置与就近危险动作；完成成功有延迟移除、失败不消失、减少动态效果；侧栏所有入口及主/组件菜单不裁切；原生浅深/200%截图和菜单实际耗时。QtTest/CTest、lint、颜色/文档检查、Windows原生及严格本地包；真实IME/读屏/物理设备及macOS仍单列UNVERIFIED。
