# UI-16：任务详情的信息架构与行布局

FR-002/006/007/008/009/014/018；UX-01/04/05/06/07/09/10/11。用户指出详情只是逐字段纵排，缺少行关系和分类。本轮替代UI-10“所有字段纵向常驻”和UI-14任务详情的等权卡片，保留单草稿、单一正文滚动、原子保存和固定操作区。

## 依据与问题

Apple [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)要求以重要性、对齐、相关性分组及渐进呈现建立层次，并在文字变大时重排；[Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields)强调可辨识标签及与内容匹配的输入尺寸。2026-10-24读取官方同域.md。以下分组、断点和DIP均是Daymark决定；Windows系统字体/窗口、UI-15颜色与完整状态继续有效，不模拟Liquid Glass。

现状：空备注占据大块高度；规划状态整行、关注和今晚跨组；互斥归属同时展示两框；无意义禁用分组、空标签/关联和只读时间各成卡片。卡片背景只是包裹字段，没有解决任务操作的主次。

## 页面结构（先定义，再实现）

```text
任务详情                                      未保存
任务标题
添加备注…（自然增长，不预留大块空白）

安排 ─────────────────────────────────────────────
状态 [已激活 v]          [✓ 关注今天] [□ 安排今晚]
计划开始                 截止日期
[未设置       日历]      [未设置       日历]
提醒 · 本地时间          [yyyy-MM-dd HH:mm]
仅在应用运行时检查提醒，留空清除。

归属与标签 ───────────────────────────────────────
项目或领域               项目分组（仅适用时）
[无归属 / 项目 / 领域]   [无分组 / 分组名称]
标签   [□ 标签A] [✓ 标签B]（没有时仅一行“暂无标签”）

检查清单                                      1/3
○ 步骤内容                                 上移 删除
[新增步骤，Enter添加]                              ＋

关联事件（仅有关联时，直接打开原事件）
任务信息 ▸（创建/修改/完成时间，就地展开）
───────────────────────────────────────────────
                                   …   返回  保存
```

| 行/类别 | 默认宽页 | 窄栏/大字 | 显示与数据规则 |
|---|---|---|---|
| 标题/备注 | 连续文档表面，空/短备注约一行输入高度 | 自然换行增高 | 不建立备注内部滚动；长文本不截断 |
| 状态＋关注 | 状态与今天/今晚同一行 | 状态一行，两个勾选仍同组自动换行 | “安排今晚”显式激活并关注今天，然后进入今晚分组；日期调整由既有C++规则处理 |
| 开始＋截止 | 两列等宽，标签对齐 | 内容宽不足440×文字比例时上下排 | 日期标签/选择器/手输保持独立 |
| 提醒 | 标签与输入同一行 | 窄栏标签在上、输入在下 | 本地时间输入、留空清除；固定短说明，不因焦点出现/消失而跳布局 |
| 归属 | 一个项目/领域选择器；有项目分组时两列 | 同一选择器；分组顺排 | 选项目与领域天然互斥；切换归属清空不适用分组，无分组的项目不显示禁用空框 |
| 标签 | 行标签＋可换行选项 | 同一行标签与换行选项 | 无标签不生成大空卡片；不新增二级弹窗 |
| 清单 | 添加、勾选、改名、排序/删除同组 | 原地增高和换行 | 未按Enter的内容仍计入整体保存草稿 |
| 关联/信息 | 有关联才显示；只读信息默认折叠 | 同样规则 | 仅显式点击切换信息；缩放/改窗口不展开折叠，不隐藏可编辑字段 |

默认正文最大720×文字比例DIP，标题/区段/输入左边缘一致；主页面用一条分隔线和区段标题分组，取消任务详情的等权灰卡片。区段间16、内部8–10、两列间16DIP。状态行在正文宽≥560×文字比例时并排；日期/归属两列在≥440×比例时并排；提醒横排在≥440×比例。停靠窄栏采用一列是空间适应，不再拆成多个弹窗或独立滚动焦点。

## 草稿接口和失败行为

Main持有基础安排、今晚和提醒；勾选“安排今晚”作为显式意图同时设置ACTIVE和关注今天，取消关注时若无需日期确认则撤销今晚标记；日期确认中选择保留不清空今晚，确认改期或以后再说再撤销。不在QML计算Today命中条件，取消关注是否仍命中日期继续使用todayAfterRemovingFocus的C++结果。TaskDetailsFields持有归属、标签、清单。最终合成同一TaskPatch，继续只调用saveTaskWithDetails。归属选项携带kind/id，选择项目只提交projectId，选择领域只提交areaId；任何切换先清空heading再加载该项目分组，加载已有任务时恢复合法分组。无schema/SQL/服务规则变化。

未保存离开仍保存/放弃/取消；非法提醒、日期和关系或CAS失败全部零修改且草稿保留。错误保持固定可见提示；键盘顺序为标题→备注→安排→归属/标签→步骤→关联/信息→返回/保存。Tab仅揭示视口外焦点，滚轮始终交给正文，ComboBox/SpinBox不滚轮改值。仅图标保留名称/tooltip/焦点/禁用态，沿用UI-15。
