# UX-59：提示准入与垂直节奏

FR-018/035/037，UX-01/02/05/09/10/11/13/14；P-13～19。承接UX-40/48/52/58。HIG的内容优先、清晰层级、对齐/适应与帮助不妨碍操作，落地为Daymark自己的数值规则；来源沿用ui-research及ui-baseline。

补核[Apple Offering help](https://developer.apple.com/design/human-interface-guidelines/offering-help)的简短、针对当前控件、不重复名称原则。默认关闭与菜单/切换禁用是用户要求及Daymark准入规则，不能误述为Apple禁止所有按钮提示。普通提示是无焦点、无模态、禁用输入的展示层；只有备注复制预览显式允许输入。

- 普通图标默认不弹提示；仅显式批准的含糊状态操作（如图钉置顶）可说明。菜单入口/菜单项/更多、展开收起、视图/层级/多选/筛选切换、完成/关闭和有文字按钮不提示；保留Accessible.name/状态/快捷键。不能用contentItem不是AppIcon就自动准入。
- 截断原文/完整路径仅在文字区域悬停补全；完整文字不重复。普通提示延迟600ms，移出、按下、失效、菜单或拖动立即关闭。提示与来源控件留8 DIP，优先上方、空间不足放下方并限窗内，绝不覆盖来源；不能成为主要功能的点击前置层。备注复制预览和拖放拒绝原因保留明确例外。
- 垂直节奏用4 DIP基准：行内4、相关控件8、区域12/16，边界由父容器单独负责，不能同时叠子margin与layout spacing。标题区按实际标题/副标题和控件自然高度计算，不为空副标题预留一行；同排内容垂直居中，工具区高度至少controlHeight。
- 浏览行上下留白同源且对称；完成/标题第一行共轴，辅助行间距同源；子任务数量作为同行辅助动作采用24 DIP桌面目标并随字增高，避免32高动作把整行撑出异常空隙。选择/悬停不改尺寸，简易编辑沿同文字轴，新增字段才增加实际高度。大字可重排，不缩字或裁切。

## 标题与工具栏的最终取舍

页面标题独立28 DIP语义角色（其余正文/面板标题角色不变），左侧起点与输入区共轴，整排按自然高度垂直居中；右侧固定顺序为搜索、筛选、视图切换、更多。视图切换紧贴更多左侧固定尾部锚点，其他仅列表需要的工具消失也不能推动它。当前日历状态由标题“分类 · 日历”表达；目的地按钮在列表显示日历图标，在日历显示列表图标，Accessible.name用“切换到…”说明，只有一个可见目标和一次点击，Tab/Space保持。完成/最近删除仍尊重原不支持日历的范围限制。

| 候选 | 操作成本与空间 | 决策 |
|---|---|---|
| 两个模式图标并列 | 一次点击、两个槽，重复展示当前状态 | 收敛为单目标 |
| 当前视图下拉菜单 | 一个入口、两次点击，频繁切换更慢 | 不作为主要入口 |
| 单个目的地图标 | 一次点击、一个槽，标题提供当前上下文 | 采用，固定尾部位置 |

这是按用户的紧凑/直接操作要求，结合[HIG Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)的熟悉图标和明确动作、Layout的稳定关系所作的产品取舍，不声称macOS只能采用此方案。排序复用现有拖动/手柄；多选复用Shift、Ctrl/Command、右键及菜单，不增新常驻按钮。子任务显示、分类/搜索中的已结束任务显示收进更多菜单的“显示”组，勾选表达状态；提醒记录与循环任务归工具组。历史显示启用时更多按钮标记状态，默认不在输入框上方占行。筛选仍负责标签/分类，二者不混为任务编辑动作。

验证：复用desktop_surfaces检查必要图钉提示、切换与菜单不提示/关闭已有提示及文字补全，几何检查提示与来源无交集；task_list_interaction检查浏览/编辑轴和上下留白，保留草稿/完成/多选。浅深/100～200%、窄窗、键盘名称与原生截图分开记录。不增加同义长链或放宽预算，实际证据见PROGRESS。
