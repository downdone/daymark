# UI-17：参考iOS的圆角分组、行控件与分组操作

FR-007/018、UX-01/04/05/09/10/11；继承UI-16单草稿、单轴、固定操作区及同行/互斥归属。用户截图明确授权参考iOS控件、圆角和色彩，以下为Daymark自主实现，不复制Apple字体或图标资源。

依据[Apple Toggles](https://developer.apple.com/design/human-interface-guidelines/toggles)及现有Layout原则：开关表达布尔状态，复选框用于清单/多选；状态除颜色还以滑块位置和可访问checked表达。任务表单仍显式保存，设置仍立即生效，不能因开关样式擅改写入时机。

提取参考图的关系：浅灰画布承托独立圆角内容组；组圆角16DIP、输入8DIP、图标底6DIP、开关为全圆胶囊；不为每个字段套描边卡片。分组之间16DIP，内部12DIP，标签与控件对齐、组内分隔弱。默认浅色白组、深色使用分组表面；蓝色图标表示类别，开关开启使用成功色，关闭用中性轮廓色；正文/次级文字沿UI-15保证对比。尺寸不是Apple规范数值。

任务安排保留状态＋今天/今晚同行、开始/截止同行、提醒紧随；今天/今晚改紧凑滑动开关。组标题增加原创图标及小色底；归属/标签同组，步骤仍用完成复选框。宽页多个控件同排，窄栏/200%自然重排。设置布尔偏好采用同一开关；不加入截图中的紧急、位置、发消息等未实现能力。标题/备注同属一个圆角内容组。常规控件圆角8、选中行10、详情内容组16，层级大于控件而小于开关全圆胶囊。

“拖入今天/今晚”是Label与DropArea，点击无操作；删除顶部伪按钮，分组迁移使用任务“…”中的“安排到今晚/安排到今天”真实菜单命令，任务拖放排序仍保留。不再暴露没有单击行为的按钮外观。沿用setTaskEvening和既有TaskService，不在QML复制Today查询。

验证：构建/CTest、两项lint；原有202阶段涵盖开关toggle/click后的实际任务/设置保存和恢复、互斥归属、错误草稿、窄栏/200%、短备注滚轮。原生截图核对组圆角/开关/图标/左右布局、无顶部伪按钮，以及任务菜单的真实分组回路。所有自动数据为QTemporaryDir，真实鼠标拖放、读屏、macOS仍独立UNVERIFIED。Windows用scripts/build-windows.ps1与test-windows.ps1；macOS用bash scripts/build-macos.sh和ctest --preset macos-debug。
