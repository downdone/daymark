# CAL-05：日程浏览与定位

扩展FR-010/019/020/021，追加FR-022；UX-01/02/05/06/07/09/10/11。依据[HIG Modality](https://developer.apple.com/design/human-interface-guidelines/modality)、[布局](https://developer.apple.com/design/human-interface-guidelines/layout)及项目视觉系统：内容优先，查看不写入，编辑是明确动作，短暂查看可轻松退出。只读详情采用非模态轻面板（无全窗遮罩），点击外部/Esc/关闭均退出；进入编辑后沿用现有模态草稿保护，不叠加两个面板。Windows保留其原生习惯，不复制iOS资产。

## 操作与视觉

点击格内/议程事件→只读详情：完整标题、实际实例日期/本机时间、备注、循环频率/间隔/结束日、提醒提前量、关联任务。循环事件明确“本次安排”与“编辑整个系列”，并显示系列起点；无实例来源（如通用提醒入口）明确显示系列起始安排。详情不含删除按钮，无保存、无副作用；只有显式编辑进入现有表单。实例已失效/事件被删时显示空态并禁用编辑，不回退到错误日期。

宽度最多520DIP、四周16DIP、标题20DIP，正文/次级文字沿用14/12和6/8/12圆角；单一外层滚动与固定关闭/编辑区，长标题/备注换行。短内容自然高度；窄窗及200%受宿主高度限制后滚动。hover/focus/disabled复用共享控件，不增动画或降低整窗opacity。关联任务仅显式点击才跳主窗。

日期导航新增“跳转日期…”；复用DateField的手输/弹层/键盘，非法输入在原位置说明并保持当前视图，成功后关闭并选中该日。主窗与独立窗分别更新自己的锚点，不互相翻页；取消不改日期。今天/方向键/旧日期改期保持原有行为。

## C++接口与排序

calendarDaysFor为事件实例追加occurrenceKey（全天ISO开始日、定时UTC开始瞬间）；同一日事件全天优先、定时按实际开始UTC升序，再按标题和ID稳定排序；任务既有顺序不变。循环频率仍按系列保存，不存实例副本。

calendarEventPreview(eventId,key)只读，重新从缓存验证系列和实例。非空key必须精确匹配当前合法实例；空key返回系列起点上下文。输出日期/时段、循环/提醒摘要、编辑范围、关联任务，QML不投影规则或判断实例是否合法；双窗同一接口。实例key是本轮只读定位键，不是支持单次修改的持久ID。
