# UI-20 / CAL-06A：连续日程、直接操作与全局视觉修订

FR-002/007/010/014/019/020/021/022，UX-01/04～07/09～14，P-13。用户四图及追加提醒链路为本轮输入。Apple HIG Color/Layout/Buttons/Motion强调内容层级、语义色与直接操作；[Apple日历说明](https://support.apple.com/en-euro/guide/iphone/iph3d110f84/ios)说明日程的开始结束、提醒及长按直接调整。截图中连续跨日条、日程实例详情与有序设置行作为机制参考；以下Qt尺寸/配色为自主值，未复制Apple资产。

## 先定义关系

| 项目 | 本轮设计 |

| 跨日事件 | C++按本机实际可见日投影，分周切段，稳定排序分配无重叠泳道；同一周横跨多格连续浅彩背景，真实开始/结束有圆角，跨周边缘平直；最多三条，隐藏项仍可从当天议程访问；只为三条可见泳道做碰撞分配，超出条目计数避免密集事件退化为二次方扫描。午夜结束不多占一天，循环实例独立定位。主/独立日历共用。 |

## 工程与边界

无schema/依赖变更；EventService计算循环实例，TaskWorkspace映射周段和排序许可，QML仅绘制/收发命令。跨日条字段week/column/span/lane/start/end/实例key由C++提供；QML不重判时区/午夜/循环。任务原子草稿、软删、关系、提醒UTC/当地日期语义不变。新循环日程入口只读缓存过滤，不创建任务规则。

按连续条数据和测试→共享月格实现→循环日程入口/预览→排序→全局视觉与提醒单层小切片构建。临时库覆盖跨周/月/年、重叠、午夜、循环实例、不重复查询任务；UI覆盖真实原子提醒一次提交/取消/非法值、默认浅深/200%、菜单及键盘。每切片构建/CTest，最后lint/颜色/文档、原生截图和严格本地包；macOS/真实IME/读屏/物理拖动/DPI/8h与通知实际送达仍单列UNVERIFIED。

视觉自主值：主要动作浅底#e4efff/深色#183b5d，文字#005bbb/#90c5ff；常规强调#0068d9/#79b5ff；全天色条#def3e6/#173b29、文字#205b35/#a1e6b7。输入焦点1px，控件/行/面板圆角10/12/16，状态/开关/提醒行标签14，说明12。


## 追加反馈：减少开关、导航分区与清单排序

依据HIG层级、一致性和直接操作，UX-02/05/07/09/11：安排状态仍表达收集/激活/暂停；“今天、今晚”是一个关注分组，改为“不特别关注 / 今天 / 今晚”三段单选，说明日期仍可能使任务出现在今天，避免把日期判定与关注混为一谈。今天/今晚继续映射原todayFocus/evening，不改QueryService。开始/截止是可空日期，保留两列标签与可直接点击/手输的DateField，通过已有“无日期”清除，不再用独立开关控制字段显示。提醒去掉重复HH:mm文本框，只保留可编辑的小时、分钟步进控件，支持键盘和一次完成。

侧栏的任务、规划、项目与标签各有完整可点击标题及方向箭头，展开状态独立写入现有ui.ini偏好。折叠不切换页面，标题标出当前所在分区；键盘Tab/Space和左右键可操作，默认全展开，页脚设置/数据固定，滚动仅正文。没有实际功能的导航整理菜单不引入。

检查清单把上移按钮换为可见拖动手柄，按住手柄直接拖，行保持占位并显示提起/目标线，释放才改草稿顺序；Esc取消不改，Ctrl+↑/↓提供同等键盘能力，最终与整份任务一次保存。清单文本编辑/勾选/删除区域不启动排序；不因拖动直接写库。

详情底部改为一致的白色圆角“任务记录”分组，展开后显示对齐的创建/修改/完成行；结束/删除操作单独成组且解释可恢复性。保存错误固定在标题下方，输入不丢失；放弃草稿时只清除该编辑会话的校验错误，持久化错误保留。验证错误不得带到不相关列表。所有新控件覆盖浅深、200%、窄窗、键盘、取消/保存与重开持久化；物理手势和读屏仍单列待验。

实现评审补充：分段选择由外部草稿驱动时仅发出选择意图，不能破坏currentIndex绑定，保证放弃重开及日历月/周同步；取消关注确认前不改草稿，“保留”原样关闭。菜单高度按真实可见条目求和，显示时完成ListView布局，避免隐藏项使估算高度和行位置延迟。
