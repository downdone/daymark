# UX-50：列表文字轴与就近编辑的布局节奏

FR-002/007/035、UX-01/04/05/09/10/11/12/14，延续P-13及UX-48/49。依据用户提供的macOS提醒事项截图提取内容优先、原处编辑、行内细分隔和紧凑属性关系；遵守HIG[Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables)、[Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)。以下数值为Daymark自主规则，不是Apple测量标准，也不复制其字体、图标或私有材质。

## 审视与规则

当前主列表的树形槽32 DIP再加子级24 DIP，宽空槽使内容离左边过远；浏览行/原行编辑各自拼装完成、标题、备注和工具，尺寸稍变就会漂移。简易工具横排两个空日期字段，未编辑时的边界与当前值混杂；详情标题被关闭/拖动控件推右，备注却靠左，正文从多个缩进轴开始。界面已经使用共享字级和色彩，继续加装饰不能解决这些几何关系。

- 列表只有一套轴：外侧6、层级槽24（无树/智能范围不占槽）、完成命中32起、文字间隔8、每级缩进20 DIP。展开箭头居于层级槽，完成圆中心与标题首行中心一致；正文、备注、辅助信息、分隔线、原行编辑工具左边共用文字轴。父子层级通过缩进和展开表达，不额外叠图标列。
- 原行编辑保持标题/完成圆/备注原位，标题仅替换为无边框输入；下方展开核心动作。未设置的日期为有名称和提示的圆形图标入口，已设置日期显示明确值；时段始终可直接进入，标签/分类/提醒/旗标统一32起命中与轻底圆形反馈，宽度不足自然换行。编辑背景为安静的分组色，浏览选中与编辑状态有区别；不嵌套一张大表单。
- 详情标题与备注共享左轴，关闭/拖动/展开/更多放在标题右侧；展开页保留左上返回。属性仍用对齐的次级标签列、正文值和必要分隔；双页签只负责内容切换。不新增存储字段、假位置/联系人功能或没有命令的装饰按钮。主要保存、离开保存、无效输入和撤销规则保持。
- 图标/字级/色彩沿UX-48，所有文字跟随缩放；大字时控件保持可读、工具换行、正文单轴滚动。整行选中不靠边框叠加，键盘焦点有明确轮廓；菜单、tooltip及减少动态沿原契约。

## 验证

复用task_list_interaction检查父/子/独立、100/200%、浏览↔简易编辑的完成/标题/备注/分隔/工具坐标，新增首行垂直中心和详情标题/备注轴断言，旧24 DIP断言按此契约改为20且仍严格检查。验证日期圆形入口可打开/取消、已设置显示值、标签/提醒/旗标不丢数据；保留原集合、失败、来源箭头及拖动链。calendar_interaction/contextual_workspace/desktop_surfaces验证共享详情、时段及组件无回归，构建/lint/静态守卫和浅深/200%截图复看；macOS物理桌面、IME、DPI及读屏未实测则UNVERIFIED。
