# UX-51：列表双击空白建立原行草稿

FR-001/002/035、UX-03/04/05/07/09/11及P-02/03/05/13。按用户指定：可录入列表的空白区域双击新增，直接出现简易编辑行，“新任务”标题全选待替换；点击外部时，模板未改取消，已改一次建立。HIG内容优先、原处编辑、可恢复与明确反馈沿UX-50。已完成/已取消/最近删除等历史列表不创建新任务；双击已有任务继续编辑该任务。

草稿是界面状态，不预插SQLite、不创建临时真实任务再软删。默认安排/分类/标签由C++的TaskService::draftForScope产生，界面不重复Today/范围语义。复用单个TaskQuickEditor及详情草稿控件，列表末尾临时行共用文字轴、核心动作、菜单、选时段和键盘；大字可换行滚动，打开后揭示并选中标题。

以最终可见字段与初始模板比较：标题、备注、日期/时段、提醒、分类/标签、旗标/置顶和重复等修改均计入；仅聚焦或开关选择器不计入，改回原值可取消。点击草稿内或其选择器不触发外部提交；切换范围/任务/关闭遵守同一离开门。Enter或Ctrl/Command+Enter显式建立，Esc明确取消新草稿；创建前完成圆禁用，完整详情保持同一未保存草稿。所有字段一次原子写入，失败零残留且保留草稿、输入与错误，成功才关闭。双击开始不触发误保存、忙碌不重复提交。

验证复用contextual_workspace的独立临时库与真实指针/键盘：空白双击/模板全选、未改外点零写、仅开菜单零写、替换标题外点单次建立、范围默认继承、Esc取消、无效输入保持/修正后建立和已有任务双击不新建；服务/工作区检查原子创建和只读默认。不扩张已接近预算的task_list_interaction，也不重复增加CTest套件；UX-49来源/菜单/恢复和UX-50轴线继续回归。
