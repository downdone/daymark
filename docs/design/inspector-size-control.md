# UX-57：详情尺寸控制与展开排版

2026-10-28；FR-035，UX-01/05/06/07/09/10/11/14，P-07/09/13/14。按Apple HIG的用户控制、适应布局、清晰层级与可访问性，修正共享详情尺寸行为。现有HIG来源及事实见[设计基准](ui-baseline.md)和[就近任务面板](contextual-task-inspector.md)；数值是Daymark自主规则。

现状：inspectorExpanded将用户的expanded与主窗width<1000、文字scale>=1.5相或，后两者永远覆盖收起按钮，因此首开被强制展开、点击收起无视觉作用。这不是操作系统最大化或主窗minimumWidth=880直接导致。删除该强制条件，尺寸模式只由同一编辑会话的显式选择决定；首次启动默认就近紧凑面板。宽窄/文字缩放只参与边界夹紧、字段重排与正文滚动，不修改用户选择。

展开/收起仍使用同一字段实例、taskId/版本/脏草稿和既有离开前保存协议，不能调用重新载入/保存或丢失选区。扩大窗口不自动展开，缩小窗口或150/200%文字不禁止收起。当前进程内保留用户的尺寸选择；重启默认紧凑。就近模式继续真实锚点、来源不可见降级、手柄移动与屏内夹紧。极小可用空间下两种外形可能接近，但收起后保留日期摘要及自然高度，不留伪失效按钮。

展开形态采用居中的可读内容列：头部、错误、页签、正文与子任务列表共享同一列，正文上限640×文字scale DIP，外壳仍受主内容区约束。标题/备注与分组共用内容轴，标题区域只保留少量纵向留白，去掉“日期与时间”重复标题/双分隔，时间与分类标签以单条分隔和属性行表达。字号/色彩/圆角沿UX-48，不引入页面专属字体或重型框线；正文单轴按需滚动，头部退出/尺寸切换/错误始终可达。

原生截图发现CurveRenderer初始主窗图标缺失，尺寸切换虽可点击但不可见。共享Glyph使用Qt GeometryRenderer及有界4样本图层做兼容绘制和抗锯齿，保留原创路径、线宽/颜色和软件裁剪；实际像素检查覆盖尺寸按钮，按截图物理尺寸/窗口逻辑尺寸映射坐标，避免假定grabWindow的DPR元数据必然一致。原生/离屏及浅深大字截图另验，不能仅凭按钮对象存在判为可用。

复用contextual_workspace的真实首开流程：880宽首次紧凑→点击展开→1280宽仍展开→Space收起；再在880宽/200%深色展开与收起，验证可见几何、内容列、同taskId/版本、脏标题/选区和最终一次保存。补截图复看普通/大字/浅深，原日历日期选择/子任务/保存失败路径保留。task_list_interaction沿用既有布局/页签/锚点及大字回归，不增加重复CTest或放宽预算。构建/lint/完整测试记录真实结果；Windows仅出本地预览便携包，macOS没有实机不能称已验证或提供macOS二进制。
