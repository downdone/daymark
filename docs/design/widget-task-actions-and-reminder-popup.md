# UX-69 小窗直接操作与到期提醒

2026-11-03，FR-001/012/014/026/033/043、UX-01/04/07/09/11/13。遵循P-02/03/05/07/13～20，HIG的直接操作、上下文菜单、通知中的简明内容与就近操作；参考来源为[上下文菜单](https://developer.apple.com/design/human-interface-guidelines/context-menus)与[通知](https://developer.apple.com/design/human-interface-guidelines/notifications)。截图仅参考操作机制，视觉沿用Daymark。

## 操作契约与实现前评审

- 小窗底栏“添加任务”切换为原位单行输入，Enter新建今天任务，成功清空并保持输入，Esc空输入退出；空输入失焦退出录入以恢复原收球条件；非空草稿不因失焦、自动收球而丢失。写入期间禁重复提交，失败保留文本/原位错误。创建不读取主窗当前范围、搜索、分类或标签，不唤起主窗。
- 今日任务左键查看、完成圈只完成；标题区超过系统阈值拖动，目标行显示落点，释放提交，Esc取消。拖动边缘自动滚动，并暂停后台同步应用，结束/销毁恢复。右键/Menu/Shift-F10提供详情、置顶、特别关注、上/下移、取消提醒、完成、删除。删除为软删，含子任务须确认，并提供原位撤销；完成沿用整树规则。
- 小窗排序总是使用完整Today投影，独立于主窗范围和筛选。复用同父/同置顶组及时间分区规则；具体时段按时刻排序，跨合法今天/今晚分区沿用原业务命令，不把拖动伪装成改时间。CAS/写入失败不预改模型。
- 独立实体置顶提醒窗，主窗隐藏时仍显示；不主动抢输入焦点、不自动消失。显示任务名、原定提醒时间、待处理数量；提供查看、完成、关闭、延后10分钟。一次只呈现一项，队列最多投影10项并显示总数量，逐项处理，不生成弹窗风暴。
- 任务提醒的到期认领/去重/周期仍以SQLite事实为准。关闭与延后只是**本机弹窗展示状态**，按数据库文件隔离保存到本机QSettings（只存身份散列、时间及动作，不存标题）；不改任务提醒时间或周期锚点，不同步到其他设备、不加入任务JSON。写失败保持弹窗并给出可重试错误。重启恢复最近24小时未处理项及有效延后项；已完成/软删/取消提醒/重新安排的旧提醒不再显示。旧版提醒历史升级后也可进入待处理队列。
- 系统通知沿用现有独立设置；新增“到期弹窗”默认启用，可独立关闭，关闭弹窗不等于完成任务。应用退出期间无后台保证，恢复/启动重新认领。到期轻量检查每秒一次，仅到期时运行既有工作线程维护；编辑期间也不能无限推迟已到期提醒。

布局使用共享字体、32 DIP命中和实体菜单，错误不靠日志。小窗输入/菜单/确认/拖动阻止自动收球；菜单挂于稳定Window根，不能继承任务淡出。提醒窗浅深色、100/200%自然高度并限制到可用屏幕，正文必要时滚动；Tab/Enter/Space、Esc关闭当前弹窗及完整可访问名称。

## 测试与边界

临时库集成验证主窗在搜索/分类时小窗创建及排序不改主窗状态、重载顺序、非法分组、CAS失败、置顶与整树软删/撤销；提醒认领、重复周期锚点不变、关闭/延后持久化、重启/切换资料隔离、完成/取消/改期清除旧弹窗、超过50项历史与10项显示上限。纯逻辑测试注入时间，不等待10分钟。真实QML合成指针/键盘覆盖原位输入、右键实际命令、拖动、Esc、隐藏主窗提醒与200%布局。Qt6.10.2 Release/lint/CTest及Windows原生截图分别记录，macOS/物理DPI/读屏保持UNVERIFIED。无编译脚本修改、默认发布或真实用户数据测试。
