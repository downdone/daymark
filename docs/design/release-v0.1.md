# v0.1核心能力交付计划

用户要求实现全部核心能力并发布v0.1。本轮持续推进已有M0～M7需求，不将版本号变更当成功能完成。

## 顺序与门禁

1. VERIFY：托盘与外部穿透恢复、几何/模式设置，代码与测试通过，真实桌面恢复待验收。
2. IMPLEMENTED：项目/领域/Heading、标签和Checklist、Tonight与排序已实现并通过测试。
3. IMPLEMENTED/VERIFY：CalendarService、月/周、改期与联动；真实拖动手感待人工验收。
4. IMPLEMENTED：重复实例、提醒持久认领与应用内回退。
5. IMPLEMENTED：JSON导入导出、备份恢复/每日快照、10k性能；8h稳定性UNVERIFIED。
6. DONE（本地范围）：UI基准组件、最终部署包、SDK路径隔离启动和记录完成；按用户后续指令不进行GitHub发布。

每批先设计接口与失败状态，再实现、build/CTest并更新PROGRESS；数据模式变化只新增migration。所有自动测试用QTemporaryDir，原生交互与macOS未测保持UNVERIFIED。8h稳定性不能以快速smoke替代。

## 窗口切片交互

设置增加穿透、锁定、背景透明度、位置重置和关闭到托盘；穿透只有托盘可用且外部解除动作已注册才允许。托盘菜单始终提供打开主窗、显示隐藏组件、解除穿透、退出。无托盘关闭直接退出且不能启用穿透。退出仍走草稿保护和worker排空。

QSettings保存在当前数据目录的ui.ini，测试不写系统用户设置。保存DIP位置、大小、屏幕标识/DPR及归一化位置；屏幕移除/geometry改变时钳制到可用区域，提供显式重置。mini保持独立布局与floating尺寸。启动安全默认不恢复穿透状态，避免后台无恢复通路。

## 日历切片契约

FR-010/011；CalendarService输出ISO日期、6行月格或7日周列；标记start/deadline/both由C++合并。日期索引避免42次全表扫描。改期一次版本化TaskService命令只改所选字段，合并标记须明确选择；跨月改期使用日期弹窗。创建按date上下文一次事务落库。月/周、周首日、今天/翻页和日任务侧栏接同一workspace；周首日保存在当前数据目录。测试覆盖闰日、跨年、周首日、双标记合并/拆分、冲突回滚、Someday隐藏；拖拽与真实交互待后续验证。

## 组织与详情切片契约

领域/项目/Heading/Tag使用CatalogRepository与CatalogService，所有SQL仍在persistence。删除项目事务内解除任务project/heading，转ACTIVE并保留日期；删除Area清项目所属与直接任务归属；项目完成不完成任务，通过查询隐藏。任务详情一次版本化命令保存归属、标签、清单、今晚和提醒，先验证完整候选再事务写；Checklist只软删，完成主任务不勾清单。Tag用Unicode casefold规范键。

UI通过独立“组织管理”面板创建/改名/状态/删除，删除/完成显示影响说明并确认；详情提供归属/Heading选择、标签多选、逐项清单。先保存一个详情命令再关闭，失败保留草稿。导航增加领域/项目/标签列表。不把组织操作SQL或项目有效状态判断放QML。

## 重复与提醒切片契约

FR-014/015；RecurrenceRepository保存规则与幂等实例，RecurrenceService负责本地日历计算。固定规则最近30日至未来30日滚动补全；月末缺日跳过。模板编辑软删明天起未手改的实例并重新生成匹配日期，不覆盖历史/今日/手动改动。停止规则保留实例，可明确选择软删未来实例。完成后N日按完成时间的当前本地日期计算；相同occurrence唯一键禁止重复。

TaskRepository事务认领到期提醒，更新版本和fired时间；所有已触发提醒可由数据库重建到应用提醒中心，托盘只尝试提交一次汇总（至多10条标题），不能证明系统实际送达。每30秒后台检查，启动检查遗漏，睡眠恢复后下次tick补查；应用未运行不承诺后台通知。本地日期时间输入拒绝过去及DST不明确/不存在的时间。测试：固定规则/月末/闰年/周间隔、幂等、手改保护、完成后生成、重复认领与完成抑制。

## 发布边界

用户最初授权发布v0.1，后续明确“先交付本地版本”。本轮只交付本地Windows包、源码与Git提交，不推送或创建GitHub Release。禁止把真实数据库、私人日志、Qt SDK或构建缓存纳入源码。本机包内仅部署所需运行库，不代表公开再分发授权已审查。macOS实测/签名、8h稳定性和真实OS交互未满足时必须披露，不能称完整双平台V1已验收。
