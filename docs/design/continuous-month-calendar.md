# 连续月历、直接时段新建与紧凑侧栏（UX-35）

2026-10-25用户追加，基于UX-34。涉及FR-034/035、UX-01/02/04/05/07/09/11/14、P-13/14。先保留统一任务/范围、保存门、CAS与已有验证，再分片实现；实际状态只见PROGRESS。

1. 日视图：空白时刻单击打开就近新建；拖选范围带起止预览，释放打开同一新建器。Enter/添加才持久化，取消零新增。小时轴仍按真实分钟/DST边界，任务身份与列表统一。
2. 月视图：滚轮连续浏览周，不整页截断月份；相邻月份接续、有清楚月份标题、每周只出现一次。已有跨周/月条、定时标记、详情/拖动/菜单及议程保留。虚拟化可视周，仅保持当前附近有限月份；接近边界后平移窗口并按周日期/偏移恢复，不在QML计算时间或查询任务。
3. 架构：C++只读适配生成唯一周模型；共享月格组件负责日期/条绘制，连续列表负责滚动/月份定位，CalendarPanel仅接线与命令门。禁止另造任务筛选或复制第二套月格算法。打开年视图仍不物化全年实例。
4. 侧栏：分类列表取消默认额外间隔，分区收紧；一级/二级文件夹及16步长保留，行命中不小于32，200%自然增高。设置/备份只留两个相邻图标，悬停及键盘焦点说明、可访问名称、原入口功能均保留。

验收：日空白单击与45分钟拖选、取消不写；跨月滚轮不重复周/不跳回，滚动月份标题正确，边界回收与返回定位，跨月任务条连续/详情同ID，100%/200%/浅深/键盘；分类拖放/右键/重命名、底部图标可见命中；Debug/Release、lint、原生截图及短跑。真实触控板惯性/物理辅助技术单列UNVERIFIED。

实现接口：`CalendarMonthStream`拥有约四个月周列表，接近上下边界后平移一月，始终以周起始日期和相对偏移恢复；`CalendarMonthGrid`供连续列表重用，不再在CalendarPanel内保留第二套网格。列表刷新按代次、尺寸、文字大小合并；数据未变不重置模型。可见首尾周经`requestCalendarSpan`生成本地循环实例，最大70天并两端补7天，防止全年物化。取消/拖动/失败保存、旧跨月条及独立日历范围继续按UX-34。

过程失败保留：虚拟化后旧固定一帧断言先于布局完成，增加可观察的WAIT状态并继续受原watchdog约束；旧回调读取新缩放导致定位回月初，改为捕获布局代次与尺寸；一周delegate初始32高裁掉标题，改为真实最小行高；合成滚轮补齐有效phase/angle/timestamp，按实际跨月条件等待，未降低版本/可见月份断言。纯投影临时库测试覆盖跨月周唯一、闰日、跨周条数量与只读版本；新增独立场景覆盖正反回收、单击创建/取消和图标入口。

原生复验追加：后台范围加载期间的导航在完成后执行；虚拟化日期项不能因回收后重新获得程序焦点而改写用户选定日期，仅明确点击、方向键或Tab导航更新选择。月份内选日后切换日视图保留该日，实际点击新建和月周回收用独立临时库探针验证。
