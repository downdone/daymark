## 信息架构与范围

收集箱及五个自动视图位于导航顶部，用两列六张紧凑卡片显示名称、图形和数量；其下为分类和标签两个独立分区，只包含自建资料。收集箱是未分类任务的默认列表，日期与分类互不排斥。分类仍为两级文件夹；标签不形成层级或替代归属。最近删除在导航底部独立进入。日历是同一批任务的时间视图，保留固定位置的列表/日历切换图标。

| 面板 | 精确范围 | 分组与子任务 |
|---|---|---|
| 今天 | 已到开始/截止日、已到的日程/提醒或兼容旧关注的未完成活动任务 | 全天、上午、下午、今晚；只显示独立匹配的条目。蓝色子任务数量打开原任务的子任务tab，不添加不匹配的子项。 |
| 计划 | 具备开始、截止、日程或提醒日期的未完成任务 | 此前安排、今天、明天、近日期及未来月份；不设未来30天截断。 |
| 全部 | 所有未完成、未归档分类的任务，包括旧暂停任务 | 按分类路径分组，未分类为收集箱；可显示/隐藏子任务及逐父项折叠。 |
| 特别关注 | 标记特别关注的未完成任务 | 精确匹配，数量链接查看子任务。 |
| 完成 | 已完成且未删除任务 | 按完成月份，行上显示完成日期时间；可以重新打开。旧已取消内容在页面菜单的历史记录中保留入口。 |
| 分类、收集箱与标签列表 | 分类/默认归属/标签匹配 | 保留树状层级、统一缩进和L线；匹配子任务只出现一次。 |
| 最近删除 | 软删任务 | 按删除日期，同次删除的父子项形成展开树，恢复按钮不编辑任务。父任务恢复同次删除的后代；单独恢复子任务时若父项仍被删除则移为根任务。 |

智能视图中的子任务独立参与筛选与数量，不受普通列表的子任务显示偏好或父项折叠影响。搜索保持全局任务搜索（完成、历史及最近删除分别限定其范围），不补入不匹配的子项；搜索时也不因全局隐藏子任务而漏掉匹配内容。QML不自行判定时间或拼接数据，规则集中QueryService；工作区提交后刷新整个受影响集合，再向界面报告成功。

日期与提醒不从父任务继承。计划日期与占用起止时间保留各自意义，循环与提醒周期在原任务中编辑。界面移除混合归属和状态的“收集箱/可执行/以后再说”选择及额外关注分段；安排今天直接修改日期。已有暂停任务保留历史事实，详情显示暂停提示和恢复安排动作，不静默恢复提醒。

## 父子操作

完成父任务完成所有未完成后代；重新打开只打开同次完成的成员。此前独立完成的子项仍完成。删除父任务前明确确认整树软删；取消零修改。父项与本次删除的后代在最近删除可一并恢复；此前已删除的子项保持删除。分组ID持久保存，不用相同时间戳推测归属；重启及JSON往返仍可恢复。

移动分类联动全部未删除后代，已完成后代也跟随；移动一个子任务到不同分类则从原父项中移出，并带走其后代。新设父任务时同步其分类。日期、提醒、旗标与标签不隐式继承。循环子任务未来实例使用现有父项的分类；父项已完成或删除时不继续在其下生成。所有命令单事务、源版本及每次写入CAS，中途失败回滚数据、版本及编辑记录；批量含重叠父子项按祖先优先处理。

## 紧凑布局与管理

普通行40DIP起，标题13、元信息12，上下内边距4，完成/详情命中区至少32，200%按内容自然增长。简易编辑不改变父子列和L线；空白点击先保存，失败保留草稿。备注悬停仍可查看完整文字。末行不画多余分隔线，选中/悬停/键盘焦点不叠画线；鼠标焦点不产生多余空框，键盘焦点保留；悬停提示使用统一浅深配色。

移除分类/标签标题两处常驻管理省略号，保留加号与展开。条目右键或键盘菜单提供编辑、分类升降级/移动/上下移、归档与删除。常用属性在锚定小面板编辑，明确保存/取消；失败保留输入，Esc脏草稿需放弃确认，窄窗和200%内部滚动。分类标题右键提供已归档分类入口以恢复；集中管理页仅保留恢复及兼容用途。分类拖动边缘排序/中央归属及原图标不变。
