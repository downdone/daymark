# UX-46：桌面就近面板精修

2026-10-27；FR-035/037/041、UX-01/05/07/09/10/11/12/14、P-07/09/13/14。依据用户macOS截图提取视觉关系，实际状态见PROGRESS。

## 原则与范围

HIG[Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)强调聚焦相关操作、箭头指向来源、避开必要内容，关闭按内容/保存语义决定；[Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields)强调字段用途、清晰输入与平台习惯。Daymark保留原子草稿、失败保留、外部结束编辑保存、新建显式取消及拖选一次选入；不增加关闭确认或改任务模型。

当前问题是外框/每字段深边框、嵌套卡片、冗余分组标题、标题/备注/属性间距不成体系。精修覆盖日历新增、共享任务详情、时段选择小窗与其共用字段；普通设置/数据表单继续既有显式框，不把所有输入去边框。Windows仍使用系统标题栏/平台键盘，独立绘制资源，不复制Apple专有资产。

## 视觉与布局契约

- 外壳：统一内容色，14 DIP圆角、1 DIP细轮廓和低透明柔和阴影。增强对比保留明确边界、不依赖阴影；减少动态不引入弹簧。只在真实来源在面板外、可正确指向时显示小箭头，手动拖动后不留假箭头。源项保持原选中反馈。
- 新增：首行小型“新任务”拖动区及取消/添加，下面突出任务标题16及单行备注13，取消始终显式放弃。字段正文13、标签次级色，内容轴一致；去除大块灰底和白色卡片嵌套，使用组间12/16留白及细分隔。内容自然高度，超高仅正文滚动；头部/错误/提交保持可达。
- 属性：日期/时分同一行、开始结束同列，日期/时段/重复/提醒一组，分类/标签另一组。小面板用紧凑标签列，宽窄/200%自然换行；已有时段直接入口保留。普通字段透明底，悬停轻底，键盘/输入焦点明确轮廓；非编辑状态不连续堆叠深色矩形。菜单选择与输入同样字级，不继承标题粗体。可点击/可输入通过标签、图形、值、悬停和键盘语义共同表达。
- 共享详情同一外壳和属性表达，备注保持透明、标题不画贯穿全宽的编辑下划线；展开/收起保留同一草稿，父子/历史/错误链不动。时段小窗沿用同一外壳，精确输入仍清楚、时间轴对齐并保留全部小时。
- 旗标/置顶这类独立布尔属性保持可识别开关与状态，不仅靠颜色；图标使用现有原创系统。按键命中不因视觉收紧而低于32 DIP，正文和标签不靠缩小字号实现密度。

以上色值/间距为Daymark自主设计，不冒充Apple固定标准。不增加模拟系统玻璃或额外大模糊，保证可读、透明组件背景及Qt6.10.2软件回退可用。
