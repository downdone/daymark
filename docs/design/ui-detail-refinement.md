# UI-09：详情、任务工具区与日期输入

对应FR-001/002/007/010/012、UX-01/03/04/05/06/08/09/11/13。依据既有UI基准，保持显式保存、草稿离开保护和C++日期校验，不变更schema。

- Today默认只保留标题、录入和概况。搜索、筛选通过有文字的工具入口展开；有筛选时保留提示和清除入口。刷新与多选放入页面菜单。拖放提示只在拖动任务期间出现，避免被误认为按钮。
- 详情使用紧凑正文和日期分区；删除/取消放入更多菜单，底部仅返回/保存。归属、标签、清单保持可达。备注可编辑、正文可滚动，200%回退覆盖详情。
- 日期字段本身可手输，点击打开非模态日历，日历不抢走文本编辑焦点；Alt+Down打开，Esc/Enter关闭，选日/今天/明天/清除只改草稿。手输错误交由现有C++校验，不偷偷修正日期。日历改期和事件日期复用同一控件。
- 菜单显式测量文字宽度、对齐右侧入口，使用独立Popup.Window避免小组件内部裁切；长项换行，菜单内容超高时滚动，保留穿透恢复说明。

验证：构建/CTest/lint；隔离数据原生合成检查日期选择、手输保留、快捷日期/清除、草稿保护、页面工具操作、右边缘菜单项目文字及几何；默认/880窄窗/200%及260宽组件截图。合成调用不代表物理输入法、读屏或真实用户验收。
