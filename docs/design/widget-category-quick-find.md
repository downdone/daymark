# UX-72 · 小窗分类快速检索（设计评审稿）

2026-11-04。范围规则已获用户确认：**分类默认显示全部未完成任务，可在设置中改为只看今天。** 本文件描述开发方案，功能尚未实现；不以设计稿代替Qt/平台验证。界面预览见[三联图](../../assets/design/widget-category-quick-find/preview.png)，可编辑SVG及绘图源同目录。

关联FR-012/026/043及拟新增FR-044，沿用UX-09/10/11/13、P-02/03/05/07/13～21。HIG映射：内容优先（常用入口克制、正文不被挤窄）、一致性（主/二级分类同一语义）、用户控制（范围明确、草稿和失败有恢复）、适应性（停靠/缩放/键盘）。不照搬参考产品的折纸外形、配色或通知红点。

## 1. 范围与核心规则

| 入口 | 内容 | 快速添加 |
|---|---|---|
| 今天 | 现有Today投影，与分类范围设置无关 | 未分类，安排到今天，沿UX-69 |
| 一级分类 / 全部未完成 | 自己及二级分类中的未完成任务，包含未安排及将来任务 | 直接归属该一级分类，不自动安排今天 |
| 二级分类 / 全部未完成 | 该分类自己的未完成任务 | 归属该二级分类，不自动安排今天 |
| 分类 / 仅今天 | 上述分类集合与现有Today投影的交集 | 归属所选分类，安排到今天 |

“全部未完成”复用主窗分类未完成范围，不能误用`effectiveActive()`将SOMEDAY等仍未完成任务过滤掉。完成、取消、软删、归档分类及远端删除待处理的任务依现有QueryService隐藏；Today继续复用既有日期、逾期及计划状态判定，不在QML重写。列表保持小窗的扁平任务行，子任务通过父任务摘要表达；每个匹配任务ID只计一次，不虚增父级占位行。计数与实际列表使用同一投影和参数。

分类快捷栏只提供检索入口，不改变分类树，也不改变任务归属。主窗的当前分类、搜索、标签、视图及编辑会话不被小窗切换修改。会话内按分类身份＋范围记住滚动锚点/选中任务ID，切回时恢复；任务已移除则选择邻近合法行，范围改变不套用另一范围的像素位置。跨重启只恢复有效浏览上下文，不逐帧写滚动位置。

## 2. 快捷栏与分类选择器

小窗Panel增加附着在正文外侧的窄快捷栏，和正文同属一个Window，统一处理层级与输入区域。保留“今天”、最多默认3个常用一级分类及“分类…”入口；首次按当前分类顺序初始化，之后由用户固定/取消和拖动排序，不随任务数量自动重排。不自动固定所有二级分类。常用较多时只滚动中间分类段，“今天”和“分类…”固定；滚轮只滚动入口，不自动切分类，且与正文任务滚动区互为同级。无分类时不显示空快捷栏，“分类…”仍能说明当前无分类并引导已有分类管理。

按钮横向显示简称并自然省略，不旋转中文或按单字竖排。选中态使用现有selected底与accent标记，不靠四色背景区分。数量按当前分类范围统一计算，0项仍保留入口。截断文字区可显示完整路径提示；按钮可访问名称始终包含完整路径、数量和当前范围。

“分类…”在小窗附近打开实体选择器，不跳主窗口：顶部“搜索分类名称或路径”，中部共享两级树，行左侧选择分类，右侧“常用”开关管理快捷入口。名称点击后切换并关闭；常用开关只改变快捷栏，保持选择器打开。搜索只查分类名称/路径，首版不增加第二套任务全文搜索。可直接固定二级分类；同名子分类以完整路径补充。常用快捷的排序独立于全局分类排序。

默认显示快捷栏，可在设置关闭。关闭只收起附着栏，分类选择仍通过标题的分类入口和组件菜单可达。首次初始化与手动清空常用列表分开记录，不能把用户清空后的列表重新自动填满。

## 3. 空间、三种形态与输入

正文记忆尺寸保持，快捷栏增加外侧宽度，不从任务行里扣空间。正常56 DIP，200%文字时约96 DIP；具体值用现有字体测量验收。沿既有`growLeft`停靠方向，右侧停靠时栏在左侧，左侧停靠时栏在右侧，向屏幕内侧展开。只在拖动结束并改变逻辑停靠方向时换边，不随hover和内容刷新翻转。只有屏幕容不下“正文最小260＋快捷栏”时回退标题分类选择器，保持正文可用。窗口设置需区分正文尺寸与含快捷栏的原生总尺寸，旧记录按原正文尺寸迁移；不能把总宽反复回写为正文宽，导致每次重启继续变大。输入mask覆盖正文与快捷栏的实际可点击区域。

Panel稳定展开后才显示并启用快捷栏，球/小窗动画期间不抢占输入；Mini显示当前分类/范围、数量与首项摘要，不展开第二条分类栏；球保持轻量图标入口。若用户禁用Panel，Mini/球仍可通过菜单选分类，但不能借此偷偷启用Panel或显示一条独立悬浮栏。三形态共享同一浏览上下文，借用小窗及自动收回只改变形态，不重置分类。Mini/球右键菜单增加一个“分类：当前名称…”入口，复用同一选择器，不改变前三个形态命令顺序，不新增第四种组件形态。

组件设置新增“分类检索”组：分类任务范围（全部未完成/仅今天，默认前者）、显示分类快捷栏、常用分类与顺序。范围设置统一作用于所有分类入口；“今天”入口始终表示Today。Panel标题为分类名称＋匹配数量，副标题明确“全部未完成/今天”，一级有子分类时补“含子分类”。不能仍标“今天”却展示整个分类。

选择器/菜单打开时沿UX-71隔离底层任务、拖动和形态输入；关闭恢复。Tab进入快捷组，方向键只移动焦点，Enter/Space切换；选择器支持搜索、方向键、Enter和Esc，关闭恢复触发位置。快捷排序另有右键上移/下移及移除，不能只提供拖动。提示、空态、错误与高对比沿共享样式；减少动态时立即切换。

## 4. 草稿、任务命令与异常

- 输入第一段非空标题时固定`draftContext`。切分类/改范围前，空草稿直接切；非空草稿先按原上下文保存，成功再切，失败保留原分类/文本及可重试错误。保存中禁重复提交，后续切换意图按代次处理，不能把A中输入的任务悄悄存到B。归属与日期使用`createWithDetails`同一事务，禁止先建任务再补分类。
- 完成、置顶、特别关注、软删/撤销仍走既有业务命令。排序使用当前明确上下文及完整合法排序集合，保留未显示任务的相对顺序；沿同父/置顶/日期分区与CAS限制。不能把现有Today重排方法用于分类全量。
- 拖任务时禁止通过悬停分类自动切换；首版不支持把任务拖到快捷栏改分类。快捷入口拖动只排序本机快捷列表，不改变分类层级和全局顺序。
- 改名/移动分类按稳定身份更新名称与路径，选中上下文不丢失。归档分类在快捷栏隐藏但保留常用身份，恢复后按原序出现；当前分类归档/删除时回到今天并给出简短原因。删除移除无效快捷身份，遵守现有分类删除保留任务的规则。
- 完成最后一项保留所选分类并显示“该分类暂无未完成任务”或“该分类今天暂无任务”。取消固定不切换当前内容；当前分类未固定时，“分类…”入口承接选中状态。
- 登录、退出、切换资料时，先沿现有草稿保护门，再加载对应本机资料的浏览偏好；不得把上一账号的分类ID/标题带入下一资料。同步期间的删除/重命名沿相同失效规则。

## 5. 工程接口与数据

窗口几何仍由`WidgetViewModel`管理；新增独立`WidgetTaskContextViewModel`管理检索与本机偏好，不向窗口控制器塞任务查询，不修改主窗`TaskWorkspace.view/search`。`TaskWorkspace`仍持有唯一业务缓存并发布一致的只读快照。QML只呈现模型、发意图，SQL仍在Repository。

```cpp
enum class WidgetContextKind { Today, Category };
enum class WidgetCategoryRange { AllUnfinished, Today };
struct CatalogRef { QString kind; QString id; }; // 兼容现存area/project存储身份，UI仍只叫分类
struct WidgetTaskContext {
    WidgetContextKind kind = WidgetContextKind::Today;
    std::optional<CatalogRef> category;
};
struct WidgetBrowsePreferences {
    int formatVersion = 1;
    WidgetCategoryRange categoryRange = WidgetCategoryRange::AllUnfinished;
    bool showQuickRail = true;
    bool shortcutsInitialized = false;
    QList<CatalogRef> shortcuts;
    WidgetTaskContext lastContext;
};
```

建议接口：`chooseContext(context)`、`setCategoryRange(range)`、`setShortcut(ref,enabled)`、`moveShortcut(ref,target)`、`createTask(title,draftContext)`、`canDropTask(context,id,target)`及`dropTask(context,id,version,target,targetVersion)`。具体Qt Q_INVOKABLE转换放适配边界，内部保持强类型。暴露`tasks`、`shortcuts`、`contextTitle/rangeLabel/count`和`pending/error`；一次成功投影一起更新标题、计数和内容，不能把新标题配旧任务。

分类范围由Catalog树解析到标准查询身份集合，随后复用`QueryService::select/inView`：AllUnfinished沿现有分类规则；Today做同一分类集合与Today的交集。不要简单将分类ID塞进现有`projectFilter`而丢失一级直归/area兼容语义。父子分类遍历与时间判定只在C++。旧`todayTasks`继续服务原今日语义；新的`widgetTasks`供三形态共用，不把原todayTasks改名后改变其语义。

偏好按本机资料隔离保存到版本化QSettings，不迁移任务数据库，不改同步协议，也不默认上传偏好。写失败保留可浏览的内存状态并明确“偏好未保存，可重试”；恢复读取最后一份有效状态，无效ID回退今天。新旧异步结果带profileEpoch/queryGeneration，快速切分类或资料后丢弃旧结果。时间跨本地午夜按已有时钟刷新Today交集，不用24小时定时替代日历日。

计数在业务缓存变化/范围改变时由C++统一投影，不在QML逐分类全表扫描，也不每秒重置快捷栏。10k数据评测切换延迟与帧阻塞，目标可见切换p95<100ms，实际测量后决定是否需额外缓存；不预建索引服务或另一套查询框架。

## 6. 开发切片与验收

1. 纯查询/上下文：一级直归＋子分类、二级、未安排/将来/SOMEDAY、完成/取消/软删/归档、Today逾期与跨日、重复实例去重；主窗搜索/分类不受影响。
2. 偏好和资料：首次初始化/手动清空、改名/迁移/归档/删除/恢复、损坏文件/写失败、重启与账号隔离、过期异步回调。
3. 原位命令：分类与日期原子新建、原草稿上下文绑定、切换保存失败、完整上下文排序与CAS、软删撤销、主窗隐藏仍可操作。
4. QML/原生：快捷选择/常用管理/搜索、Mini/球上下文一致、菜单无穿透、关闭恢复、键盘/Esc、长名称/空态/浅深/100～200%、四角停靠/窄屏回退与减少动态。

所有自动数据库使用QTemporaryDir。按单切片推进，先验证查询和隔离再接快捷栏；现阶段只交付设计及图版，尚未修改widgetTasks、设置或业务行为。Windows/macOS、物理DPI及读屏各自记证据，不把设计图当平台通过。
