# UX-45：今天入口与直接时段选择

2026-10-27用户追加；FR-028/032/034/035/038，UX-02/03/05/06/07/09/11/14，P-02/04/05/07/13/14。状态及证据仅记PROGRESS。

## 问题和原则

今天列表切日历仍保留旧浏览日期，导致目的地名称与日期脱节；具体时间藏于类型菜单，常用操作不可发现。依据HIG[直接操作与macOS习惯](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[就近面板](https://developer.apple.com/design/human-interface-guidelines/popovers)及项目已有[日历契约](macos-calendar-interaction.md)，让日期导航表达用户意图、核心时段直接可见；渐进显示仅保留时区/提前提醒等次要选项。独立实现资源，复用全局字级、圆角、颜色、命中及草稿保存规则，不引入另一类日程对象。

## 日期与时段操作链

- 从今天列表进入日/周/月日历时锚点回本机今天；普通分类仍保留上次浏览位置，日历内主动翻页/切尺度/改范围不被刷新强制拉回。年入口沿用UX-44。日周时间轴首次加载且含今天时定位现在，其余日期从工作时段开始；普通刷新保持手动滚动，显式“今天”可再次定位。
- 任务详情与展开形态直接显示“时段 / 选择具体时段…”，不再通过“类型→全天”寻找。已有时段显示起止摘要，可一键重选；选好后原开始/结束行直接显示可输入的时分。原行编辑也提供时钟入口，新建任务复用同一组件。
- 点击在来源附近打开日时间轴小窗：显示开始/结束日期与HH:mm输入，以及当前日已有安排的只读背景。单击预览一小时；拖动沿用日历吸附及边缘滚动，释放有效范围即选入当前草稿并关闭；手输可精确到分钟，按完成/Enter选入。Esc或点击外部取消此次选择，不改变打开前草稿；取消拖动不提交。不会弹出新增任务表单，也不写占位任务。
- 选择的日期/时间/时区/跨午夜统一由C++解释。背景基于全部任务避免遗漏冲突，不扩大主日历的任务范围，不更改主窗或独立日历锚点；排除正在编辑任务的旧时段，允许重叠。跨日原时段保留日期，拖选明确替换为所选日范围；结束午夜映射次日00:00。DST日按真实分钟轴绘制，不用固定24小时秒数；无效或不唯一时刻保留输入并明确提示，最终保存仍经现有服务/CAS校验。
- “改为仅日期”作为时段旁就近菜单的次要动作，清除具体时间保留日期；时区和提前提醒原能力保留。选择时段不改变关注、提醒、循环、分类/标签及其他草稿。任务原有离开前保存规则不变，不增加“使用时间→使用时段→保存”三重确认。

## 布局、键盘和边界

小窗首选约440 DIP宽、随文字与可用高度调整；主操作/日期输入与时间轴分层，边缘向上/向内避让；200%窄窗可滚动表单，时间轴独立为本次范围选择提供24小时可达视口，不在常驻详情嵌入第二滚动轴。取消/完成始终可达，浅深/增强对比复用token。键盘Tab到日期/时间直接输入，Enter完成，Esc只取消当前选择；输入错误不提交，焦点与来源恢复。背景任务不可误编辑/拖动/删除；辅助名称使用当前日期/用途，长摘要按全局截断提示规则补全。

## 用户追加：直接排期、关注和批量删除

- 日期任务条单击选中后，显示“为某任务拖选时段”及键盘替代的选择时段按钮；在日/周轴的一个日期列内拖选释放直接安排这项任务，未选任务时仍新建。按下时捕获taskId/rowVersion，取消不写入，失败保留目标和错误，不创建副本。已有时段继续原移动/端点；更多日期任务中的单击也能选中返回时间轴。主/独立日历走相同离开保存和CAS门，范围不扩大。一次拖选绑定一项选中任务；点选其他任务可继续安排。
- 原行工具加旗标，Ctrl+Shift+F（macOS由Qt映射⌘⇧F）切换特别关注，菜单显示同一快捷键。编辑时改当前草稿；浏览时改当前任务；多选时有任一未关注就全部关注，否则全部取消，只改选中项。菜单/选择器/设置等模态上下文禁用，普通文本删除键不被批量命令抢走。
- 多选工具栏、集合右键和Delete（macOS Backspace）均进入同一个紧凑删除确认，显示去重后的实际影响数量，包含当前所选父任务的存活子项。单事务预检全部选中版本，父先子后，已由本批父级删除的子项不重复处理；任意失败整批回滚。记录本批实际新删除的组与版本，撤销只恢复本批，不恢复此前单独删除的子项；撤销遇修改冲突不覆盖他人变化，最近删除保留长期恢复入口。沿用已有schema和删除组，不引入硬删。
- 加测主体：TaskService原子删除/冲突/注入失败、TaskWorkspace批删撤销/旧删除子项隔离、旗标只改选中；UI探针覆盖集合入口、键盘与文本保护、连续多任务排期、拖选失败/取消/单击不提交。用户追加范围仍以本轮PROGRESS统一记录。
