# UI-07 全界面视觉统一规范

沿用[UI基准](ui-baseline.md)，本轮将目标落实到全部可用页面。保持信息优先、轻量连续表面、单一蓝色强调、系统字体；原生窗口边框及系统托盘菜单遵守平台，不仿制另一系统。无新增图像资产或第三方依赖。

## 统一元素

| 元素 | 规则 |
|---|---|
| 表面 | 主内容白/深灰，侧栏低一级，输入白/深灰，弹窗同主内容；1px弱边界 |
| 排版 | 正文14，次级12，区块15 semibold，弹窗18 semibold，页面26 semibold；均参与文字缩放 |
| 间距 | 4/8/12/16/24/32；表单字段间12，区块间24，弹窗内边20 |
| 按钮 | 普通中性描边、主要蓝底、工具透明底、危险红字；主提交每区最多一个；文本决定宽度，常规高36起 |
| 输入 | 圆角6，内边10～12，默认描边，聚焦蓝色2px；提示/选中/禁用一致 |
| 选择 | 下拉框单箭头、选中列表；勾选框18起、统一勾线；滑杆和数值步进同色同圆角 |
| 弹窗 | 圆角12、统一标题/内边/底部按钮区；宽度随可用空间，正文滚动，底部主要动作始终可达 |
| 列表 | 导航/任务/管理列表共享选中与焦点语言；完成圈和行操作分离；不使用大块通用按钮作为任务行 |
| 状态 | hover弱填充、pressed加深、selected浅蓝、focus清楚轮廓、disabled降低文字对比但不整页降低opacity；错误保留文字提示 |
| 日历/组件 | 日历延续同一表面与选择；组件独立背景alpha，文字不透明，Mini和浮窗使用同一工具按钮 |

UI-08组件密度修订：浮窗工具区使用WidgetAction，默认32DIP命中区、16DIP图形，表头单排；主窗普通按钮继续36DIP起。统一颜色、焦点与图标语言，组件采用适合低干扰场景的密度。见[组件与日历评估](widget-calendar-review.md)。

## 实施接口

DaymarkStyle是仅展示层的Qt Quick Controls样式模块，基于QtQuick.Templates，未定制类型回退Basic。DesignTokens是颜色、字体、尺寸来源；既有Theme桥接模式/文字缩放，业务QML仍调用原C++命令。选择Qt自定义样式使标准确认按钮、菜单内部生成控件与显式控件都采用同一外观。

页面按工具栏、过滤/录入、正文、反馈分层；管理表单采用同一字段间距、区块标题与底部提交。常用操作优先，危险和维护操作下沉但保持可达。标题不再放大成默认Basic宽按钮，日期按钮、图标命中区按同一token计算。

组织与重复规则共用响应式模式：可用宽度小于640×文字缩放时上下排列，列表区100高可滚动，编辑区使用剩余高度滚动；宽窗两栏。保留同一表单实例和草稿，变化仅影响布局。表单操作行按宽度换行，主要保存/返回固定在底部。

## 验证

每个切片构建及CTest；样式模块和应用分别qml lint。使用已有真实临时库smoke覆盖所有功能页、标准确认弹窗、菜单/下拉、默认与200%文字、浅深色、1120/880/1440、Floating/Mini。截图用合成任务；视觉检查不冒充读屏/输入法/鼠标真实验收。

样板页StyleGallery仅由合成验证入口打开，包含普通/主要/轻量/危险/禁用按钮、聚焦输入、菜单勾选项、下拉选项、勾选框、滑杆、数值步进及成功/错误文案。smoke调用真实下拉delegate的clicked并检查选项与弹层关闭，验证勾选切换与数值增减；这不等于物理键盘输入验收。手动触发editingFinished不会完整模拟Qt输入事件，不能据此证明数值键入路径。

Windows复现：设置DAYMARK_QT与DAYMARK_MINGW后运行`./scripts/build-windows.ps1`、`./scripts/test-windows.ps1`，再运行`cmake --build --preset windows-debug --target daymark_style_qmllint daymark_qmllint`。以windows原生后端运行`daymark.exe --smoke-test --screenshot <合成PNG绝对路径>`输出各页和ui-style/ui-menu/ui-choice/ui-style-dark/ui-style-200截图。自动smoke使用临时目录，不加载用户库。

macOS保持`bash scripts/build-macos.sh`入口；当前无机器，构建与全部平台体验UNVERIFIED。系统文件选择器、窗口边框、托盘菜单保留原生样式；自定义QML样式不替换这些系统界面。

后续UI-12对密度数值及应用图标作修订，见[整体精修](ui-polish.md)。本文件早期36DIP/26DIP等数值保留为历史设计；新实现以UI-12与共享token为准。
