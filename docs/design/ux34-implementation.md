## 用户可见行为的取舍

- 日历菜单不提供隐藏全部任务的无意义开关，年视图不放仅对任务绘制有效的选项；周的日期标题进入对应日，日期任务溢出在内部列表查看。
- 日历任务保留单击直接详情，减少查找成本；小时块单击选中，信息/双击/Enter进入同一面板。双击不是唯一入口。
- 未安排侧面板通过按钮开启，不启用关闭状态的抽屉边缘手势，避免遮挡其他页面的右键/点击。拖动预览不写入，Esc取消，失败回原值。
- 小面板并不删属性：日期、时区、提醒、循环、分类、标签、父子、编辑记录都仍可达；200%或窄窗展开同一会话。
- “年”首先负责导航；不显示不完整的负荷统计，不因浏览写入一年的循环实例。循环任务生成与重复提醒保持不同含义。
- 系统辅助偏好仅合并平台确实可读取的项。真实系统通知送达、物理键鼠/IME/辅助技术、多屏睡眠、8小时稳定性和Windows实机结果仍需各自证据。
