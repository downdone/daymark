# UI-11：紧凑滚动与备注输入

FR-007/018、UX-05/09/11/12。针对用户反馈的大幅慢回弹、短备注仍出现内部滚动和焦点切换后滚动目标混乱。

- 统一ScrollView和显式列表/正文的运动策略：边界停止，最高惯性速度1200DIP/s、减速度6000DIP/s²；不添加弹簧或延时回弹。数值为Daymark设计选择，不是Apple/Things测量值。
- 内容在视口内时关闭拖动/滚轮滚动和不必要滚动条，长内容才启用。键盘导航独立保留。下拉框和数字框的滚轮不修改值，滚轮用于页面滚动。
- 备注随内容自然增长，不建立内部Flickable/ScrollView，不在短文本里截获滚轮。光标可见性仅由外层正文负责；焦点字段已在视口内时不改contentY，手动滚动不重新吸回焦点。
- 宽窄、200%、空/短/长备注均检查；合成滚轮验证页面位移而非字段内部滚动/选项改变，检查短正文不可flick与所有应用滚动面边界策略。保留草稿、事务保存与日期语义。

截图中的独立“归属、标签和清单”弹窗属于早期结构；当前实现沿用UI-10统一面板，不恢复二级弹窗。原生物理触摸板/IME/读屏/macOS需另外验证，不能用合成事件冒充。
