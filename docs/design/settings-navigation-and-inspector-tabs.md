# UX-47 设置层级与详情页签

2026-10-27；FR-035/037、UX-01/02/05/09/10/11/14，P-13/14。

## 依据与问题

Apple HIG的[Settings](https://developer.apple.com/design/human-interface-guidelines/settings)用于全局偏好，[Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables)用列表表达设置层级、以chevron表达进入下一层，[Segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls)用于少量紧密相关的内容/选择。项目自主定义尺寸、色值与资源，不复制系统资产。

现状：设置四类导航与主题选项均用同一种分段控件；正文FormGroup背景与页面相同，层级不清。桌面小窗/日历、外观/辅助功能在长列表中缺少稳定分组，动作像任意按钮拼接。任务详情分段占满全宽，选中框过重，没有与属性输入区形成清晰关系。

## 本轮设计

- 设置首页为分组目录：外观、桌面组件、通用、关于，分别有原创图标、短摘要和进入箭头；不使用分段选项作为主导航。保留现有四页索引兼容，首页为-1。进入页后固定顶部返回和当前页名，返回恢复目录滚动/原来源焦点；Esc先返回目录，再关闭窗口。关闭按钮与原生标题栏保持可用，重新打开保留最后位置。
- 子页采用iOS式内嵌圆角分组：页底灰、内容组白（深色反转），组名在组外，行内细分隔，注释在组下。外观分显示/辅助功能；桌面组件分任务显示/任务交互/独立日历；通用分启动/提醒/备份/资料帮助/退出。不新造账号、同步或未实现选项。
- 行标题左、选项右；开关切换布尔值、下拉选离散值、滑杆调连续值，数据/帮助等导航采用整行chevron；重置这类就地动作无chevron，退出使用危险色。桌面组件的显示状态改为开关，展示形态用明确的“小窗／迷你条”值选择。不透明或增强对比启用时背景透明度禁用，记住原值而不显示可操作的无效选项。置顶与固定桌面保留原互斥服务及穿透恢复限制，辅助功能偏好保留真实有效状态。错误仍可见，更改立即保存，不增设假保存按钮。
- 默认窗宽600、高640DIP起，受主窗口限制；正文单轴按需滚动。大字号/窄窗行内选项自动堆叠，标题/返回/关闭保持可达；焦点进入被遮挡项自动揭示。
- 任务“详情／子任务”使用独立内容页签：居中且宽度受限的轻底胶囊、细选中面、13字级、正常选中字重变化，32DIP起命中，默认/悬停/按下/焦点/禁用明确。使用PageTab语义、左右/Home/End选择、活动页签为Tab停靠点；切换仍通过原selectEditorTab保存门，写失败不错误切中。不改全局主题/日历分段样式。
- 无额外页面进入动画，不增加菜单等待；保留任务同一草稿、父子返回、正文滚动和设置原服务/失败反馈。
