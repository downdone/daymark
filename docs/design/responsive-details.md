# UI-03A：共享草稿的响应式详情

对应M3-01、FR-007及UX-02/04/05/07/09。单个详情面板复用现有标题/备注/规划/日期状态与TaskWorkspace命令，保留显式保存。窗口宽度扣除侧栏、440 DIP列表、详情和边距后仍足够时，详情停靠右侧、非模态，正文为它预留空间；否则居中模态覆盖。字体缩放参与宽度预算，窗口调整只改变呈现，不重载草稿。

切换任务/视图、新任务快捷键、打开管理工具、重新加载及任务状态/归属/排序操作统一走navigateSafely。脏草稿显示保存/放弃/取消；取消保持任务和输入，放弃不写库，保存失败保持原上下文，保存成功后才执行目标动作。目标状态操作重新读取task.rowVersion，避免保存先推进版本后使用旧版本。

详情内部字段按窄列上下排布，日期各有标签与选择/清除操作；底部动作可换行，内容可滚动。Esc与返回使用同一草稿保护，完成控件仍不打开详情。日历保留覆盖详情，避免挤压七列网格。

验证通过真实应用的临时库smoke扩展，覆盖停靠/覆盖、大字、窗口往返、切任务/导航/完成的保存/放弃/取消、失败草稿以及数据库实际结果。截图为合成数据；不以Qt方法调用替代原生读屏或系统焦点验收。
