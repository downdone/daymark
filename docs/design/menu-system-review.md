# UX-55：全菜单的语义分组与平台一致性

FR-002/012/024/025/035/038，UX-01/05/06/07/09/10/11，P-07/09/13/14。基于[Apple Menus](https://developer.apple.com/design/human-interface-guidelines/menus)及[Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)：相关命令相邻，组间分隔，状态明确，名称说明结果，子菜单克制，图标有目的。同组不混用随意装饰；Windows托盘保留系统QMenu，macOS菜单栏保留原生角色，不把QML皮肤强加到系统菜单。

## 统一规则

- 顺序为主要动作→状态/标记→安排/整理→危险动作，各菜单按实际职责取子集，不为单一同类选择硬加线。
- 分隔线只隔语义组；动态隐藏后不出现首尾线、相邻双线或空组。单独禁用说明可作为组的可见内容，危险操作最后独立。
- 名称动宾明确。继续询问输入的动作使用省略号；显示设置/详情本身不机械加省略号。显示/隐藏使用结果动词，布尔属性用勾选，不把“显示/隐藏”同时写进标题。
- 文字、勾选、快捷键和子菜单箭头独立列；同组默认不额外添图标。快捷键只展示真实可用的组合，不注册第二个抢焦点的快捷键。
- 沿用正文正常字重、共享菜单圆角/实体底、单一高亮、禁用对比、32起命中及200%可滚动；鼠标/键盘/取消/外点与原草稿保护不变。恢复入口不可被整理掉。

## 全量清单与分组

| 入口 | 语义组（分号为分隔） |
|---|---|
| 任务列表单项 | 详情/完成或重新打开；置顶/特别关注/取消提醒；移到/今天今晚/清日期；适用的排序；删除 |
| 任务列表多选 | 集合摘要；完成/重新打开；分类/日期/标签/特别关注；删除 |
| 最近删除 | 多选摘要（适用时）；恢复；不提供再次删除或编辑 |
| 详情更多 | 编辑记录；放弃草稿（适用时）；取消任务/删除 |
| 分类/标签右键 | 重命名/编辑；新建子分类/移动层级；适用的排序；归档；删除 |
| 侧栏分区 | 新建；归档管理。只有一个动作的管理/标签/分类新建菜单不加线 |
| 页面更多 | 选择；重复/编辑当前分类标签；重新加载 |
| 日历显示 | 跳日期；未安排/当天议程；已完成/周首日；桌面日历 |
| 日历任务 | 详情/完成或重新打开；置顶/特别关注/取消提醒；删除 |
| 跨日条 | 调整开始/结束日期，同组无分隔 |
| 时段选项 | 改为仅日期；时区/提前提醒（不同职责） |
| 标签选择 | 已有标签/空态；新建标签；原勾选/新建草稿协议保持 |
| 重复/其他下拉选项 | 不重复、周期预设、自定义分隔；其他单一维度选择保持连续。日期/时间/时段选择器属于编辑面板，不伪装成命令菜单 |
| 小窗/Mini组件 | 打开主窗；桌面固定/置顶；锁定/穿透；外观设置；隐藏 |
| 桌面日历设置 | 当前透明度及互斥数值；固定/置顶；重置位置 |
| 托盘右键 | 打开/新任务；组件显示或隐藏；穿透状态/明确恢复点击/重置位置；设置；退出 |
| macOS原生菜单栏 | 应用关于/设置/退出分组；文件新建保存/数据；编辑撤销重做/剪切复制粘贴/全选；视图模式/日期导航；窗口主窗侧栏/桌面日历 |
| 文本编辑上下文菜单 | 保留Qt系统剪切/复制/粘贴/选择命令和平台剪贴板，不另建动作语义 |
| 样式样板 | 与真实菜单同样分组，保留禁用例子 |

## 验证责任

共享菜单验证实际可见顺序/分隔，包含隐藏全部中间组和连续候选分隔；task_list_interaction复用单/多/已完成/最近删除与快捷键状态，calendar_interaction复用日历菜单，desktop_surfaces复用透明菜单及设置。托盘在无托盘环境也构造真实QMenu，widget_window检查菜单顺序、动态文字/勾选、恢复禁用/可用以及恢复点击动作，不伪造OS托盘存在；不增加重复CTest。标准Qt6.10.2 Release构建、双lint、关联CTest和浅深/200%截图。Windows Shell托盘呈现、macOS原生菜单外观/辅助技术仍需平台实测。
