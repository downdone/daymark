# UI-10：单一任务编辑面板

需求FR-002/007/008/009/014、UX-01/04/05/06/07/09/11。用户反馈隐藏菜单项留白、基础详情与归属弹窗割裂、宽窄窗滚动与焦点混乱。本设计替代UI-03A/UI-09的任务覆盖弹窗和二级详情入口；保留日期选择器、离开确认和其他管理工具。

- 同一个Pane承载完整草稿。宽窗右侧并排；窄窗替换主内容区，保留导航和返回，不再打开任务详情模态弹窗。调整窗口不改变字段顺序、内容、草稿或滚动位置。
- 标题、备注、规划、日期、归属、标签、清单、提醒、关联事件、只读信息按顺序常驻。无标签/清单展示空态。字段全部纵向排列，不因断点改变展开状态。
- 面板头部与返回/保存固定，正文只有一个显式Flickable；备注随内容增高、清单使用自然高度，无内部滚动列表。Tab进入视口外字段时由同一个正文滚动到可见位置。
- 基础字段与扩展字段提交一个TaskPatch，经TaskService.edit完成一次CAS和事务；任何字段无效、版本冲突或持久化失败全部零修改、草稿保留。旧saveTask/saveDetails入口兼容其他命令，不连续调用它们伪造整体保存。
- 切任务、导航、事件关联、关闭共用同一个保存/放弃/取消保护。删除仍软删并支持撤销。
- 不适用的菜单项高度归零、不参与宽度预算；相邻有效项紧密排布。

验收：完整草稿成功/非法日期或提醒/关系失败/陈旧版本的原子性；标题与清单一起保存/放弃/取消；宽窄往返草稿/滚动不丢、单一正文、键盘焦点自动可见；1120/880/1440、200%、长备注/多项清单；不在Today的任务菜单无空行。Debug/Release、CTest、QML lint和Windows隔离合成截图。真实IME/读屏/macOS仍单独验收。

实现细节：焦点可见性在布局重排后的16ms单次调度中处理，备注光标独立映射到同一正文；单一滚动条位于面板右侧。offscreen没有活动窗口焦点，自动测试仅直接验证滚动目标，真实QQuick焦点断言在Windows原生运行执行。列表分组采用固定viewSection投影，避免隐藏列表期间切换section.property。

V-02W稳定性复测中，正文改用显式Flickable以明确控制内容尺寸；布局polish后核对焦点字段的正文坐标及视口尺寸，仅在几何变化时追随，手动滚动不重置。后台维护保持表单可编辑，写入仍互斥。保持同一草稿、顺序和固定操作区，按UX-05/09/11重新验证原生焦点与200%。原生测试必须使用已呈现窗口；隐藏启动造成未呈现的布局结果不能算用户可见界面验收。
