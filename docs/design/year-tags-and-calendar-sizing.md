# UX-44：年定位、就近标签菜单与日历尺寸

2026-10-27；关联FR-012/034/035/040、UX-02/05/09/10/11/13/14、P-04/07/09/13/14。状态与证据只记PROGRESS。

## 系统分析及原则

截图中的年入口只改变日期，没有同步可见区域，违背导航反馈；标签把摘要、复选框、展开按钮和第二列表重复铺开，破坏内容优先与空间稳定；无框日历仅右下角隐形小区域可缩放，缺少可发现性和键盘替代。保持共享任务、草稿、日期语义与窗口层级，不新增数据模型。

依据Apple HIG的[菜单按钮](https://developer.apple.com/design/human-interface-guidelines/pull-down-buttons)、[单选按钮菜单](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)与[窗口](https://developer.apple.com/design/human-interface-guidelines/windows)：多标签不是互斥单选，采用带勾选的命令菜单；内容随窗口尺寸适应，缩放交给Qt系统窗口交互。桌面组件保留已接受的透明无框形态，不把它解释为所有窗口都应自绘系统装饰；主窗口仍保留平台标题栏。以下尺寸为项目值，不是Apple强制标准。

## 交互与视觉关系

- 年入口显示本机今天所在月份及日期，初始布局完成后再定位，不夺取输入焦点。月份能放下时优先完整展示该月；窄窗大字号必须滚到月内时，在顶部保留同一行的月份标题，避免日期失去语境。显式“今天”和年导航可重新定位；数据刷新、保存标签和状态更新不反复改用户滚动。月份/日期双击钻取、方向键与PageUp/Down仍保留；键盘移动才主动转焦点。单日只在所属月份高亮。
- 标签行只有标签摘要按钮（无选择时“选择标签…”），点击在其旁弹菜单：既有标签按现有目录顺序显示，选中项打勾；末尾分隔线后是“新建标签…”。零标签显示禁用空态再提供新建。每次选择更新当前草稿并关闭菜单，无第二确认；不隐式保存整个任务。Esc/外部点击只关闭菜单，恢复来源焦点。与原行、展开详情、日历新增共用同一菜单，避免嵌入第二个常驻滚动区域。
- 长名称换行、长菜单限高并滚动；优先在来源按钮下方展开，空间不足向上，极小窗口才限制到屏内。摘要截断时按全局提示规则悬停补全文字，菜单打开时抑制。字体/圆角/分隔/选中/焦点/禁用复用全局Menu。多选以勾显示，不依赖颜色。新建沿用已有资料创建事务及错误保留；成功仅选入当前草稿，取消任务不删除已创建标签。
- 独立日历四边/四角可拖动调尺寸，光标方向与边一致；右下角有轻量尺寸手柄，支持Tab到达及方向键16 DIP、Shift+方向键64 DIP调整。最小420×480，内容自适应/滚动，不缩字体。尺寸和位置沿用现有独立WindowStateStore保存及屏幕规范化；透明度只作用背景，置顶/桌面层与小窗互不影响。

## 验证矩阵

复用calendar_interaction：年入口实际视口含今天、布局晚到/200%/窄窗、显式今天重定位、状态刷新保持手动滚动；独立日历重复同验并保留模式隔离。复用task_list_interaction：标签选择/取消、分隔线及末尾新建、取消新建/成功选入、离开保存及重开、浅深/200%菜单边界。窗口四边四角几何/光标/命中和键盘尺寸由QML探针验证；WindowStateStore临时设置库测试尺寸恢复、不串主窗。真实系统拖动、实际DPI/多屏/读屏及macOS另记原生/UNVERIFIED，不以offscreen替代。构建、CTest、lint、文档/颜色守卫；完整旧失败保留。
