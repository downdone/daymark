# 桌面任务组件：形态、定位与交互统一方案

2026-10-30，用户已确认 / IMPLEMENTED（平台验证边界见PROGRESS）。设计契约不表示已经实现或验收；既有v1.8.0行为及发布标签不改变。覆盖FR-012/013/018、UX-09～14，依据P-07/09/13/15/17。经确认后取代compact-desktop-surfaces中形态与锚点规则，保留其减少动态/失败回滚/数据安全要求。

## 1. 现状分析

已读WidgetViewModel、WidgetWindow、QtWindowPlatform、SettingsDialog和WidgetWindowTest。问题不是只缺一段动画：

- 球并非独立形态，而是mini与miniCollapsed/autoCollapse组合；QML又有miniWantCollapsed、miniReveal、键盘保持等状态，切换意图与动画完成分散。
- 球上只有点击展开，没有自身拖动处理；悬停开始变形后才可能碰到Mini拖动区。Mini摘要同时负责点击展开/拖动，还有重复展开按钮，点按与移动边界不清。
- changePresentation先沿用当前左上坐标，再normalizeGeometry按当前形态挤回屏幕；保存读取实际窗口位置，屏边的临时避让可能成为新位置。现有屏边循环测试从大窗已经能放下的位置开始，未覆盖用户把球直接放到边角后再展开。
- 屏幕选择采用第一个与窗口相交的屏幕，跨屏时未按主要面积/拖动结束目标选择。
- 小窗宽度决定Mini宽度，两个视图的尺寸意图耦合；用户只想改小窗大小，也会改Mini。
- workspace全局错误会阻止收球，即使错误来自另一个界面。浮动层级以“置顶/固定桌面”两个互斥开关表达，锁定位置又容易被理解成固定显示形态。

## 2. 三种形态的必要性与边界

| 形态 | 主要任务 | 显示内容 | 建议定位 |
|---|---|---|---|
| 悬浮球 | 保留低干扰入口 | 原创图标、必要状态标记，不滚动播放文字 | 可选，不承担完整任务处理 |
| Mini条 | 工作时快速扫一眼 | 今天数量、第一项摘要、展开/更多入口 | 可选，独立于小窗尺寸 |
| 小窗 | 就地处理今天任务 | 列表、完成、添加及进入主窗详情 | 最完整形态，可由用户禁用并改用主窗 |

保留三者，但不能强迫每个人都使用三者。任何一种都可启用/禁用；不把“保留三种”解释为默认自动轮换。

默认兼容：Mini/小窗启用；已有“闲置收球”用户再启用球，其他用户保持球关闭。新用户默认小窗；不在此次重设计中悄悄改成收球。

## 3. 可用性、显式形态、临时预览分开

- enabledForms：任意子集，决定允许进入的形态。
- selectedForm：用户最后一次明确选择的形态，决定重启及恢复显示。
- effectiveForm：当前实际可见形态，包括自动收起和悬停预览；不因预览写回selectedForm。
- visible：用户显示/隐藏意图。enabledForms为空时强制有效隐藏，但保留最近合法选择，不能恢复时进入被禁形态。
- autoCompact：独立偏好。关闭后明确选择球/Mini/小窗就保持该形态；开启后仅Mini可在闲置时暂收球，球悬停可暂预览Mini。
- 通过菜单/设置明确选择的小窗保持常驻。从球或Mini点击快捷展开属于临时查看，保留原常用形态；鼠标离开且无操作后1000ms回到原停靠形态。键盘操作、菜单、拖动、业务提交和组件错误期间不自动收起。

不持久化动画进度、悬停、拖动/按下、菜单打开和键盘保持。

### 所有启用组合

| 启用集合 | 行为 |
|---|---|
| 球+Mini+小窗 | 三者两两直接切换；可选球与Mini自动收展 |
| 球+Mini | 两者直接切换；Mini不出现打开小窗的按钮，可明确打开主窗 |
| 球+小窗 | 球点击进入小窗，小窗可直接回球；无Mini悬停预览 |
| Mini+小窗 | 两者直接切换；没有球和收球定时器 |
| 仅球 | 固定球；点击打开主窗；无形态切换项 |
| 仅Mini | 固定Mini；点击打开主窗；无收球/小窗入口 |
| 仅小窗 | 固定小窗；保留任务操作，没有无效收起按钮 |
| 全禁用 | 隐藏组件、释放输入区域，停止定时器；主窗/托盘保留设置恢复入口 |

启用一种不应立即切走当前合法形态。禁用当前selectedForm时，优先恢复最近明确使用且仍启用的形态，否则按小窗→Mini→球取可用项；全部无可用项则隐藏。禁用正在预览的形态立即取消预览，回到合法选择。设置操作是单次状态提交，不能先生成被禁形态再修正。

## 4. 两两切换与操作入口

任何形态右键或Shift+F10都打开同一组件菜单，包含“切换形态”，列出所有已启用形态，当前项有勾选；两次点击内可直接到任一目标，不要求经第三形态。球不堆常驻按钮。

- 球：鼠标单击优先打开小窗；小窗不可用时进入Mini；两者都不可用时打开主窗。右键直接选择形态或打开主窗。
- Mini：摘要单击优先打开小窗，不可用时打开主窗。保留独立拖动区域和更多按钮；去除与摘要动作重复的展开箭头。回球可直接经形态菜单。
- 小窗：任务标题打开主窗同任务，完成按钮只完成；头部收起按钮回到最近使用的可用紧凑形态，无紧凑形态则不显示。更多菜单能直接选球或Mini。
- 键盘：Tab能进入所有可操作入口；Enter/Space按上述点击语义；形态菜单可键盘选择。Esc优先关闭内层菜单/输入，再从无编辑小窗返回紧凑形态，无可用紧凑形态则保持小窗；不把Esc等同于退出程序。
- 所有被禁目标的入口移除，菜单剩一个形态时不呈现空的切换层。形态是显示方式，“打开主窗”是另外一个明确命令。

## 5. 拖动与自动收展

三种都可拖动：球整个球、Mini独立握持区、小窗头部空白区。使用平台拖动阈值区分click与drag，进入拖动后取消本次click，释放不得展开/打开主窗。按下时冻结hover切换；拖动完成后在原形态稳定落点再恢复定时器。

可选自动收展参数为Daymark拟定值：球悬停连续150ms后预览Mini，160ms平滑揭示；离开连续600ms后收回球。Mini自动收球需球和Mini均可用。快速掠过不展开；快速反向只反转视觉进度，不累积几何。

菜单、按下/拖动、键盘操作、组件自身的未完成输入期间暂停自动收起。鼠标离开后不立即清除键盘保持，键盘交互结束/失焦才解除。悬停不激活窗口或抢输入焦点；明确点击或键盘操作才按平台习惯激活。

球与Mini只显示组件相关简短状态；其他界面的错误不能强制改变形态。错误不自动打开小窗；在当前形态提示并提供明确处理入口。减少动态直接到目标状态。

## 6. 统一定位：用户锚点与实际矩形分离

每个组件只有一个逻辑锚点，所有形态围绕它计算位置；不保存三套互相追逐的坐标。小窗和Mini分别保存尺寸，球直径由共享可访问尺寸决定，不记忆动画帧。

- 锚点保存屏幕身份、相对可用区域位置、参考角（左上/右上/左下/右下）及边缘距离。采用DIP，DPR不重复乘除。
- 初始化从用户所在位置选择增长方向：靠右向左，靠下向上。方向只在明确拖动结束、用户重定位或屏幕拓扑变化后重算；一次hover/动画/形态往返不改变方向。
- 切换保持同一参考角：左上保持左上，右上保持右上，左下/右下向上生长。这里“位置固定”指逻辑锚点固定，靠右展开时左边界按目标宽度改变是预期行为。
- 先由锚点和目标尺寸得到完整矩形，再在同一屏幕availableGeometry内避让。避让结果只用于本次呈现，不反写锚点；回球后回原落点，无累计漂移。
- 拖动结束才能写入新的用户锚点；屏幕热插拔/临时分辨率变化采用可恢复的备用落点，不覆盖原屏位置意图。目标屏幕按拖动释放时指针/窗口主要面积选择，不取第一个相交屏幕。
- 菜单按当前形态的真实按钮定位，屏边自动选择上下方向。显示菜单时冻结形态切换；移动/缩放/显式切换时关闭菜单，释放保持锁。
- 原生窗口一次提交目标矩形，内部做揭示/淡入；透明视觉空白不得拦截桌面点击。需验证系统窗口输入区域，不用opacity当穿透。

## 7. 设置、层级与恢复

设置分三块：允许使用的形态（三个开关）；自动收展（仅球和Mini都启用时可用）；位置与行为。

“显示任务组件”与“允许的形态”明确区分。三者全禁用时状态显示“未启用任何形态”，提供恢复默认；托盘“显示组件”遇空集合打开该设置，不擅自重新启用用户禁用的形态。

层级用一个互斥选项：普通 / 始终置顶 / 桌面层。“固定在桌面”改为“桌面层”，避免与锁定位置混淆。锁定位置仅禁拖动/缩放，切换形态、完成任务和菜单仍可用。

鼠标穿透属于高级行为，三者输入统一禁用且冻结自动收展，维持当前合法视觉；启用前关闭菜单。必须保留托盘/主窗恢复，重启恢复可点击。穿透期间球不会因鼠标悬停展开。

隐藏不改变允许集合、显式形态及锚点；恢复时使用selectedForm，不恢复半段动画或过期菜单。自动收球可在恢复稳定后再计时。

## 8. 工程边界与接口草案

沿用一个原生任务组件窗口；球/Mini/小窗为同一业务投影的三个渲染形态，不建三份Today模型。独立日历仍属另一组件，不混进此状态机。

- WidgetPresentationController：统一处理enabledForms/selectedForm/effectiveForm、显示、交互保持和事件优先级。输入SetEnabledForms、SelectForm、HoverChanged、Press/Release、DragStarted/Finished、MenuOpened/Closed、FocusChanged、Hide/Show；非法目标返回明确结果。
- WidgetPlacementPolicy：纯函数resolve(anchor,size,screens) → rect/targetScreen/fallbackReason；不读写QWindow/QSettings，可单测多屏/负坐标/缩放。
- WidgetGeometryStore：只存用户锚点、两个尺寸、允许集合及显式偏好；旧mini/autoCollapse与当前几何一次迁移，保留旧值供回退。不将本机设置迁移混入SQLite业务schema。
- QtWindowPlatform：执行单次目标矩形、原生拖动、窗口层级及输入区域；平台失败回滚状态和几何，QML显示可操作错误。
- QML：发输入意图并渲染只读快照，仅负责可取消动画；过期动画以transitionId忽略。动画完成只提交当前代次，不在QML重新决定形态。

优先级：禁用/隐藏及屏幕安全恢复 > 明确形态命令 > 拖动/按下/菜单/键盘保持 > hover与idle。新的明确命令取消旧动画；平台失败保持上一稳定合法状态，不能把偏好、实际窗口和菜单各留在不同形态。

## 9. 实施顺序和验收

1. 先确认本稿的形态必要性/可用组合、点击与回退语义；不先改动画数值。
2. 纯状态机和几何策略UT，再替换原布尔组合；关联测试保留原业务断言。
3. 接入三种拖动/菜单/焦点及配置迁移；再实现动效与输入区域。
4. Windows原生链验证后执行完整CTest，macOS分别原生验收；未测不标通过。

必测：8种允许集合及启用/禁用当前形态、6条直接转换、仅球/Mini点击主窗、全部禁用的托盘恢复；拖动不误点击/hover掠过/快速反向/菜单保持/键盘Esc与失焦；四角球原位放置后展开、大窗与小窗尺寸独立、50次往返无累计位移、多屏负坐标/最大面积选择/拔屏恢复；100/150/200%DPI与文字倍率分别测；Qt失败注入、设置写失败、应用重启、透明区域可点击底层桌面、穿透恢复。自动测试用QTemporaryDir，原生OS/多屏/读屏证据独立记录。

HIG映射：一致性→统一命令/状态反馈；用户控制→禁用目标不被自动进入/小窗不自动关闭；布局稳定→固定逻辑锚点；可访问性→焦点保持/键盘替代/大字/减少动态。来源为仓库ui-research所列官方HIG布局、动效及可访问性条目，本稿阈值与具体规则属于Daymark提案，不是Apple规定，也不声称当前实现已满足。

## 10. 实现对照

纯状态与几何策略分别位于WidgetPresentation.h、WidgetPlacementPolicy.h；WidgetViewModel作为唯一QObject协调器承载计时器、平台提交和QSettings v2存储，不额外拆空壳QObject。enabledForms/selectedForm/effectiveForm只读快照供QML；UI不判断任务归属。原生输入区域使用Qt QWindow.setMask配合圆角视觉区域，offscreen不调用无实现的mask而冒充系统证据。

保留setMini/setMiniCollapsed/setMiniAutoCollapse仅作旧探针兼容和旧配置过渡；正式界面使用selectForm/setFormEnabled/setAutoCompact。后者在球或Mini禁用时拒绝开启自动收展，自动事件也再次检查允许集合。旧配置键保留，widget/v2追加存储形态集合、显式选择/最近历史、两个尺寸、锚点与可见意图；短暂避让与动画进度不落盘。设置失败通过现有错误通路显示，不迁移业务库schema。

用户确认后本契约覆盖P-15历史“小窗/Mini共享宽度”的具体数值约定：同类动作保持稳定槽位，两种形态分别保留用户尺寸。窗口层级互斥、锁定/穿透恢复和键盘替代继续遵守原原则。

## 11. UX-65：球是停靠入口，点击为临时查看

2026-10-30用户修正：球的价值是用最小占用长期留在固定位置，需要时就地打开任务，用完恢复球。临时打开Panel不更新selectedForm、history或持久化偏好；effectiveForm决定眼前界面，temporaryOpen标记快捷查看。计时从鼠标离开、并且所有交互保持解除后开始，每次回到小窗/打开菜单/按下/键盘操作都会取消旧计时；满足条件1000ms后回selectedForm。停留在窗口内不按墙钟强制收起，避免打断操作。菜单/设置中的selectForm始终是明确更换常用形态，可取消待回球计时。

球禁用、展开目标禁用、隐藏、穿透和平台拒绝都不得留下非法临时形态；重启恢复停靠球，不恢复临时小窗。没有Panel但启用Mini时，球点击临时打开Mini，仍返回球；只有球时打开主窗。

原球位置在hover预览后仍应可点击打开任务。右侧停靠的Mini排列朝内展开（握持/入口在右，更多在左），左侧反之；预览握持区保留点击快捷展开，拖动阈值后取消点击。需要测试原全局点击位置，而不只调用控制器函数。

## 12. UX-66：球与小窗动效

球到小窗180ms，小窗到球150ms，使用OutCubic。背景沿原角锚点变化；小窗内容保持完整目标尺寸，只做裁剪与淡入淡出，不缩放字体、按钮或重排任务行。展开时间20%后淡入内容，收回时内容先淡出。悬停Mini后点击打开，在Panel能容纳当前Mini矩形时延续背景；Panel记忆尺寸更窄/更低时直接切换，避免目标原生窗口裁掉尚未收展的Mini。快速反向保留当前视觉矩形/透明度，以新代次接续；过期完成事件忽略。

展开先提交最终原生Panel矩形，再动画内部背景；收回期间保留Panel原生矩形，当前代次完成后才提交球矩形。输入mask随实际圆角背景更新，透明空白不占用输入。最后平台缩窗失败恢复此前合法小窗及错误提示。隐藏/禁用直接收敛，穿透前先完成当前目标；减少动态立即到目标，保留相同锚点与交互语义。直接Panel↔Mini保持原行为，Mini↔球沿用160ms揭示。

球↔Panel使用Qt标准ParallelAnimation/NumberAnimation及顺序淡入淡出组；代次改变后停止旧组，以当前视觉尺寸和透明度重新起步。完成、隐藏、禁用或失败收敛至稳定目标，业务状态与原生几何由ViewModel统一提交。探针通过afterAnimating采样实际插值状态，QQuickItem.grabToImage异步记录截图，不在动画前后同步grabWindow干扰默认GPU帧时序。

验收包括左右/上下锚点、中间帧背景尺寸和字体不变、双向反转与旧回调、闲置自动回球、减少动态中途切换、原生输入mask及失败回滚。HIG映射：连续性通过同一背景解释形态关系，用户控制通过可反向与不抢焦点，稳定布局通过角锚点/固定内容尺寸，可访问性通过减少动态和原有键盘路径。具体时长是Daymark约定。
