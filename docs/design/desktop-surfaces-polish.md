# UX-38 全窗口精修：主窗、今日小窗与迷你条

## 产品与HIG映射

先记任务，再添加可选属性；列表执行、日历安排，同一任务只有一份事实。主窗承担整理与完整编辑，小窗承担今日扫读/完成，迷你条承担摘要/展开。三者不是缩小后的三个完整应用。对应FR-012/013/018/034/035，UX-01/04/05/09～14、P-02/07/09/13/14。

参考事实：[macOS设计](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/)强调熟悉的平台交互和可配置窗口；[工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars)将常用操作就近组织；[滚动](https://developer.apple.com/design/human-interface-guidelines/scroll-views)要求清楚的内容与控制区关系；[提醒事项列表](https://support.apple.com/en-gb/guide/reminders/remn1d887139/mac)支持列表/分区并保持侧栏可恢复。以下具体尺寸和QML均为Daymark独立实现，不复制Apple资源，也不声称原生材质能力。

## 全面审视与取舍

| 表面 | 已有基础与差距 | 本轮处理 |
|---|---|---|
| 导航/主列表 | 已有智能范围、两级分类、Shift选择及关系图标；真实焦点/IME仍缺平台证据 | 保留范围语义与统一密度，不再增加导航入口；共享滚动条和工具图标状态统一 |
| 主窗日历/独立日历 | 共享日周月年与时间草稿；窄宽工具栏缺弹性，独立窗未跟随减少透明度 | 窄/大字下视图与日期导航分行；月格数量放不下时显示完整省略入口而非半个数字，提供全文计数/键盘/辅助操作；统一独立窗表面/置顶状态/实色回退 |
| 就近详情/新建 | 同一会话，时段摘要/起止同行已实现；完整会话解耦和首帧P95未闭环 | 保留草稿/错误/保存边界，避免本轮引入第二会话；性能问题继续单列UX-37C |
| 设置/组织/备份 | 已用共享行高、分组、标签；高风险数据动作需要文字 | 保留显式文字及确认，不以纯图标替换；共享工具按钮和滚动边缘跟随本轮 |
| 今日小窗 | 仅圆圈+标题，无时间/父子关系/完成反馈；标题拖动立即调用系统，锁定时产生无效错误；空态有重复添加 | 重建紧凑标题/滚动内容/单一底栏；显示已有时间摘要及关系；完成成功后短暂反馈，失败原位保留 |
| 迷你条 | 计数与标题同一句，整片只能拖动、点击不展开；错误不可见，放大可截字 | 独立计数+首条标题；正文点击/Enter/Space展开，拖动需越过阈值；错误有图形及可访问说明；无置顶按钮 |

## 完整视觉关系

复用UX-37D的13正文/14列表/12辅助/16标题、32最小命中。小窗标题与主窗工具栏同级，任务名常规字重，计数次级；默认不把每条任务做卡片。标题/内容/底栏共用12边距，列表文字与底栏动作对齐；分隔线只在内容边缘，滚动条仅真实溢出显示。悬停弱填色，键盘焦点描边，置顶有选中填色与checkable语义，完成圈填色+勾，不只依赖颜色。共享工具按钮圆角采用控件圆角，避免每个次级工具都像独立大圆按钮；迷你条外轮廓使用半高圆角，浮窗/独立日历用面板圆角。

小窗保留置顶/收起/更多三个头部动作；添加在底栏且只有一个入口，旁边打开主窗。更多含主窗、锁定、穿透恢复说明、设置、隐藏，去除与头部重复的置顶。空态居中说明、加载与错误独立；正文只有一条纵向滚动轴。透明只作用背景，solidWidget/高对比强制实色，正文和操作保持不透明。

迷你条默认仍约260×48，字号放大时按内容提高最小高度，不把用户完整窗尺寸覆盖为迷你尺寸。标题过长省略并提供全文tooltip/可访问名称。无任务明确“今天暂无待办”，加载不误报空。迷你错误不丢弃，可展开处理。

## 交互、失败与验证

点击完成立即提交同一C++命令；只有模型成功移除才显示勾选/短收拢，减少动态效果时直接更新。失败取消等待态、保留行并显示原错误。不以延时写库营造动画，不建立今日筛选副本。点击正文打开主窗同一任务；底栏创建沿用今日上下文；列表上下键/Enter/Space、Tab及菜单Esc可用。锁定只禁止拖动/缩放，保留点击与展开。

新增短独立桌面表面fixture，使用临时库，检查小窗/独立日历并存、置顶/迷你恢复、今日模型与完成同步、关系/时间、无溢出不滚动、长列表滚动、迷你点击/键盘、大字与浅深/高对比/实色、菜单宽度及窄日历布局。仍运行旧完整测试，不增加watchdog预算、不把失败隐藏。截图和合成指针不等于真实桌面置顶/穿透/读屏/macOS；未实测明确UNVERIFIED。
