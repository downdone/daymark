# UI-15：全界面动作图标与语义配色

FR-001/002/007/010/012/013/017/018/019/020/022，UX-01/03/04/05/06/07/09/10/11/13/14。先审计再修改；业务/草稿/命令不变，无schema及外部依赖。依据[HIG Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[Icons](https://developer.apple.com/design/human-interface-guidelines/icons)、[Color](https://developer.apple.com/design/human-interface-guidelines/color)与项目P-13。平台系统字体和原生窗口保留，图标原创线性绘制，不分发SF Symbols。

## 决策原则

仅图标限于上下文明确、常见且低风险的动作；不能靠tooltip才能猜到所有流程。新用户不熟悉的“跳转日期/桌面日历/预览恢复”保留文字。重要动作、结果、范围与破坏性行为不压成含混图标；标准对话框确认/取消不加装饰图标。选中状态用图形/底色/可访问状态，不能只改颜色。

所有仅图标动作32DIP起命中区、16–24DIP图形（200%命中区随之增大），同一1.7/24线宽与圆端点；需名称、hover/键盘tooltip、焦点轮廓、disabled状态，沿用同一命令。列表完成圆与行编辑仍分离。图文按钮共享ActionButton，6DIP间距；常规次级图文默认无填充，hover/pressed才出现表面，主要创建仍蓝色实底。

## 全页面动作审计与去向

| 页面/区域 | 仅图标 | 图标＋文字 | 保留文字 |
|---|---|---|---|
| 主窗/任务列表 | 侧栏、搜索、筛选、清除筛选、更多、快速录入旁添加、关闭错误提示、完成/恢复 | 批量修改、查看任务、继续加载、撤销删除 | 退出多选、各范围/选项、日期语义 |
| 侧栏/资料库 | 更多菜单入口 | 导航图标＋名称；普通图形中性，选中蓝色；标签/项目有语义色可保留 | 各菜单的完整动作文字，计数 |
| 任务详情 | 更多、清单添加/上移/删除（既有行内语境） | 需要进入完整操作的入口 | 保存、返回、保存后继续、放弃修改、取消离开；取消任务/删除任务菜单有文字 |
| 日历主/独立窗 | 前后翻页、显示筛选、置顶、设置、隐藏 | 跳转日期、桌面日历、新建事件、未排期、当天议程、撤销事件删除 | 今天、月/周分段、跳转前往/取消、确认改期；日期格数字不加图标 |
| 事件只读详情 | 无额外图标按钮 | 编辑事件/编辑整个系列（铅笔） | 关闭、范围说明；本次安排与系列起点不以图标替代 |
| 事件编辑 | 重新载入、解除关联 | 删除事件（垃圾桶＋文字） | 保存事件、返回、循环/提醒/时间与关联角色选项、删除整系列确认 |
| 组织管理 | 上移/下移排序（上下文有标题与提示） | 新建、删除 | 保存、返回、名称/颜色/类型/状态选项与二次确认 |
| 重复规则 | 无新增纯图标 | 新建规则、停止并删除规则 | 保存规则、返回、规则范围、日期、覆盖保护及删除确认 |
| 设置 | 无将多状态开关改成猜图 | 显示/隐藏组件、展开/迷你、重置位置 | 分类、主题/字体、置顶/穿透/启动/透明度等开关、提醒/备份选项 |
| 数据与备份 | 无 | 导出JSON/CSV、创建快照、预览JSON导入/快照恢复 | 仅添加/跳过相同ID、替换当前数据、备份警告、返回和双确认；不能只用上下箭头表示数据方向 |
| 批量修改 | 无 | 无（范围本身足够复杂） | 字段/动作、取消、应用所选范围 |
| 提醒中心 | 无新增（记录本身可点） | 无 | 触发记录、标题和时间、关闭及空态 |
| Floating/Mini | 加任务、展开/收起、图钉、隐藏、更多（既有，统一状态） | 无新增重型操作 | 标题/数量/任务摘要；Mini不新增图钉；菜单完整文字 |
| 日期选择器 | 上/下月、输入框日历 | 无 | 今天/明天/清除、日期数字和手输；不把清除日期误画成删除数据 |
| 标准确认/空态 | 无 | 由明确上下文决定，默认不盲加 | 确认/取消/关闭/保存与动态空态CTA；菜单保留文字，不堆每项装饰图标 |

不改变软件文件图标的原创标识和几何，本轮保留其品牌蓝；界面强调蓝与品牌蓝属同一色系但不同角色，不把所有图形和状态涂成品牌色。

## 色彩系统（Daymark自主值）

浅色：白色正文、#F5F5F7侧栏、#F5F6F8分组、#1D1D1F正文、#61646B次级文字；深色：#1C1D20正文表面、#16171A侧栏、#25272C分组、#F5F5F7正文、#B2B7C1次级文字。层次靠相邻表面/留白，普通按钮、导航图形和菜单不默认染蓝。

强调：浅#005BC4/白字、深#85B7FF/#102038文字；选中浅#E9F1FF、深#243C60。错误/破坏浅#BD2730、深#FF9BA2；成功浅#24734B、深#83D6AA。今日标记独立calendarToday浅#C9343F/白字、深#F58D96/#2D1017文字；不再借用danger职责。字段填充浅#F3F4F6、深#25282E，必要底线/控件边界浅#7C818B、深#828B99；装饰分隔浅#DDDFE5、深#3D4148不承担命中边界。悬停浅#ECEEF2/深#303238，按下浅#E2E5EB/深#3B3F46。

所有色值集中DesignTokens，Theme转发；标签/项目语义色亦在该处成对定义。默认、hover、pressed、selected、focus、disabled、error各自定义，禁用不冒充可点击；减少透明度仍走实色偏好，正文不随背景alpha变淡。目标普通文字4.5:1、必要图形/边界3:1；按实际相邻背景计算，不能仅以Apple参考当PASS。

## 验收与实现切片

1. 配色token/前景角色和共享图文按钮、原创图形；构建/CTest。
2. 全页面按审计表迁移，保留objectName/点击命令/菜单/所有草稿与恢复路径；构建/CTest/lint。
3. 原生默认/浅深/200%/独立420×480、图标可见性与名称/状态、纯图标点击原操作链和对比度复核；Debug/Release与严格本地部署。

macOS、物理DPI/IME/读屏、高对比及真实外部桌面输入验收保持UNVERIFIED。Windows命令scripts/build-windows.ps1、test-windows.ps1；macOS用bash scripts/build-macos.sh及ctest --preset macos-debug。

增强对比度为显式本机偏好（设置→外观）：文字/边界/选中及焦点蓝提高区分，浅深各一组，并临时使用实色组件/日历背景，关闭后恢复原透明度；不假称自动检测了Windows或macOS系统高对比。此偏好默认关闭，不改DB模式；重启持久化及无效值拒绝用临时库验证。

色彩复核入口：Windows `python scripts/check-ui-colors.py`；macOS `python3 scripts/check-ui-colors.py`。直接读取token，每组65个文字/边界配对，共260对；表面包含默认/悬停/按下/选中/字段，图形色及今日反色另检。禁用及装饰分隔豁免，透明背景不作任意壁纸对比承诺。增强对比度下滚动条取消淡化、滑杆轨道使用必要边界色，透明度控件暂不可调并有解释。
