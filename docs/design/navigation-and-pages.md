# UI-21：导航目的地与主内容页面

2026-10-24，依据用户侧栏截图反馈。FR-006/009/014/015/018/019/021，UX-01/02/05/07/09/11/14。保留业务、schema、离线和原子保存语义；默认单代理。

## 分析与HIG映射

现有“规划”同时放日历页面、重复规则模态工具、循环日程浮层和提醒历史模态工具，形似同级导航却有三种行为，工具没有当前选中态。项目分区在无数据时只展示“＋管理项目与标签”，混淆创建与管理。提醒数量是最近触发记录总数，不能当成未读。两套长期浏览/编辑列表装在弹窗中，遮挡导航并形成额外返回层级。

Apple HIG [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)将侧栏用于应用区域及顶层内容集合；[Modality](https://developer.apple.com/design/human-interface-guidelines/modality)要求模态有清楚收益、任务短而集中，并避免弹窗内再建一套应用。映射为：主要目的地进入主内容区、稳定选中/返回；周期任务与日程共享发现入口，保留不同业务含义；历史工具降低视觉优先级；仅短时输入、草稿离开保护和危险确认保留弹层。布局数值与Qt实现为Daymark自主设计，不声称原生Apple组件或认证。

## 完整操作链与布局

| 入口 | 目的地与动作 | 返回及保存边界 |
|---|---|---|
| 规划→日历 | 原主月/周页面 | 原行为与独立日历保留 |
| 规划→重复安排 | 主内容页内“重复任务 / 循环日程”分段；任务规则列表/表单，事件系列列表及摘要 | 分段切换、侧栏、返回及退出均保护规则草稿；事件沿用单项编辑和整个系列语义 |
| 工具栏铃铛→提醒记录 | 主内容页展示最近50条触发历史，不展示未读徽标 | 返回原内容；点击记录跳到同一任务/事件；无记录有真实空态 |
| 领域与项目/标签标题旁＋ | 归属区新建领域或项目，标签区单独新建标签 | 取消零修改；创建成功进入对应内容；不冒充选入任务草稿 |
| 领域与项目/标签标题旁更多 | 进入整理任务页并选中相应概念；已有项目页更多可直达当前项目 | 浏览列表与选择/新建编辑区；保存/失败/草稿保护、安全结束和删除确认保留 |
| 日历→循环日程 | 进入相同重复安排页并定位循环日程；桌面日历唤起主窗该页 | 不再从浏览列表叠加另一层浏览浮窗；单个事件编辑仍可临时呈现 |

主内容页保留侧栏与共同标题工具栏，管理页没有遮罩、浮窗边框或关闭叉。标题区提供返回原任务/日历的按钮；选中态与页面一致，隐藏侧栏仍可恢复。任务搜索/录入/多选只出现在任务页，不泄漏到管理页。页面表单未选择时显示空态和新建动作，不默认铺开空白高级表单。列表与编辑区在宽窗并列，窄窗/大字选中后使用完整正文编辑并提供返回列表，正文溢出才滚动，提交区固定。

## 状态及工程契约

Main单独保存当前工具页面标识，TaskWorkspace.view仍为最后任务/日历上下文，不向QueryService注入伪视图。所有用户导航统一经navigateSafely；组织/重复页草稿先处理，任务草稿仍走原保存/放弃/取消。进入相同目的地不重置草稿。子日期/菜单/确认打开时Esc先退出该层，页面Esc可经保护返回。写入忙碌防重复，错误与输入保留，成功仅以operationFinished为准。

默认/hover/selected/focus使用既有语义token；导航、图标动作均有名称/tooltip，Tab可达；空态提供当前任务说明，pending不丢输入，error可重试。组织和重复页面的内部确认框与其他页面共用Overlay，不能把页面可见当成模态阻塞。原任务草稿内“新建并选择”继续有效，侧栏创建使用明确的新建语义。

回归发现后台维护与长按手势的竞态：30秒维护将busy置true，原列表因此禁用行并取消抓取。TaskWorkspace新增仅GUI协调的interactionActive属性；任务按下至释放/取消以及清单拖动期间，后台维护合并延后，交互结束立即补做。显式写入仍走原busy/CAS规则，任务筛选与排序许可不变。临时库测试验证多次刷新只在交互结束执行一次维护；原长按/释放落库及Esc断言保留，不靠停掉维护或增加测试等待规避。

## 验证

先页面改造构建，再统一导航/日程入口与真实QML场景。保留原271阶段业务/滚动/草稿断言，增加页面切换不弹窗、稳定选中、无任务工具泄漏、规则/组织脏草稿取消与放弃、合并分段、历史入口、侧栏创建及就近管理。验证1120/880/1440、浅深/200%、固定保存区与几何；Qt Test/CTest、两项lint、颜色和本地文档链接。自动数据全部QTemporaryDir，真实库/既有进程不操作，不推送发布。原生截图与离屏分别记录；Windows未在当前Mac执行，物理键鼠/读屏/IME/多屏/8h不因合成流程通过而标PASS。

## 产品哲学复审

按[产品哲学](../product-philosophy.md)区分责任/结果的归属与横向标签：侧栏分“领域与项目”和“标签”，C++只读navigationCatalog将开放项目放在所属领域后并输出depth；独立项目保持顶层，归档/结束项目仍可从管理页恢复。标签保留PRD的全局开放任务目的地与上下文筛选。整理页面使用领域/项目/标签分段，项目分组嵌在项目内，类型不再作为四选一数据库表单暴露。标签分区展开偏好存既有ui.ini，不改schema。测试覆盖投影层级/历史仍在/标签独立/偏好重开、概念分段的脏草稿保护、创建语义与真实合成示例。

随后按用户“简约而不简单”约束，由[UI-22及全产品复审](product-experience-review.md)收紧呈现：页面标题为“整理”，概念说明仅在无数据空态出现；有数据时顶部新建，空数据时空态新建，编辑时不常驻另一个创建。空标签区不占侧栏，任务字段和整理页仍有入口。安全后果在相关选择/确认处说明，后台维护不冒充保存。此修订替代初版每页常驻解释，不改UI-21的归属、模型或导航保护。

明确放弃组织/规则草稿后退出编辑状态，再执行待导航动作；即使目标是设置这类短时弹层，关闭后也不会重新显示已经放弃的表单。拒绝放弃仍完整保留输入。搜索排序许可的即时通知与列表防抖分离，见[模块契约](contracts.md)。
