# 分类、标签及浏览交互统一设计（UI-28）

2026-10-25，用户要求系统重设计后实施。延续FR-024～030、UX-01/02/04/05/07/09/11/14、P-13/14；Apple HIG依据沿用ui-research的Hierarchy、Sidebars、Consistency、Agency、Accessibility。以下是设计契约，实际状态仅见PROGRESS。

## 一套归属，两种导航

分类是唯一归属，最多两级；一级汇总自己与二级的任务，二级只展示自己的任务。标签平级、多选，只增加横向查找条件。两个侧栏分区始终存在，空分区仍可新建和管理。

分类树由C++输出深度、上级名称、完整路径和子分类数量；导航、管理、新建的上级选择、任务归属均使用该投影，不在各页面重新拼树。侧栏一级有独立展开按钮，选择子分类时其一级可见；右键/键盘菜单或行尾选项可编辑、新建二级和调整层级。缩进配合展开和父级提示，不能只靠空格表达归属。

所有新建共用一个短表单：名称＋上级（一级分类/现有一级）。分区加号默认一级；一级上下文新建预选该一级；任务中新建仍只选入草稿。标签只有名称，不出现上级。管理页负责改名、归档、排序、安全删除，分类归属用明确的“移动/提升为一级”操作及结果预览；带子分类的一级不能降级，先说明需移走子分类。移动保留分类ID、任务归属及原有属性；删除分类保留任务，二级提升一级，确认中说明。分类不提供日期、执行状态和完成入口；历史元数据仅在兼容层保留，不显示旧属性面板。旧隐藏状态在管理中统一呈现为已归档，恢复后回到普通分类。全部分类统一文件夹图标，层级仅靠缩进和展开表示。

用户追加分类上下拖拽：UI29修订为行上/下各30%插入前/后，中间40%移入一级分类；不改变图标，采用插入线/移入文字预览。二级不能接收子分类，含二级的一级不能降级。服务统一校验、源/目标版本检查，Repository单事务完成移属及同级排序；失败回滚。任务拖放与分类拖放按来源类型分别识别，Esc取消分类拖动不落库。右键/菜单键/Shift-F10直接编辑、创建二级、移动/升降级、排序、归档/恢复、安全删除；标签只有平级操作。管理页保留用于集中查看及恢复归档，日常无需设置。

导航与管理使用相同选中对象。保存后继续选中结果，错误保留输入；新建、选中、切换类别、移动和离开均经过已有草稿保护；不以无关后台catalog成功重置表单。归档/历史分类仍能在管理找到，任务归属显示完整路径。

## 列表父子与简易编辑

查询服务仍唯一决定视图成员。父子同时命中时紧邻成树，左侧展开按钮有子项数量和可访问名称，默认展开，可独立收起；只命中子任务时显示“父任务：名称”，不补入不命中的父任务。子项沿用最上层可见父任务的分组标题，避免今天/今晚或日期分组把树拆散。父子独立完成、置顶和日期，父任务收起不改变视图成员判定或数据；搜索时展开命中结果。完整子任务管理仍通过详情/子任务tab。

用户追加明确列表内退出即保存：点击空白、另一任务、导航或关闭主窗时，未改动直接退出；有改动先通过同一原子命令保存，成功后执行原目标动作；保存失败保留输入、原编辑面板和焦点，不导航。完整详情继续显式保存和离开保护。展开到同一任务完整详情属于继续编辑，保留同一草稿。弹层、拖动、忙碌时不额外触发离开。

列表工具栏提供全局“显示/隐藏子任务”图标，记住偏好；关闭时只在列表隐藏子任务，Today数量、日历和数据不变。显示后只有缩进及极简L形连接线，父任务仍可单独展开/收起。所有列表筛选由C++执行，不在QML复制视图规则。

## 固定工具与日历表达

列表/日历视图切换放在内容标题左侧固定位置，标题和右侧搜索/筛选显隐不改变其位置。收起导航按钮位于导航顶端；折叠后保留窄导航轨及恢复按钮，内容区不承担导航开关。普通导航/完整详情均可恢复。

日历所有任务标记具有语义背景和清晰文字：普通任务用primaryFill/primaryInk，带时间安排用scheduleFill/scheduleInk，截止有旗帜和文字色区分，完成有勾和删除线；跨日条延续同一配色。不能继续按旧eventId有无决定是否有背景。

## 验收

临时库：树投影含归档/路径，创建二级、升/降级、跨一级移动、带子分类阻止降级、任务ID/标签不变；列表折叠不改变Today计数/查询、单独子项父提示、分组不拆树。QML/Cocoa：空白点击干净退出/自动保存成功/验证失败保留，点击行不误退出；侧栏树菜单/新建上下文、移动预览/失败、任务草稿新建；切换视图图标坐标一致，导航开关位于导航边界，浅深100/200%标记有背景。保持键盘Tab、左右展开、菜单键/Shift-F10和Esc关闭一层，所有图标有名称。每片build/CTest，最终Debug/Release/lint及原生截图；物理输入、IME、VoiceOver、Windows当前源码单独UNVERIFIED。
