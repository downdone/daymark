# 桌面界面语言与全窗口统一（UI-31）

2026-10-25，FR-007/010/012/013/018/024～031，UX-01/02/04～07/09～14；当前状态只见 PROGRESS。以用户本轮五张截图为视觉关系输入，沿用统一任务及父子联动契约，不改 schema、日期判定和数据操作。

## 分析与取舍

当前五个智能视图已经分明，但其下分类、标签、回收与工具仍像等权按钮；设置在巨大的分段、说明、卡片和滑块之间重复留白；新增缺少标签—输入对齐；日历月份、翻页与一长串工具占去两排空间，月格只有横线，选中日期整格深色盖住事件。问题是关系不统一，不能靠缩小所有文字解决。

提取 macOS 提醒事项的智能卡、来源列表、就近小面板和紧凑表单；提取日历的独立月份标题、集中翻页、细网格、日期右对齐及连续色条。保留 Daymark 两级文件夹和独立标签，不引入任意图标、模板、账号、农历或尚无实现的日/年视图。视觉独立绘制，窗口仍用运行平台原生边框，导出/导入的系统文件选择器保留原生外观。

## 完整操作与状态

分类右键/上下缘排序/中央移入、标签右键和归档恢复不变；来源列表不改造成大卡片。底部工具有独立分隔，不与分类混淆。用户进一步确认收集箱上移：顶部采用六个入口，收集箱是未分类任务的系统入口，自建分类区不再包含它，日期不清除。普通列表保留父子缩进，简易字段退出即保存，错误保留输入；日期芯片显示已选值，空值显示动作名称，信息入口仍直接完整详情。

日历使用整月细格及淡周末背景；今日圆点和选中日期区分，只有键盘焦点画完整焦点边界，跨天横条保留背景。每周只为本周实际横条预留泳道，避免一周重叠撑高整个月。窄窗议程打开后排在网格之前，宽窗位于右侧，不依赖异步滚动到页面底部。月/周功能、跳转、未排期、独立桌面日历、已完成筛选、周首日、当天议程、改期及撤销全部可达，空间不足自然换行和滚动。收起议程回到网格顶端，避免保留旧面板滚动偏移；“全部”用列表图标，与收集箱的托盘图形区分。暂不重写查询或时区逻辑。

新增分类/标签采用同一行式表单；分类选择上级、标签选择现有五种颜色，文件夹固定。编辑同样布局，保留版本冲突、失败草稿、Esc放弃保护。设置、数据/批量/确认及选择弹层共用全局控件与窗口规范；独立桌面窗口同步颜色和控件，不假装改成 WidgetKit。

默认/hover/pressed/selected/键盘focus/disabled/error分别保留。Tab依视觉顺序；Enter提交、Esc关闭临时层，脏草稿仍确认。窄窗与200%把标签和值转上下排，固定尾部动作、单轴正文滚动；即时设置不添加虚假保存按钮。

## 分片与验收

先统一共享控件/表单及设置/新增并构建，再导航/日历/任务快捷区及其他窗口，最后完整门禁。交互保持使用独立interactionActiveChanged通知，不能在按住/释放时触发整页stateChanged重入enabled绑定。维护仍在手势结束后合并补做，日期变化和写入继续发业务通知。保留398阶段既有数据、草稿、键盘、真实指针与呈现断言；新增/调整针对新布局的可见性和窗口边界检查，不能靠隐藏旧控件通过。Debug/Release CTest、两项lint、Cocoa合成截图默认/浅深/880/200%，检查设置三个分类、新建、数据、日期及连续月历。45/120秒watchdog不放宽。物理键鼠、中文IME、VoiceOver、Windows、真实通知/穿透、多屏睡眠与干净机独立部署仍单列。
