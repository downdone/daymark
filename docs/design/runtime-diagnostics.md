# 全局本地日志与底层网络证据

OBS-01，2026-11-05。用户要求错误码不足时可直接定位到底层，并增加全局日志。本切片扩展[错误码体系](diagnostic-codes.md)，不改变认证、同步数据与证书校验，不靠反复注册或延长超时掩盖问题。

## 范围与分层

应用侧增加独立 Qt Core 日志组件，安装全局 Qt message handler，保留原 stderr / 测试 handler 行为。入口在 QApplication 构造前初始化，捕获平台插件/TLS初始化失败；记录启动、QML、资料就绪、业务失败、网络、更新意图和退出。Qt网络以结构化事件写入，SDK原生更新进程保持Qt-free，使用自己的同类JSONL日志。服务端沿结构化slog与请求ID，不新增远程日志服务、遥测或上传。

默认位置为当前资料目录的 `logs`；正常默认资料使用既有QStandardPaths路径，显式data-dir随该目录。smoke/preflight/自动测试只用QTemporaryDir，不能写真实用户日志。CLI可指定本地log-dir便于支持人员收集，不能由服务器指定。每个进程/会话独立文件；应用单文件2MiB、每会话一份轮换，启动裁剪已关闭的旧日志至10份/7天；活跃会话和未知文件保留。更新器单文件同样有界，目录只处理自身命名的日志。日志不可用不阻塞本地任务，stderr及可操作状态保留。

更新器日志在安装根目录`update-state/logs`，单进程最多约2MiB及一条有界记录，保留最近20份并跳过仍运行的进程；应用日志阈值同样允许最后一条有界记录越过阈值，下一条轮换。受限候选启动在COMMIT前只允许写诊断文件，不因此开放业务资料写入。DLL缺失等进入main之前的系统加载失败无法由应用日志捕获；Qt致命消息同步落盘，但不声称捕获任意崩溃或系统断电。

## 网络证据

每次完成的请求记录：组合码、原业务key、HTTP状态、Qt NetworkError整数/枚举名、脱敏errorString、TLS错误整数/枚举名、已观察阶段、耗时、配置预算、请求ID、Qt/TLS后端/系统/应用版本和服务地址指纹。服务地址指纹只用于比较两台客户端是否连接同一构建配置，不包含明文URL。

TLS错误来自sslErrors信号，只观察、不调用ignoreSslErrors。Qt未公开的Winsock/Schannel原生数字明确标记未提供，不从描述文字猜测。原生更新器自行获得的Win32码按实际值记录。阶段是事件观察值，连接复用不保证重复出现每个信号；超时与证书失败、代理、断连、HTTP拒绝分别保留。

只有无HTTP响应的传输错误可保存经脱敏的底层错误描述；HTTP reason phrase/响应体不作为日志，避免服务器回显凭据或任务。脱敏覆盖URL、主机、用户目录、邮箱和秘密赋值；结构化字段拒绝口令/token/cookie/账号/标题/备注/请求响应体。限制深度、字段数、数组长度、消息长度并转义控制字符。不得记录Authorization、SQL绑定值、证书私钥或本地DB内容。

## 交互与验证

用户定位顺序：记录组合码及请求ID → 展开或复制诊断，区分代理/连接/TLS/等待响应 → 从账号页或设置关于打开日志目录，按同一请求ID找`network/request.finished` → 对照服务端同ID记录。文件为逐行JSON（`.jsonl`）；无需开启调试模式，也不反复提交注册。分享前仍应人工审阅日志，日志不是数据备份。

错误主文仍为可操作的中文；追加Qt底层编号便于截图定位，详细字段逐步展开。账号失败态提供测试连接、复制诊断与打开日志；设置关于提供全局日志入口。HIG映射清晰反馈、用户控制、渐进呈现与可恢复，沿UX-09/11/13共享字体/按钮和外层滚动，200%时按钮换行，纯文本防富文本注入。

字体或视口高度重排后，只针对当前焦点重新检查可见性；不监听滚动位置来抢回用户手动滚动。关闭账号窗口收起详情并清理日志动作失败提示。主程序命令行可用`--log-dir <directory>`指定日志目录，普通业务操作不需要命令行。

测试覆盖：Qt全局捕获/原handler链、显式事件、并发写、轮换与保留、敏感信息脱敏/未知文件保留、致命错误前落盘、无日志权限不影响业务；真实断连/15秒超时记录Qt枚举和阶段，TLS错误列表与服务端业务错误分开；构建/相关Qt Test/QML lint和实际Windows入口证据。完整更新与38项回归已有证据见PROGRESS，本切片只补受影响日志/网络/账号链，不重复无关长时watchdog。
