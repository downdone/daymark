# UI-12：整体布局、密度和图标精修

FR-002/007/010/012/013/018，UX-01/04/05/09/10/11/13/14。沿用UI基准及显式保存/草稿/单滚动正文，不改变数据、业务日期或查询语义。

## 审视结果及设计

| 问题 | 调整 | 保留约束 |
|---|---|---|
| 表单按钮偏高，间距分散 | 默认32DIP控件、10DIP字段间距、20DIP页边距；紧凑模式进一步收紧 | 字号不缩小，200%按内容增高；图标命中区至少32DIP |
| 完成圆随按钮拉伸，图标比例不一 | 固定18DIP图形置于32DIP命中区，统一线条和状态色 | 完成与编辑分离，键盘名称和焦点保留 |
| 多重边框、粗标题形成噪声 | 字段边界保留outline对比，hover/焦点增强；结构分隔弱化，分组以间距/字重区分 | 焦点2DIP与错误色不弱化；文字对比沿用已有token |
| 任务元信息占多行 | 项目、标签、日期和清单汇为同一元信息行；Today视图不重复今日标记 | 详情完整可读，不改变Today归属 |
| 页头文字按钮与组件图标不协调 | 搜索/筛选统一图形按钮及中文提示，选中表示展开/生效 | 入口始终可见，搜索快捷键及筛选清除不变 |
| EXE/任务栏缺独立软件图标 | 原创蓝底日历勾选标识；SVG母版及多尺寸ICO/ICNS，嵌入应用资源/Windows PE/macOS bundle，托盘复用 | 不使用Things或Apple资产；macOS实机未验证 |

数值均为Daymark自主选择。图形资源用仓库脚本重建，不新增运行时第三方库。Mini仍仅摘要和展开，小窗保留置顶图钉。

## 验收

Debug/Release构建、CTest及两个QML lint；Windows隔离原生152阶段覆盖菜单/日期/草稿/长短备注、默认/窄/宽/200%、浅深色。截图检查主窗、任务详情、日历、复杂表单和小窗。从实际PE提取图标检查，应用图标非空且含16/20/24/32/48/64/128/256帧；无真实用户库访问。读屏、物理DPI/触摸板、macOS及完整发行仍分别记录，不以截图替代。
