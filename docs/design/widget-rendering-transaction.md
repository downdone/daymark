# UX-75 组件绘制与呈现事务

2026-11-04，设计先于实现。覆盖UX-66原生窗口随形态收缩的实现细节，保留三形态独立启用、逻辑锚点、交互保持、临时查看及减少动态的产品规则。

## 目标与问题

HIG连续性→一个视觉表面与一个可逆进度；稳定布局→固定内容尺寸/逻辑锚点；用户控制→菜单、拖动、输入期间保持；可访问性→减少动态立即收敛、焦点与穿透恢复。关联FR-012/018/035、UX-09/10/11/12/13、P-13/15/17。

旧实现收球结束后再次resize原生窗口，清空mask并在后续回调补回；宽、高、圆角又分别写mask，存在不一致中间区域。内容enabled和clip在终态切换，可能改变调色板或场景图节点。旧测试采到中间帧并不证明交接帧没有这些变化。

## 几何与平台

- 单个透明QQuickWindow终生保持透明清底、window opacity=1。画布为所有已启用形态最终全局矩形的包围盒，通常为最大Panel/Mini尺寸；三种逻辑矩形由同一PlacementPolicy分别避让，再转换到画布局部坐标。
- 形态/hover/自动收回不resize或重定位画布，终态确认也不清空mask。只有真实拖动、用户调整尺寸、配置/字体最小尺寸或屏幕拓扑改变可重新提交画布。
- 视觉球尺寸仍36 DIP起；原生画布较大不表示球变大。输入区域只覆盖实际可见形状，空白不截获桌面；Qt mask并非跨平台承诺的input-only API，其实际平台行为单验。
- 持久化仍是Panel尺寸/Mini宽度/逻辑锚点，不写画布尺寸和动画帧。拖动按可见形态全局矩形取屏幕与落点；Panel的手柄直接调整逻辑尺寸，避免原生大画布边缘与可见面板边缘错位。

## 渲染事务

- 唯一NumberAnimation驱动0～1进度，插值视觉rect、半径和三形态权重。反向先读取当前视觉快照作为新起点，不清零、不重排文字。所有内容按最终逻辑矩形布局，clip常开；屏障阻断过渡输入，不切正文enabled/调色板。
- QML属性变化只提出完整rect+radius；C++在afterAnimating合并提交一次mask，相同区域不调用平台。隐藏可清除/释放输入；稳定形态和动画完成不能先清空再重设。
- 动画结束只请求当前transitionId的呈现确认。afterSynchronizing记录已同步代次，frameSwapped之后队列回GUI确认，旧代次自动丢弃。确认只更改状态/交互，不resize窗口或改视觉终值；frameSwapped表示帧已提交，不等于物理显示器已扫描。
- 减少动态立即到视觉终值，仍在当前代次帧提交后恢复输入；隐藏、禁用、穿透安全命令可立即结束交接。几何配置失败回滚原状态/逻辑矩形/实际画布并给出错误；普通收球不再需要末帧resize，因此也不制造末帧resize失败。

## 接口与线程边界

`WidgetPlacementPolicy::canvasLayout`输出画布全局矩形及三种形态的局部矩形。`WidgetViewModel`提供只读`panelRect/miniRect/ballRect`和`transitionPending`，QML只插值这些几何，不另算停靠策略。`setPanelMinimumSize`和`resizePanel`调整逻辑Panel；最小尺寸或平台提交失败均保留原尺寸并通过既有错误通路反馈。

`setRevealRegion(rect,radius)`仅缓存最新完整形状，GUI线程`afterAnimating`调用`commitRevealRegion`；同帧宽高和圆角变化合并。`presentTransition(id)`将当前代次写入原子栅栏，渲染线程`afterSynchronizing`与`frameSwapped`只交换原子值，再队列回GUI调用`finishTransition(id)`；窗口重挂载有独立epoch，过期回调不能完成新窗口。`finishTransition`只清交接状态，不改绘制几何。

过渡期间透明输入屏障拦截指针、滚轮和普通按键，保留Escape恢复路径；结束后恢复仍可用的原焦点，否则聚焦当前形态操作入口。菜单请求先完成视觉终值、等待提交，再显示；新代次取消旧菜单请求。球的右键限定球自身，小窗空白仍不打开面板菜单。

## 验证

纯几何测试覆盖多屏/屏边/四角与不同Panel/Mini尺寸、拖动落点、逻辑尺寸持久化和失败回滚。Qt Test验证开启画布后50次两两切换原生几何无变化、关闭完成无resize调用，过期呈现与减少动态保持。QML覆盖单一进度、反向连续、固定内容尺寸与clip、屏障、菜单/焦点/输入恢复。

专用`desktop_rendering`隔离探针检查12次两两切换、浅色100%左上与深色200%右下、真实中间帧、窗口尺寸事件为零、场景图不失效及mask不清空。每次收球读取连续三帧并比较，球心须有绘制、旧面板远角须透明；Windows另用`GetWindowRgnBox`检查实际原生区域。四角/负坐标屏幕由纯几何测试补充，不冒充物理多屏。自动数据全用QTemporaryDir。物理桌面残影、混合DPI、读屏和macOS分列；不以离屏或单张静态图替代合成瞬态验收。
