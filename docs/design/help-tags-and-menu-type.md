# UX-40：Tooltip准入及菜单字级

本轮处理用户指出的组件菜单字级不协调、mini展开提示和分类重复名称。按P-13/14、UX-01/09/10/11/12/13执行，不修改数据或动作语义。

## 准入规则

| 场景 | 是否出现 | 内容 |
|---|---|---|
| 完整可见的分类/标签、任务标题、日期、按钮文字 | 不出现 | 不重复名称或当前已经看得见的信息 |
| 关闭、上一/下一、展开/收起、完成圈 | 不出现 | 常规图形、选中态和可访问名称负责表达；mini下箭头明确不提示 |
| 需要解释的纯图标操作，如置顶、分类/标签、设置 | 可以 | 用简短动词说明动作或当前状态，不附带一遍用户任务标题 |
| 文字被截断，或分类完整路径有未显示的信息 | 可以 | 补全被隐藏的原文/路径；移出文字区域即消失，不覆盖旁边的更多按钮 |
| mini摘要 | 仅标题截断或有错误时 | 首项全文/错误，不重复“展开任务组件” |
| 键盘焦点 | 不自动弹出 | 名称和状态交给可访问语义；保留清晰焦点框 |
| 按下按钮、打开菜单、拖动过程中 | 普通提示禁用 | 立即收起已有提示，不与菜单或拖动反馈争抢 |
| 受限拖放的原因 | 明确例外 | 就近即时反馈，非功能说明，可在拖动中出现 |
| 折叠的多行/超长备注 | 明确例外 | 只读可滚动全文预览，保留复制；完整单行备注不重复预览，打开选择器/菜单时关闭 |

统一停留600ms后显示、普通提示5000ms后收起，移开/按下立即关闭。普通提示为辅助12 DIP×文字缩放、正常字重、纯文本；只解释当前控件，不承载必须操作或唯一错误。正文溢出预览不受“简短动作说明”的字数约束。读屏名称不因禁用tooltip而删除。

## 菜单排版

菜单独立于覆盖层和原生弹出窗口的字体继承：菜单/文字/勾选/箭头都显式使用同一个正文13 DIP×文字缩放、系统字体、正常字重；不得继承导航选中项或标题的粗体。紧凑菜单行28起、舒适32起，随字体自然增高；这是桌面菜单例外，不缩小普通按钮的32命中。菜单内部同一文字列，勾选使用保留列，不让checkable项额外缩进。长项按真实字体度量展开宽度，空间不足时仍可读，不通过更大字号或额外换行制造层级。

## 来源与验证

[Apple Offering help](https://developer.apple.com/design/human-interface-guidelines/offering-help)要求简洁、针对当前控件并避免重复名称。Qt 6.10.2使用显式visible/delay/timeout及自定义样式，不使用6.12新增的policy API；机制见[Qt ToolTip](https://doc.qt.io/qt-6/qml-qtquick-controls-tooltip.html)。以上准入、时长、尺寸和例外为Daymark自行定义。

逐项检查所有ToolTip使用处、图标基础类及共享Menu。验证mini短标题/展开箭头不出现提示，短分类不重复、长分类全文恢复，必要图标可提示，键盘焦点不触发，菜单打开收起已有提示，默认/200%下菜单字体与文字列一致。复用desktop_surfaces独立临时库，保留旧备注/菜单/选择/拖动回归；真实物理DPI、读屏和macOS实机单列UNVERIFIED。


## 同轮日历修复（FR-037/038、UX-09/10/11/12）

时间轴空白、任务移动和端点拖动一旦按下即保留指针，不由外层Flickable抢走；15分钟吸附、持续预览、边缘自动滚动及Escape取消保留。连续拖过多个时段后，只新建一个所选起止范围的草稿，未提交不写库。年视图只绘制本月日号，今日与选择分别用语义色圆形表达；非本月占位不可点击/聚焦/高亮。同一数据投影不重建日期代理，避免无关状态刷新导致重影和滚动/焦点丢失。

新建面板可拖动标题区域，输入、按钮、日期选择器仍负责各自操作；位置限制在窗口内，重新打开按所选时段定位。外部点击拦截底层操作：空标题关闭且不插入；非空标题校验通过后原子保存并关闭，失败保留面板、文字及可操作错误。取消明确放弃，Escape延用离开前保存门；日期/时间等内部选择器操作不作为外部点击。这是Daymark对就近编辑和直接操作的具体约定，不声称HIG规定必须自动保存。

验证复用calendar_interaction临时库：跨六帧连续指针移动、精确90分钟草稿、标题拖动、外部保存后的真实schedule/无底层操作、非法结束日期的零插入与输入保留、年视图非本月不高亮以及无关状态刷新保持代理。保留空标题/取消零插入、键盘及缩放既有检查。Windows合成输入与截图不替代物理鼠标或macOS实机验收。
