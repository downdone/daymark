# UX-56：设置的桌面两栏导航

UX-68更新：通用页将“备份周期”与“数据与备份”管理入口合并在“备份与数据”组；帮助独立为“帮助与说明”。侧栏移除常驻备份图标，入口路径为设置→通用→数据与备份，沿用独立数据工具及草稿保护，不迁移数据库或改变备份协议。

FR-012/018，UX-01/05/06/07/09/10/11/14，P-07/09/13/14。按HIG内容层级、稳定导航、布局与可访问性原则，以macOS设置的“侧栏选择—内容检查”关系替代UX-47的目录/进入/返回；保留独立资源和Windows原生窗口习惯。

设置始终为两栏：左栏是外观、桌面组件、通用、关于四个一级入口，原创图标与文字同行，只显示一个选中项；右栏固定当前标题/摘要，正文保留既有分组、控件及即时保存。无目录首页、进入箭头和返回目录步骤。默认外观，重开保持当前类别，切换时保留各页滚动。状态、错误与关闭仍固定可达，数据/帮助走原路由，不改变保存或穿透恢复逻辑。

默认约860×680 DIP，左栏176～220 DIP、右栏分组控件自适应；最小640×420，200%时保持两栏、右侧字段按需堆叠和单轴滚动。侧栏独立按需滚动，正文不能拖动整个导航。浅深/增强对比沿共享视觉源，选中底/焦点分别表达选择和键盘状态，字体使用原正文/标题角色，无重型框线或页面切换动画。

侧栏上/下、Home/End选类，当前类别为Tab入口；Tab进入右侧，聚焦被遮挡控件会揭示。Esc关闭设置，弹层先使用自身取消；保留原生标题栏关闭。设置不是一组互斥参数，不使用分段控件作为一级导航。

保留现有分类索引和设置字段对象协议；setVerificationCategory/activateVerificationCategory映射真实侧栏入口，不保留虚假的可见返回按钮。desktop_surfaces更新真实指针/键盘导航、四页内容、偏好保存、滚动恢复、关闭/重开、浅深200%及宽窄几何；calendar_interaction/原完整探针保留实际设置与路由检查。关联构建/lint/CTest通过后再按打包门槛生成本地候选，不上传Qt运行库。原生Shell、macOS和物理输入验收单独记录。
