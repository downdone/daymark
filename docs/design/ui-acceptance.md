# UI/UX目标验收与迁移计划

日期：2026-10-22。对应 [设计基准](ui-baseline.md)，证据来源见 [调研](ui-research.md)。**以下是待实施门禁，当前均未因研究完成自动通过。** 当前应用功能测试通过和UI目标验收通过分别记录。

## 1. 可验收基准

UI-14整体验收清单见[全界面设计](hig-redesign.md)：除原UX门禁外，检查三类设置始终可切换、切换正文回顶；规则修改后新建/切换/退出的取消与放弃；组织/事件/批量日期可手输和选择；提醒中心空态和返回；默认/深色/200%下的分组、选中及焦点。程序化点击、合成键盘和截图与真实IME/读屏/物理DPI分别记录。

| ID | 目标及需求关联 | 复现方法/通过标准 |
|---|---|---|
| UX-01 内容优先 | FR-002、PRD §3 | 用20项混合长度任务打开Today；正文为主、标题对齐、默认无每行大“编辑”按钮、导航不抢过任务；不出现无法读全任务的唯一入口 |
| UX-02 稳定导航 | FR-003～006 | 切换六视图并返回，位置/选择合理保留；隐藏侧栏后按钮和键盘仍可恢复；不可显示点了无作用的目的地 |
| UX-03 快速录入 | FR-001、TC-001/002 | 浏览状态1动作进入标题，连续录入20项；Enter成功继续、Esc可退出；空标题/写失败保留输入，任务数和重启一致 |
| UX-04 行操作分离 | FR-002/007 | 点击标题打开详情，点击完成仅完成；空白点击不误删；上下键/Enter/Space在正确焦点上下文工作；输入中文空格不完成任务 |
| UX-05 详情上下文 | FR-007、PRD §3.2 | 1120×720宽窗侧栏/列表/详情互不遮挡；880×580使用主内容编辑页（UI-10），无二级详情弹窗；关闭回到原任务，脏草稿保存/放弃/取消与错误保留全部通过 |
| UX-06 时间含义 | FR-003/010/011、TC-008/021～025 | 开始/截止/提醒有独立名称；日期选择及清除可键盘操作；非法范围零修改；Someday日期暂停；日历标记非单靠颜色 |
| UX-07 恢复与信任 | FR-002/006/017、TC-016/038～040 | 软删后可撤销且看到恢复结果；错误有行动入口；项目删除迁出确认和导入替换备份不被视觉精简移除；成功仅在提交后显示 |
| UX-08 搜索范围 | FR-016、TC-020 | 新用户能读出全局/历史范围；中文/英文/备注/空结果可用，清除或Esc回原上下文；没有为导航抢输入法按键 |
| UX-09 字体/布局适应 | FR-018、NFR-09、TC-041 | 默认/大字下主动作仍可达，无重叠、截断关键字段；长中文、200%文本、窄高窗可滚动；DPI与文字大小独立验证 |
| UX-10 对比与状态 | PRD §3.1、NFR-09 | 正文4.5:1，大字/必要图形3:1；真实token组合逐个计算；light/dark、hover/selected/focus/error清楚，灰度仍分辨开始/截止/过期 |
| UX-11 键盘/辅助技术 | PRD §3.3、NFR-09 | 仅键盘完成录入→排期→完成→恢复；焦点不丢失，菜单/弹层可退出；Narrator/VoiceOver能读任务名、状态和动作；未跑平台不标PASS |
| UX-12 低干扰动效 | PRD §3.1 | 连续完成20项不被动画阻塞；减少动态效果下信息完整且不依赖运动；组件被动刷新不夺焦点 |
| UX-13 组件与恢复 | FR-012/013、TC-026～029 | Floating与Mini均可读可展开；完成同步主窗；穿透从托盘/主窗退出；变更背景alpha不改变字alpha；浅/深/花纹背景测试 |
| UX-14 平台融入 | NFR-09、FR-013/018 | Windows与macOS分别测菜单、原生窗口、快捷键、中文输入法、关闭策略；不得用Mac外观替换Windows系统控制 |

本表的项目阈值用于判定，不等于当前应用已达到。可访问性实测失败属于功能缺陷，不能用视觉评分补偿。

## 2. 验收数据与截图协议

使用QTemporaryDir或明确隔离的数据目录，禁止截图真实私人任务。固定合成数据集至少包含：空列表、1项、20项、200项滚动；长中文/英文/emoji、多行备注、无日期/只截止/过期/未来/今日关注/Someday/已取消。实现项目/标签后再加入相应数据。

每个UI切片至少提供：默认1120×720、最低880×580、宽窗1440×900；浅/深色；默认及200%文字；有焦点、悬停、选中、空态、错误/草稿。不是每次做全笛卡尔积：每个切片覆盖其风险，发布前完成全套主路径矩阵。记录OS、架构、Qt、DPI、逻辑尺寸、文字设置与渲染后端，不能只记录PNG像素大小。

验证顺序：自动化数据/状态回归 → 真实QML操作 → 截图检查布局/对比 → 原生鼠标/键盘/读屏和多屏验收。offscreen截图不证明系统窗口层级或辅助技术。图标来源、字体回退及许可在分发前复核。

## 3. 用户任务基准（初始预算，待真实测量）

计数起点/终点必须一致；按键输入标题内容不计作动作，打开菜单、点按钮、确认各计一次。预算是体验研究目标，未达标先分析错误与可靠性，不能删确认/保存保护作弊。

| 任务 | 起点→终点 | 初始预算 |
|---|---|---|
| 收集一项 | 列表浏览→提交标题 | 2个显式动作以内（进入录入＋提交） |
| 完成一项 | 已可见任务→提交完成 | 1次直接动作，无模态确认 |
| 安排到明天 | 已可见开放任务→开始日已提交 | 3个显式动作以内 |
| 看并改备注 | 已可见任务→编辑备注可输入 | 1～2个显式动作 |
| 搜索并返回 | 当前视图→搜索结果→回原位置 | 搜索激活/退出各有直接入口 |
| 撤销最近删除 | 删除反馈可见→任务恢复 | 1次动作，恢复结果可定位 |

邀请3～5位目标用户做形成性评估（人数是项目计划，不是Apple规定）：不给路径提示完成上述任务，记录成功/误操作/卡点/返回原状态的能力，测试前说明可恢复与数据隔离。当前无真实用户样本和耗时，不能宣称对标Things效率。

## 5. 评审模板

```text
任务：UI-xx；适用Apple HIG原则及官方来源；关联UX-xx、FR/TC：
目标用户操作链：
布局/主要动作/次级动作/数据写入边界：
状态：默认、hover、selected、focus、pending、success、error、empty
平台/主题/逻辑窗口/DPI/文本缩放/输入法：
验证：build、CTest、QML、截图、原生操作、读屏
结果：PASS / FAIL / UNVERIFIED（逐项，不用总分掩盖阻塞项）
遗留与解除条件：
```

## Apple HIG强制评审

遵守[项目原则P-13](../principles.md)。每轮说明适用原则、用户操作链、视觉层级与完整状态，并用本表UX项给出证据或UNVERIFIED。使用HIG不能替代键盘、200%、真实辅助技术及平台实测，也不能将Daymark自主token写成Apple规定。

UI-15补充：逐页按[动作审计](actions-and-color.md)验证纯图标名称/tooltip/焦点/禁用与原命令一致；图文动作在200%和独立420×480保留操作栏。浅深/增强对比度四种token组合以`python scripts/check-ui-colors.py`（macOS通常`python3`）复算普通文字4.5:1和必要边界3:1；禁用及装饰分隔不以此阈值冒充有效控件。透明桌面背景的实际对比取决于壁纸，增强对比度临时使用实色背景且关闭后恢复原偏好，仍需真实平台验收。

UI-16详情验收按[布局契约](task-detail-layout.md)：宽页同行与窄栏重排，项目/领域互斥和适用分组、移动后的今晚/提醒原子提交、只读信息跨缩放保持、取消无日期任务关注无多余确认；原单草稿/单轴/日期/失败恢复继续执行。

UI-18按[直接编辑契约](direct-editing.md)验收快速编辑的保存/取消/放弃与完整详情转移、日期开关和快捷菜单只改单字段、时间选择取消不改输入、200%固定操作栏。原有滚动/焦点与原子保存回归必须同时通过，物理输入与读屏独立记录。
