# Daymark 4.1.1

包含 4.1.0 的任务工作流改进，并修复正式 Windows 候选发现的日历卸载绑定错误。4.1.0 未提供 Windows 二进制。

Windows托管更新包由受保护流水线发布。

- 任务在多处被修改时，可比较并合并各项内容，取消比较保留草稿，保存前继续校验版本。
- 退出时可选择保存、放弃修改或继续使用，主窗口和小窗的快添、任务编辑及子任务草稿均受保护。
- 标签支持连续多选、应用与取消，简易编辑直接显示分类、标签摘要及保存按钮。
- 小窗临时失焦保留编辑现场，子任务详情支持返回父任务，新增任务被当前筛选隐藏时提供查看入口。
- 日历新建时，标题中的日期与当前安排不一致会要求明确选择；改进搜索空态、长选择列表和托盘恢复操作。

Windows x64 安装包使用项目自签名证书，在线更新包另有独立签名。自签名证书尚未取得 Windows 公共发布者信任。

本地 Windows 完整 CTest 55/55 通过，最终增量的构建、QML 检查、原生窗口及草稿回归通过。真实 Qt/Go TLS 双设备联测使用测试指定的 OpenSSL 后端通过。本机 Schannel 对临时自签名 TLS 服务存在握手超时，尚未解决，生产 TLS 校验和后端策略保持原配置。物理混合 DPI 多屏及 macOS 尚未实机验证。正式候选、安装与公开升级结果见发行工作流和 PROGRESS。
