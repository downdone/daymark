# Daymark 2.2.3

Windows托管更新包由受保护流水线发布；完整安装器和便携包在完整测试、签名与独立部署验收通过后附加到本页。

- 修复切换收集箱、今天、分类、标签和搜索时顶区高度变化的问题，保持品牌、导航、标题和正文起点稳定。日期与统计在宽窗同行显示，窄窗或大字模式放入现有底部状态行。
- 调整融合顶区的比例和对齐：主窗字标、页标题、页面工具和窗口控制共用视觉中心轴，保留Windows右上角热区。设置和账号窗口按各自一级标题对齐；设置分类说明换行不再推动正文。
- 更新就绪提示改为正文右下方的蓝色通知卡，明确显示版本、说明和主次操作，避开导航、快速输入和底部动作。通知不抢焦点，“稍后”恢复最近的有效输入位置；支持Enter、Return和空格，忙碌时禁用重启。
- 修复惰性通知关闭后的重启意图派发，保留原有保存退出和版本提交流程。新增真实Windows布局回归，覆盖40次页面、16次设置分类及浅深色、100～200%文字与通知键盘交互。

便携包完整解压后运行顶层daymark.exe，现有托管安装可通过内置更新升级。安装、更新和卸载保留任务及账号资料。程序采用项目固定公钥和证书指纹自签名验证，尚非Windows公共发行者信任，无需导入根证书。

数据库schema10、HTTP JSON v1及Qt6.10.2保持不变。Windows优先；macOS/Linux本轮跳过，物理多屏/DPI、读屏和Windows 11 Snap悬停菜单仍需实机验收。实际验证和资产身份见仓库PROGRESS。
