# Daymark 2.2.5

Windows托管更新包由受保护流水线发布。

- 主窗口重新梳理任务、侧栏和工具栏的视觉层级。任务分隔线沿文字对齐，悬停显露操作，键盘焦点单独标记。
- 快速添加、搜索、设置、账号和现有任务详情统一配色与字号。分类、日期和其他选择器按内容收紧，大字模式下可滚动。
- 桌面小窗、Mini 条和悬浮球采用同一套视觉规则。小窗分类选择更清晰，Mini 条以任务摘要为主，悬浮球保留蓝底白标。

本次 Windows 更新与既有数据库和同步协议兼容。完整安装包和便携包使用项目自签名，尚无 Windows 公共发行者信任。macOS、Linux、物理混合 DPI 多屏和读屏未在本轮验证。
