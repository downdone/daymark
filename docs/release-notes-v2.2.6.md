# Daymark 2.2.6

Windows托管更新包由受保护流水线发布。

- 主窗口统一任务、侧栏和工具栏的视觉层级。任务分隔线沿文字对齐，悬停显露操作，键盘焦点单独标记。融合标题栏让标题、品牌和窗口按钮共用垂直对齐轴。
- 快速添加、搜索、设置、账号和现有任务详情统一配色与字号。选择器按内容收紧，大字模式下可滚动。
- 桌面小窗、Mini 条和悬浮球使用同一套表面与边线。Mini 条采用更收敛的圆角，留足菜单按钮空间，三种形态的轮廓都支持平滑抗锯齿。悬浮球改用实体浅底或深底与品牌色标志。

Windows 托管用户可从 2.2.4 在线升级，现有数据库和同步协议兼容。安装包和便携包使用项目自签名，尚无 Windows 公共发行者信任。macOS、Linux、物理混合 DPI 多屏和读屏未在本轮验证。
