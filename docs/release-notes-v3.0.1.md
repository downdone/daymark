# Daymark 3.0.1

Windows托管更新包由受保护流水线发布。

- 设置按常规、任务与提醒、桌面组件、外观、数据与隐私、关于与帮助重新分区。提醒/时间识别、备份/日志/隐私、使用帮助各有明确入口，保留原有偏好和即时保存；键盘顺序、每页滚动、浅深与大字号一并适配。
- 桌面组件的形态启用与背景/自动收展分组，主题显示与窗口标题栏分组，账号继续使用独立窗口。
- 增加默认关闭的可选使用统计：仅发往当前账号服务，主动同意后才采集固定使用/性能区间；可撤回清理，不包含任务/备注/分类/标签或输入内容。需要自定义部署新版服务或由运营方另行启用，旧服务不影响普通任务同步。
- Go业务服务增加独立管理员MFA/恢复码、角色/审计、用户状态及会话管理、公告草稿/预览/发布/撤回，以及聚合看板和可恢复的数据清理。后台与统计服务配置默认关闭；软件发行不自动部署或开启生产采集。
- 独立通知中心取消，保留已有任务到期提醒、提醒记录、更新及账号状态提示。后台公告仅维护服务端状态，不向客户端推送。

本次沿用本地schema11和任务同步协议。3.0.0可按现有托管流程升级；从2.2.x仍需完整安装或新便携目录升级，先退出程序并保留资料备份。业务服务新增迁移4及独立统计库；服务运维步骤见server/BUSINESS.md，管理员密钥须独立托管。

版本号按用户指定为3.0.1，已公开3.0.0标签/资产不覆盖。Windows安装/便携包继续项目自签名，不属于Windows公共发行者信任；macOS/Linux和物理混合DPI/读屏未在本轮验证。构建、候选与实际安装/更新证据统一见PROGRESS；发行说明本身不是门禁通过声明。
