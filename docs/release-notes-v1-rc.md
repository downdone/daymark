# Daymark 1.0.0-rc.1 · Windows V1候选版

这是用户指定的Windows本地候选交付，供实际日常试用；并非完成双平台正式V1验收。macOS当前没有构建/验收机器，未提供Mac二进制。版本与包校验和见[进度](PROGRESS.md)，实际结果见[验证记录](verification-report.md)。

## 功能

具备离线任务收集、六视图、持续Today/今晚、项目/领域/Heading/标签/清单、月/周日历、重复任务、提醒中心、托盘与Floating/Mini组件、JSON/CSV和WAL一致备份/恢复。详见[需求审计](v1-feature-matrix.md)。

相对v0.1新增：宽窗停靠/窄窗覆盖的共享详情草稿；任务多选与事务化批量完成/移动项目/改开始日/替换标签；清单内容搜索及项目/标签过滤；历史7/30天；Anytime归属分组和今日标记；Someday快捷激活；组织排序、领域归档与恢复、颜色标识；日历已完成开关及未排期列表；拖到Today的未来日期确认；侧栏折叠恢复、每视图滚动位置、导航快捷键；紧凑列表、实色组件、备份周期及系统提醒开关；Windows用户级开机启动；托盘/组件录入及首次关闭提示。

## 使用与升级

解压ZIP后运行daymark.exe；包内带Qt/MinGW运行库，没有私人任务数据。程序数据目录保持原位置，v0.1数据可直接升级。首次打开schema1库，先在数据目录的backups/migrations创建一致快照，再事务升级为schema2；备份失败时拒绝升级。旧版本不能打开schema2；回退请在独立目录使用升级前备份，不能把版本号手工改回1。

自有JSON继续使用formatVersion=1，接受schemaVersion=1/2，导出为2。旧areas记录缺少archived时补未归档默认值。替换导入仍需预览、双重确认并先备份。批量改开始到未来会取消持续关注Today，保留截止日；日期冲突整批不写入。

开机启动默认关闭，仅显式勾选后登记当前用户的当前程序路径；移动解压目录后请重新登记。系统启动管理可能禁用该项。关闭系统提醒不删除应用内提醒记录。备份默认每日，7/30天选项在启动时检查，保留最近7份；迁移和替换前备份不受周期限制。

## 已知边界

候选包未签名、未做原生安装器和独立干净机验收。macOS开机启动适配、macOS编译/签名/运行、两平台8h稳定性与睡眠/多屏、真实焦点/穿透恢复、系统通知送达、中文输入法/读屏/系统高对比及全部200%场景仍需验收。程序收到Windows时间/设置/唤醒事件会刷新本地日期和提醒，但合成/状态测试不证明真实系统事件已通过。

不提供账号、云同步、AI、外部日历集成、小时轴、移动端及后台关闭后的通知。详尽正式发布门禁仍见PRD与里程碑。Qt许可与公开再分发边界见[第三方记录](third-party-notices.md)；本包限当前本地验证范围，未进行GitHub上传。
