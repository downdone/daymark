# Daymark 2.1.1

Windows托管更新包由受保护流水线发布；安装程序与便携包在完整测试、签名和独立部署验证通过后附加到本页。

- 优化内存与对象生命周期：设置分类、日期和时间选择器按需加载；主列表共用任务菜单，桌面日历关闭后释放内容，隐藏窗口释放可重建的图形资源。保留草稿、滚动位置和小窗稳定画布。
- 修复隐藏窗口后切换主题导致操作图标缺失或颜色滞留的问题。
- 新增离线日期与时间识别：快速添加时预览安排和提醒，可修改或忽略，保留标题原文；歧义和过期时间不静默猜测。
- 新增 Windows 完整安装向导，支持目录选择、开始菜单、可选桌面快捷方式、修复和卸载。安装、更新和卸载保留个人任务与账号资料；程序运行中会提示先退出。
- 修复首次启动的锁错误分类与冷启动争用，以及 Mini 小太阳按钮和置顶组件拖动的交互问题。
- 完善安装模块错误码映射；将错误码与同步协议的生成文件一致性检查纳入完整测试和编译前门禁。
- 关闭导入预览后释放临时计划，切换资料使旧预览失效；取消不写入任务数据库。

安装版与便携版均支持内置更新。便携包应完整解压并运行顶层 daymark.exe，保留 versions 及其他随附文件。

程序采用项目固定公钥与证书指纹进行自签名校验，尚无 Windows 公共发行者信任，系统可能提示未知发行者；无需导入 Root 证书。正式更新包使用 MSVC143，不能与本地 MinGW 候选互换。

数据库 schema10、HTTP JSON v1 和 Qt 6.10.2 保持不变。本轮发布优先 Windows；macOS、Linux及物理多屏/读屏验收未由本次自动测试覆盖。
