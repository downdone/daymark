# Daymark 3.1.0

Windows托管更新包由受保护流水线发布，提供完整安装包和便携包，更新设置入口及原生更新工具链。

- 设置增加“账号与同步”：查看账号、同步状态与待传数量，立即同步或进入已有账号管理窗口。
- 检查更新集中在设置→关于与帮助；移除主侧栏更新按钮及常规设置的退出组，托盘退出和草稿保存保护保留。
- 交互安装检测到当前安装正在运行时，询问“强制关闭并继续 / 取消安装”，默认取消。确认后仅关闭属于此安装、同一用户的应用；活动更新事务继续拒绝安装。静默安装不强杀。
- 更新器采用经过签名和散列校验的版本工具链，后续兼容的工具升级随应用在线交付；保留上一套工具用于恢复，不原地覆盖正在运行的更新器。
- 修复安装向导在显示关闭确认时可能互相等待的问题，补充真实向导取消、确认、修复及资料保留验收。

**3.0.2及更早版本接入本更新工具链，需要使用完整安装包安装一次，或退出后在新目录解压便携包。**旧更新器会拒绝未知的必要能力；本次不支持从旧工具链直接在线安装，也不放宽校验。后续同一工具链协议内的兼容版本恢复在线更新。任务数据库仍为schema11、HTTP JSON同步协议不变，安装/卸载保留个人资料；请先保存正在编辑的内容。

程序采用项目固定指纹自签名与独立P-256更新签名，不属于Windows公共发行者信任，不需导入根证书。Qt6.10.2/MSVC正式构建、公开安装与旧工具链拒绝结果见PROGRESS。macOS/Linux按本轮范围跳过，物理混合DPI/读屏及最低Windows实机未在本轮验证。后台及统计服务不因本次发行自动部署或启用。
