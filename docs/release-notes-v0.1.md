# Daymark v0.1.0 本地版本

日期：2026-10-22。范围：Windows x64本地验证包；用户已明确本轮不进行GitHub推送或Release。该版本不代表完整双平台V1验收通过。

## 核心流程

- 离线任务CRUD、六个规划视图、搜索及历史选项、上下文标签过滤、完成/取消/恢复、软删与撤销。
- 领域/项目/Heading、归属互斥、标签、清单、项目状态与安全删除；Today独立排序和今晚分组、项目排序/分组。
- 月/周全天日历、开始/截止标记合并与拆分、按日创建、单字段改期、日期冲突回滚、周首日设置。
- 每N天/周/月/年/完成后重复、幂等实例、手改保护和停止规则；UTC提醒、应用内记录、托盘汇总。
- 半透明桌面组件、Mini、置顶、系统拖动/缩放入口、锁定、穿透安全恢复、托盘和单实例、几何和外观持久化。
- WAL一致手动/每日快照、JSON导出/验证预览/事务导入、双确认替换与恢复、CSV；浅深/系统主题和文字大小。

## 验证边界

具体PASS、性能与校验值登记在源码verification-report和PROGRESS，以实际执行为准。测试全部使用临时库/合成任务，不附个人任务数据。

macOS构建/签名/运行、Windows真实多屏热插拔、穿透外部恢复、原生层级/焦点、中文输入法/读屏及连续8h稳定性尚未完整实测，保持UNVERIFIED。Qt标志测试不证明真实OS行为，托盘showMessage不证明通知送达。

UI已开始应用独立Things/Apple参考基准；宽窗固定右侧详情、每视图滚动位置、系统高对比/减少透明度、完整辅助技术及全部200%文字场景仍待体验验收。当前详情为覆盖面板并显式保存，Upcoming以按钮每次展开30天。批量编辑、开机启动、外部日历、全局快捷键、云/账号/AI和移动端不在此包内。

本地包含本机Qt/MinGW所需运行库，不依赖SDK PATH。Qt公开再分发授权未核实，不将本地验证包宣称为可公开再分发安装器。详见[第三方说明](third-party-notices.md)。

使用方法见[使用指南](user-guide.md)。schema仍为v1，本轮未覆盖历史迁移；后续模式变更须新增迁移并先备份。
