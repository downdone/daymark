# Daymark 1.1.0

2026-10-27 · 仅发布源码。不附Qt/MinGW运行库、便携包、安装包、SDK、测试日志或用户数据。此版本号表示兼容功能与交互更新，不代表完整二进制发布门禁通过；已有公开版本与标签保持不变。

## 本次变化

- 任务列表支持空白双击新增，直接在原行编辑：“新任务”标题全选待替换，未修改模板外点取消，修改后外点一次建立。保留Enter保存、Esc取消、失败不丢输入和Today/分类范围默认。
- 精修父子缩进、标题/备注/时间及完成圆的对齐，统一浏览和原行编辑的文字轴、工具形态与紧凑程度。最近删除支持Shift/Ctrl或Command多选、集合右键与批量恢复，保留事务和版本冲突保护。
- 详情面板首次定位靠近真实任务来源，箭头对准标题；可用手柄拖动或键盘移动，Esc取消移动，切换页签保持草稿和来源。
- 具体时段成为直接可见入口，任务详情、原行和日历新增共用可拖选的日时间轴小窗。日历支持选中日期任务后拖选安排同一任务；增加特别关注快捷键及批量软删/撤销。
- 优化年视图今日定位、已有标签/底部新建的就近菜单，以及独立日历尺寸调整。重复预设保持单行，开启后直接显示“结束重复 · 永不”，复杂参数只在自定义面板出现，取消恢复原值。
- 全局统一字体角色、字号、配色、圆角、线框和原创矢量图标；设置改为分组目录与子页，详情页签单独精修。启动先恢复窗口和主题再呈现，减少首次可见重排。
- 全面整理任务、日历、分类、标签、详情、小窗/Mini和托盘菜单，语义组之间使用分隔线，动态隐藏后清除空组/孤线，快捷键独立右列。透明桌面组件使用实体菜单并重新锚定当前按钮；移动或切换模式关闭旧菜单。
- 托盘显示明确的组件显示/隐藏动作，保留恢复组件点击和重置入口，增加设置入口；打开主窗保持最大化状态。macOS菜单栏按原生角色分组。
