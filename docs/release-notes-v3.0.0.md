# Daymark 3.0.0

Windows托管更新包由受保护流水线发布。

- 最近删除增加“彻底删除…”确认：默认仅从本机移除，圆形单选可选择同时从服务器彻底删除。后者需要新版服务支持，完成同步后其他设备也不能恢复；已有备份不自动清理。
- 修复取消更新后立即重查失败，自动检查改为每天一次，主窗底部增加检查/进度/重启更新入口。
- 安装向导提前检测目标目录内运行的 Daymark/更新器，提示退出后重试。
- 修复删除分类时已删除任务的冗余移动导致同步队列阻塞，保留原日志并恢复等价请求；校验拒绝显示真实诊断。

本版数据库升级为 schema11，迁移前自动一致备份。**从2.2.x请下载完整安装包手动升级，先从托盘退出；旧版更新器不会跨数据格式自动安装。** 也可完整解压新便携目录启动，个人数据位置不变。迁移后不能用旧版直接打开资料；需要回退时使用迁移前备份。

服务端新增 task.purge 和可选 purged_at_utc；旧客户端遇到该墓碑须升级。自定义服务器先升级服务端；旧服务器仍可普通同步，服务端删除选项禁用。本机移除保留必要同步事实，不是磁盘安全擦除。服务器正文被墓碑替代，既有同步日志、共享循环模板与备份按各自保留周期处理。

Windows 安装与便携包采用项目自签名，不属于 Windows 公共发行者信任。macOS/Linux、物理混合DPI多屏和读屏未在本轮验证。实际门禁结果见PROGRESS。
