# Daymark 2.0.2

Windows托管更新包由受保护流水线发布。本版沿用2.0.1引导协议、公钥、Qt6.10.2与schema10，可从已安装的2.0.1托管版本后台准备后重启切换；既有普通平铺包需先手动安装一次引导布局。

- 修复发布构建的官方地址临时配置生命周期，避免CMake自动重配后丢失官方账号入口；正式候选与签名阶段均检查实际EXE包含官方配置。URL继续仅在本地或受保护CI Secret中管理，源码只含示例。
- Windows打包包含经过微软签名、x64架构、版本与散列验证的VS2022完整CRT成员，包括线程运行库；用户无需为更新自动安装VC运行库。
- 发布流程前置轻量CRT审计和原生宿主构建，完整测试后签名，在独立Windows runner检查真实窗口及Qt/CRT模块来源，再核对绑定报告后上传。
- 支持从既有不可变tag使用已审查main工具完整重建，分别记录源码和工具提交，不移动旧tag、不覆盖已公开资产；缺少完整来源、配置、签名或独立部署证据时拒绝发布。
- 测试夹具按实际MSVC/MinGW能力标注运行库，不跨运行库自动升级；新增真实公开GitHub升级的显式验收脚本。

更新清单使用项目ECDSA P-256签名；四个EXE使用固定指纹的项目自签名证书，未获得Windows公共发布者信任，Windows/SmartScreen仍可能提示未知发布者。不要求安装根证书，不关闭TLS验证。

发布与公网升级的真实结果见PROGRESS及GitHub Actions。托管Windows runner不代表物理多屏、读屏、所有Windows版本及长期性能均已验收；Linux/macOS本轮跳过，其他机器账号网络问题仍需现场诊断。
