# Daymark 1.0.0

2026-10-26 · 仅发布源码。对应Git标签`v1.0.0`；Qt运行库公开再分发许可尚未确认，本次不附Windows便携包、macOS安装包、Qt SDK/DLL或用户数据。源码版本号不代表所有平台及人工发布门禁已经通过。

## 主要能力

- 本地优先的统一任务系统：起止日期/时间、分类与标签、真实父子任务、特别关注与置顶；今天/计划/全部/完成等范围共享同一任务身份。
- 日/周小时轴、连续月历及年导航；跨日背景条、重叠时段、预览/取消/提交的拖动与端点调整。日历直接新建完整草稿，所有属性一事务提交。
- 原行编辑与就近详情共享草稿；退出先保存、错误保留、明确放弃。默认时段摘要及按需参数，长内容/窄窗/大字展开同一面板。
- Shift范围、Ctrl/Command增减、列表全选与单/多选右键菜单；父子原创分支图标和单行摘要，完成反馈、批量预览及版本冲突全回滚。
- 任务循环与周期提醒，SQLite持久化和提醒去重；运行期间检查提醒，应用退出后没有后台提醒服务。
- 任务小窗/mini与独立桌面日历，置顶、透明度及可恢复的穿透通路。统一紧凑/舒适密度、浅深/增强对比和200%文字。
- 软删除/恢复组、JSON导入预览、一致备份与旧schema安全升级；离线核心不依赖账号、服务器或遥测。

## 数据与升级

当前数据库/JSON为schema9，本次版本与UI更新无新增migration。历史schema升级前生成WAL一致快照；失败不会继续升级或部分导入。旧版本不能直接使用升级后的数据库；回退需关闭程序，在独立目录使用升级前快照，不能覆盖正在使用的库。默认业务数据位于系统应用数据目录，与源码/程序目录分离。

## 构建与测试

C++20、Qt **6.10.2**、CMake3.24+；Windows按仓库脚本设置`DAYMARK_QT`/`DAYMARK_MINGW`，macOS使用`bash scripts/build-macos.sh`。详细命令见[环境](environment.md)、[测试方法与链路矩阵](testing-method.md)。完整CTest仍是默认，fast/ui用于开发诊断；事务、迁移、数据损坏、故障注入和晚阶段watchdog不删除或放宽。

本轮实际构建、测试结果、平台范围与提交发布证据统一见[PROGRESS](PROGRESS.md)。GitHub Actions的远程结果见仓库Actions，不能用本地Windows通过推断其他Kit或macOS当前源码通过。
