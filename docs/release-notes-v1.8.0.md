# Daymark 1.8.0

2026-10-29。源码发布作业仅发布源码及不可变注释标签；独立tag构建作业通过完整测试后附加Windows x64、macOS arm64和Linux x64候选归档。候选未签名，未完成独立干净机与全部物理平台验收，不宣称RELEASE-READY。历史标签保持不变。

## 变化

- 不登录时任务始终保存在本地；可选账号同步采用Go单体+SQLite服务，支持注册、登录、离线队列、双向同步、冲突处理和独立账号资料。
- 主窗侧栏提供独立账号窗口，集中登录、注册、服务地址与同步管理，设置页不再混放认证表单。
- Mini可在设置中开启闲置收为小圆球，悬停展开；160ms轻微平滑揭示，固定位置与最终尺寸，支持快速反转和减少动态。
- 独立桌面日历缩至默认560×540、最小360×380，统一收紧字体与间距；保留用户已有手动尺寸。
- 全局字体、详情/任务列表、设置、菜单与滚动空间进一步统一；修复跨平台探针中的异步提交/布局等待。
- 提供普通HTTPS服务的真实Qt双客户端验证模式；本机WSL服务与当前用户CA仅用于已授权联调，不随源码或运行包分发。

## 数据和兼容性

固定Qt6.10.2、C++20；本地数据库schema10。升级前做一致性备份，schema10由追加迁移引入账号同步元数据，不覆盖历史迁移。未登录核心功能离线可用；服务HTTP/JSON v1契约保持兼容。旧schema9程序不应直接打开升级后的库，回退应恢复升级前备份。构建入口见[环境说明](environment.md)，服务配置见[服务指南](../server/README.md)。

## 验证与限制

本版Windows Qt6.10.2 MinGW Release构建、两项QML lint、完整26/26 CTest（275.50秒）及发布守卫14/14已通过。后续固定提交的包校验和tag CI真实结果统一记录于[进度](PROGRESS.md)及[当前状态](STATUS.md)。之前版本通过不代表1.8.0通过；发行说明不预先声称尚未运行的tag作业成功。

此前真实Qt↔Go TLS双端联调已覆盖注册/登录、双向复制、离线恢复、冲突与故障矩阵；所有输入为合成资料。本版不上传用户数据库、测试账号、证书、日志或本机SDK。公开候选仅由CI开源Qt Kit构建，动态链接，随附GPL/LGPL文本、Qt版权/源码获取说明与模块SBOM。

Windows MSVC候选需VC++2015–2022 x64运行库；macOS包未签名/公证，Linux依赖系统X11/OpenGL等基础库。物理输入/读屏、通知/穿透、多屏DPI/睡眠、干净机、签名以及macOS Keychain原生验收仍UNVERIFIED。发布规则见[发布规则](release-policy.md)，许可见[第三方说明](third-party-notices.md)。
