# Daymark 3.2.0

Windows托管更新包由受保护流水线发布。本版把分类、任务编辑、提醒和文本录入整合进桌面小窗。

- 左侧常用分类可收起，小窗会记住任务区的宽度。将任务拖到常用分类即可改变归属，也可在“分类”入口短暂停留后拖入任意一级或二级分类。移动父任务会带上子任务，日期与提醒会保留。
- 点击任务即可在附近编辑，关闭时保存，写入失败时保留草稿。快速录入的时间标签可直接打开日历。
- 铃铛展开本机待处理提醒，支持完成、延后、忽略与撤销。关闭自动弹窗后，仍可手动打开提醒列表。
- 小窗菜单可从活动通知中离线提取任务，预览并修改标题、日期、时段和截止时间，再勾选需要创建的任务。原文保留在备注中，日期含糊时由用户确认。整批保存失败时保留候选。

Windows 3.1.0 用户可在“设置 → 关于与帮助”检查更新。使用 3.0.2 或更早版本时，请下载完整安装包接入新版更新工具链。任务数据库为 schema 11，使用现有 HTTP JSON 同步协议。

Windows 安装包和便携包使用固定指纹的项目自签名与独立 P-256 更新签名。Windows 不将该自签名识别为受公共信任的发行者。macOS 和 Linux 提供源码。物理多屏、混合 DPI 和读屏环境的验证范围见仓库的 `docs/PROGRESS.md`。
