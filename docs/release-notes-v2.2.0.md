# Daymark 2.2.0

Windows托管更新包由受保护流水线发布；完整安装器和便携包在完整测试、签名与独立部署验收通过后附加到本页。

- 新增融入界面的 Daymark 顶区：复用侧栏字标、页面工具、设置标题和账号品牌，不再显示独立标题横条。主窗口、设置和账号窗口统一浅色、深色与高对比外观。Windows 默认启用，可在“设置 → 外观 → 显示 → 标题栏”切换系统原生样式。
- 切换即时保存并应用，按设备保留选择，切换账号不会改变；保留窗口外框位置、尺寸、最大化、最小化及隐藏状态，不重建任务界面或清空编辑草稿。
- 标题栏支持标准最小化、最大化/还原、关闭、拖动、边缘缩放、双击及系统菜单。关闭继续执行原来的保存、托盘和退出规则；Windows 11 Snap 采用原生命中机制，物理多屏/缩放及悬停菜单需按设备单独验证。
- 新增标题栏模块错误码、偏好失败回滚及隔离的Qt/Win32集成和实际界面验收；隐藏工具窗不创建标题栏内容，不引入额外图形引擎或后台线程。

便携包完整解压后运行顶层 daymark.exe；原有托管安装支持内置更新。安装、更新和卸载保留个人任务与账号资料。程序采用项目固定公钥与证书指纹进行自签名验证，尚非 Windows 公共发行者信任，无需导入根证书。

数据库 schema10、HTTP JSON v1 和 Qt 6.10.2 保持不变。Windows优先；macOS/Linux保持原生窗口，本轮未实机验收。实际验证状态与资源身份见仓库PROGRESS。
