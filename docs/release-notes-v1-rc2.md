# 1.0.0-rc.2 Windows本地候选

在RC1与UI-08基础上实现用户授权的CAL-01/02；本轮不进行远程发布。当前状态、包名、校验和及实际验证统一见[PROGRESS](PROGRESS.md)。

UI-14按Apple HIG重设计全部既有界面：任务/规划/资料库导航，标题上下文与可操作空态；设置独立直达并分外观/桌面组件/通用三类。任务、组织、重复、事件、批量、数据页使用统一分组和日期控件，返回/保存固定。日历月周分段选择、议程改期图标、提醒记录与小窗同步精修。重复规则新建/切换/退出会保护未保存输入。详情底部准确提示草稿状态；原有原子保存、软删、恢复与离线语义保留。设计及官方依据见[UI-14](design/hig-redesign.md)，完整平台门禁仍单列。

## 任务日历

- 月/全天周视图与当天议程配合，任务可直接完成、恢复；计划开始/截止同日合并、不同日引用同一任务。
- 日期箭头键移动，超量入口跳入议程；宽窗右侧、窄窗/大字上下排列，提供“当天议程”直达。显示任务/事件/已完成的过滤只影响显示。
- 全标题在议程中换行；打开详情继续使用既有草稿与离开保护。事件草稿也保护返回、Esc与主窗关闭。

## 本地事件及关联

事件支持标题、备注、全天日期段或定时起止及时区。全天结束日期在界面包含当天，存储采用排他结束日；定时事件保存UTC与IANA时区，按本机时区进入日历，拒绝倒序及DST缺失/歧义输入。

事件可关联多个准备/跟进任务，任务也可关联多个事件。事件编辑中可搜索关联/解除关联、进入任务；任务编辑面板的“关联事件”中可打开事件。完成任务不取消事件，双方改期互不自动移动。

UI-10更新：任务完整字段合入同一编辑面板，宽窗并排、窄窗主内容页；归属/标签/清单/提醒无需二级弹窗。正文单一滚动、备注自然增高，返回/保存和错误提示固定；完整草稿一次事务保存，任一字段错误不部分写入。任务菜单不适用项不再留下空白行。详见[统一编辑设计](design/unified-task-editor.md)。

V-02W更新：时间/恢复事件合并，正在保存时延后维护；后台维护保持表单可编辑并保留校验错误。主窗工作区变化后规范化位置，保留隐藏/最小化状态。新增隔离数据的连续运行、完整性检查及资源采样工具，操作见[稳定性验收指南](stability-guide.md)；短跑通过不等于8h、真实睡眠或多屏通过，实际证据见验证报告。

V-03W更新：候选包内提供独立PowerShell 7校验入口；先检查完整目录、版本与敏感文件，再无SDK运行合成检查并持续审计包内DLL来源，报告保留在包外。打包要求干净提交、重新构建/测试，并校验ZIP内容及SHA侧车。不会修改真实任务库；校验和不代替签名，详细操作见[离线交付指南](delivery-guide.md)。

删除事件为软删，关联任务保留，8秒内可撤销；任务软删也不删除事件。关联随任务删除隐藏，恢复后可重现。事件字段与关系保存同一事务，冲突或错误保留原数据与输入。

本轮仍无小时轴、自动时间安排、事件重复/通知、外部日历账户或云同步。事件提醒与任务已有remind_at通知是不同能力。

## 升级及数据保护

数据库升级到schema3，追加003，不覆盖001/002。已有schema1/2打开前先创建WAL一致快照到backups/migrations；备份失败阻止升级。旧程序不能打开升级后的数据库，回退请关闭程序，在独立目录使用升级前快照，避免覆盖正在使用的数据库。

JSON/一致快照保留事件、任务关联及原有数据，JSON支持旧schema1/2导入；新JSON标记schema3。CSV继续只导出任务，不用于无损恢复。

Windows自动测试和合成窗口检查不代替真实输入法、读屏、跨屏、8h或干净机验收；macOS仍UNVERIFIED。许可及签名边界沿用[第三方记录](third-party-notices.md)，包仅用于本地候选验证。设计决策见[ADR-013](ADR/013-local-events.md)。

UI-11：统一页面滚动，取消过度回弹并缩短惯性；内容未溢出时关闭滚动和滚动条。备注自然增高、仅外层正文滚动，保留手动位置；下拉框/数字框不再被滚轮误改。

展开态组件表头增加直接置顶/取消置顶图钉，按真实状态高亮；Mini保持摘要与展开按钮，继承置顶设置。

UI-12：统一收紧控件/页边/字段间距，任务完成图形固定尺寸，元信息合并；Today不重复显示今日标签。搜索/筛选采用带中文提示的图形入口。增加多分辨率EXE、窗口、任务栏与托盘图标，提供macOS ICNS资源（实机待验）。

UI-13：Apple HIG升级为项目UI/UX强制设计依据，并纳入工程和验收流程。月格在紧凑布局也显示具体事项标题，剩余+N；长标题有完整提示及原详情入口。详情改为连续文档表面、取消外框，字段统一浅填充/底线、焦点独立强调；统一字体/字号/圆角及线条分工，较宽编辑页日期并列显示，文字放大后重排。

CAL-03：日历可独立作为桌面窗口，与任务小窗/Mini并存，翻月和月/周不切换主窗视图。背景透明度50–100%，文字保持实色，独立置顶、隐藏/恢复、拖动及右下角调尺寸，本机保存窗口几何与偏好。任务回主窗编辑；事件在所属日历内编辑并保留离开保护。共享月格增加周行细线、周末层级与选中数字字重。实际Windows证据及包见PROGRESS，macOS及真实多屏/合成/辅助技术未验收。

CAL-04新增循环事件与事件提醒（FR-021）：每天/每周/每月/每年、间隔/结束日期；当前编辑和删除整个系列。开始时/提前提醒、全天09:00基准、最近24小时补报、持久化去重与应用内事件记录。退出期间无后台服务，系统通知仍受权限影响。月格新增今日圆标、事件色条与重复标识。schema4升级前自动一致快照，JSON/快照保留新增数据，旧JSON兼容；回退须使用独立目录及升级前快照。详见使用说明和ADR-014。

CAL-05：事件格内和议程点击改为只读详情，完整展示本次日期、循环/提醒和系列起点；显式进入编辑整个系列。新增可手输/选择的日期跳转，主/独立窗分别定位；修复循环事件按系列旧起点而非本次时间排序的问题。无schema变化，schema4与原数据兼容。系统评估与后续计划见review-rc2.md，实际证据见PROGRESS。
