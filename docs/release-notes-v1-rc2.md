# 1.0.0-rc.2 Windows本地候选

在RC1与UI-08基础上实现用户授权的CAL-01/02；本轮不进行远程发布。当前状态、包名、校验和及实际验证统一见[PROGRESS](PROGRESS.md)。

## 任务日历

- 月/全天周视图与当天议程配合，任务可直接完成、恢复；计划开始/截止同日合并、不同日引用同一任务。
- 日期箭头键移动，超量入口跳入议程；宽窗右侧、窄窗/大字上下排列，提供“当天议程”直达。显示任务/事件/已完成的过滤只影响显示。
- 全标题在议程中换行；打开详情继续使用既有草稿与离开保护。事件草稿也保护返回、Esc与主窗关闭。

## 本地事件及关联

事件支持标题、备注、全天日期段或定时起止及时区。全天结束日期在界面包含当天，存储采用排他结束日；定时事件保存UTC与IANA时区，按本机时区进入日历，拒绝倒序及DST缺失/歧义输入。

事件可关联多个准备/跟进任务，任务也可关联多个事件。事件编辑中可搜索关联/解除关联、进入任务；任务编辑面板的“关联事件”中可打开事件。完成任务不取消事件，双方改期互不自动移动。

UI-10更新：任务完整字段合入同一编辑面板，宽窗并排、窄窗主内容页；归属/标签/清单/提醒无需二级弹窗。正文单一滚动、备注自然增高，返回/保存和错误提示固定；完整草稿一次事务保存，任一字段错误不部分写入。任务菜单不适用项不再留下空白行。详见[统一编辑设计](design/unified-task-editor.md)。

V-02W更新：时间/恢复事件合并，正在保存时延后维护；后台维护保持表单可编辑并保留校验错误。主窗工作区变化后规范化位置，保留隐藏/最小化状态。新增隔离数据的连续运行、完整性检查及资源采样工具，操作见[稳定性验收指南](stability-guide.md)；短跑通过不等于8h、真实睡眠或多屏通过，实际证据见验证报告。

删除事件为软删，关联任务保留，8秒内可撤销；任务软删也不删除事件。关联随任务删除隐藏，恢复后可重现。事件字段与关系保存同一事务，冲突或错误保留原数据与输入。

本轮仍无小时轴、自动时间安排、事件重复/通知、外部日历账户或云同步。事件提醒与任务已有remind_at通知是不同能力。

## 升级及数据保护

数据库升级到schema3，追加003，不覆盖001/002。已有schema1/2打开前先创建WAL一致快照到backups/migrations；备份失败阻止升级。旧程序不能打开升级后的数据库，回退请关闭程序，在独立目录使用升级前快照，避免覆盖正在使用的数据库。

JSON/一致快照保留事件、任务关联及原有数据，JSON支持旧schema1/2导入；新JSON标记schema3。CSV继续只导出任务，不用于无损恢复。

Windows自动测试和合成窗口检查不代替真实输入法、读屏、跨屏、8h或干净机验收；macOS仍UNVERIFIED。许可及签名边界沿用[第三方记录](third-party-notices.md)，包仅用于本地候选验证。设计决策见[ADR-013](ADR/013-local-events.md)。
