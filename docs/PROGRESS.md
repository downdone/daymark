# Daymark 实施进度

## 当前目标与范围

用户要求实现核心能力并发布v0.1，随后明确“先交付本地版本”。本轮交付范围因此为Windows x64本地可运行包及源码；不推送GitHub，不创建远程Release。项目仍使用C++20、Qt 6.10.2、SQLite本地优先。

RELEASE-01：DONE（本地范围）。最终Release验证、原生截图检查、带运行库打包及包外SDK隔离启动均通过，当前无进行中的编码项。实施契约见[本轮设计](design/release-v0.1.md)，产品边界见[发行说明](release-notes-v0.1.md)。
