# Daymark 4.0.2

Windows托管更新包由受保护流水线发布。

- 账号任务可直接在「安排 → 周期」设置重复。退出登录或断网时仍可编辑，连接后会同步周期和完成记录。
- 勾选完成只完成本轮。下一轮继续沿用原任务，其他设备可查看本轮完成和下次安排，也能撤销尚未推进的本轮操作。
- 服务器先升级到支持 DTO 2 的版本。资料第一次保存周期后，旧客户端需升级到 4.0.2 或更新版本才能继续同步。原有任务和修改继续保留。旧循环转换会保留已生成的任务和历史。
- Windows x64 沿用客户端数据库 schema 12 与既有托管更新 ABI。项目自签名和更新包验签策略沿用上一版。Linux 和 macOS 桌面发行、物理多屏及辅助技术未验证。公开 Windows 资产与验收状态见 [PROGRESS](PROGRESS.md)。
