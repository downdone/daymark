# Daymark 1.8.1

2026-11-04。源码发布作业仅发布源码及不可变注释标签；独立标签构建作业在完整测试及QML lint通过后附加Windows x64、macOS arm64和Linux x64候选归档。候选未签名，未完成独立干净机及全部物理平台验收，不标记RELEASE-READY，历史标签保持不变。

## 变化

- 桌面小窗、Mini条和悬浮球统一形态规则，各自可启用/禁用并直接切换；球点击临时打开小窗，无交互后回到常驻形态，菜单/输入/拖动期间保持展开。
- 形态切换共用稳定透明画布、单进度可逆动画和按帧合并的裁剪区域；收球末帧不再二次缩窗或清空裁剪，减少动态立即到视觉终值，呈现确认后恢复输入。
- 小窗支持原位快速添加、独立今天任务排序、拖动、置顶/关注/完成/软删及撤销；到期提醒提供独立弹窗、查看、完成、关闭与延后。
- 修复滚轮滑块反复明暗、菜单关闭手势误传到底层任务、跨行右键及空白点击后右键失效。Windows原生菜单在宿主层级恢复后仍位于其上方；修复稳定小窗重复布局被误淡出。
- 应用批准的新品牌母版和完整VI，统一应用/托盘图标、主窗字标、关于、账号窗口及球；侧栏底部集中设置、最近删除和账号入口，备份收纳至设置。
- Windows标签包校验和使用明确的LF换行，保证Linux发布作业逐文件校验兼容。

## 数据与兼容性

固定Qt6.10.2、C++20，数据库schema仍为10，本版不增加数据库迁移。与1.8.0共享本地任务和可选账号同步契约，未登录核心功能离线可用；HTTP/JSON v1保持兼容。升级前建议从应用创建一致性备份，从托盘退出旧实例，再将新包解压到独立目录运行；不要把真实数据库放入发行目录。更旧schema程序的回退仍应使用相应备份。

## 验证与限制

本次纳入的组件修复已完成Windows Qt6.10.2构建、相关Qt Test/CTest、原生系统菜单和自绘回退的实际窗口层级/像素专项。1.8.1固定源码的完整本机测试、包校验和GitHub流水线结果，以[进度](PROGRESS.md)、[当前状态](STATUS.md)及本标签Actions为准，不提前声明尚未运行的作业通过。

Windows MSVC候选需要VC++2015–2022 x64运行库；本机MinGW便携包与CI MSVC归档分别记录。Qt按LGPLv3动态链接，CI归档附带许可文本、Qt版权/源码获取说明及模块SBOM，见[第三方说明](third-party-notices.md)。macOS候选未签名/公证；Linux依赖系统X11/OpenGL等基础库。

物理输入/IME/读屏、DWM瞬时观感、多屏DPI/睡眠、独立干净机及签名等门禁仍单列。分类快捷检索仍处于设计阶段，本版没有该设置开关；不把设计稿计入已交付功能。发布规则见[发布规则](release-policy.md)。
