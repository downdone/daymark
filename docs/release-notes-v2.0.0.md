## 账号与服务

- 独立账号窗口默认“官方账号登录”，只填写账号和密码；注册与登录使用同一官方服务。
- “自定义URL”保留原HTTPS服务器输入、收起/更改和账号资料隔离。切换方式清空密码，保留自定义地址；忙碌时不能切换目的地。
- 官方地址从Git忽略的本地独立文件编译读取，公开源码仅示例；缺配置时官方入口明确提示且不能提交，自定义仍可使用。配置方法见[说明](../config/README.md)。编译后的程序包含连接地址，此机制不提供地址加密。

## 小窗分类

- 标题下常驻“今天 / 常用分类 / 分类”，窄窗减少常用项并保留分类文字入口。
- 同一小窗内搜索分类名称/完整路径、固定/取消常用和调整顺序；实体选择页不增加透明菜单窗口。Mini/悬浮球菜单共用浏览上下文。
- 默认分类全部未完成，设置可改仅今天。列表、数量、摘要和原位添加共用业务查询，主窗筛选不被修改。
- 切换前按原分类保存草稿，失败保留输入；资料切换拒绝将旧输入写入新资料。分类失效回到今天，偏好保存失败可重试。

Windows Qt6.10.2 Release、完整32/32 CTest、两项QML lint、分类/账号原生窗口专项及标准非预览便携包通过，SDK隔离完整原生smoke、DLL来源与ZIP/SHA256通过；真实结果维护在[进度](PROGRESS.md)和[当前状态](STATUS.md)。macOS本轮界面、物理多屏/混合DPI、读屏、独立干净机和签名未验收，不宣称正式二进制RELEASE-READY。公网服务已用真实Qt证书校验进行合成资料注册/登录及双向同步；外部独立备份目标未配置，不能视为异机灾备。
