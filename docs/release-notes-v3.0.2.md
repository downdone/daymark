# Daymark 3.0.2

Windows托管更新包由受保护流水线发布，提供安装包与便携包，包含3.0.1源码快照的完整功能。

- 设置按常规、任务与提醒、桌面组件、外观、数据与隐私、关于与帮助重新分区；保留原有偏好、即时保存、每页滚动和键盘导航，账号继续使用独立窗口。
- 桌面组件形态与背景/自动收展分组，主题与窗口标题栏分组；提醒/时间识别、备份/日志/隐私、帮助各有明确归属。
- 增加默认关闭的可选择使用统计：主动同意后才向当前账号服务发送固定使用/性能区间，可撤回清理；不包含任务、备注、分类、标签或输入内容。旧服务不影响普通同步，统计需部署新版服务并另行启用。
- Go业务服务增加独立管理员MFA/恢复码、角色/审计、用户状态及会话管理、公告草稿/预览/发布/撤回、聚合看板及可恢复清理。后台与统计服务默认关闭；本次发行不自动部署或开启生产采集。
- 取消独立通知中心，保留现有任务提醒、提醒记录、更新及账号状态提示；后台公告不向客户端推送。
- 更新标题栏验收探针以适配新的设置默认分类，补齐原生单实例标准输出及CI测试证据。3.0.1正式候选未通过，保留其源码标签，不覆盖既有发行。

本地任务schema11与同步协议保持不变。3.0.0可通过现有托管更新升级；2.2.x跨schema仍需完整安装或新便携目录，退出程序并保留资料备份。业务服务新增迁移4和独立统计库，维护步骤见server/BUSINESS.md。

Windows程序继续使用固定指纹的项目自签名和独立P-256更新签名，不属于Windows公共发行者信任，不需导入根证书。macOS/Linux和物理混合DPI/读屏未在本轮验证。实际构建、安装和公开升级结果统一见PROGRESS，本文不代替测试证据。
