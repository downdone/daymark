# Daymark 2.0.1

Windows托管更新包由受保护流水线发布。源码Release与Windows资源分步产生；只有签名清单与签名均已上传、验签通过的资源才具备自动更新资格。

## Windows在线更新

- 首次使用需手动解压本版引导包，运行根目录的daymark.exe；版本程序保存在versions目录，请完整保留目录结构。
- 启动后检查GitHub新版，后台下载、校验并安装到独立目录，准备完成提醒重启；保存退出后切换，新版本正常运行并持久确认后才清理旧文件。
- 内置项目P-256公钥验证更新包。主程序和三个原生宿主使用项目自签名代码证书并固定指纹校验；未获得Windows公共发布者信任，Windows/SmartScreen仍可能提示未知发布者。不要求用户安装根证书。
- 更新器为原生Win32界面与CLI，不依赖Qt SDK；Qt和MSVC运行库随完整包部署。同数据schema10升级，首次引导、引导层自更新和未来数据迁移仍为手动安装。

## 账号与诊断

- 保留官方账号/自定义服务选择、本地离线使用和可选同步；密码至少8个字符。
- 补充全局本地有界脱敏日志、请求ID与模块错误码，显示Qt/TLS底层诊断并提供复制详情、日志目录入口。
- 修复已完成任务的分类、标签交集筛选。

## 验证范围

Windows完整测试、签名和另一台托管Windows runner的部署检查由流水线记录，发布资源绑定精确源提交及部署散列。该托管runner验证不代表物理多屏、读屏、所有Windows版本或长期性能均已验收。Linux/macOS本轮未构建、未验证；另一台机器账号超时的现场根因仍需该机新版诊断日志。

未覆盖用户数据库、未向服务器上传本地日志或测试数据，现有tag和资源保持不可变。实时执行结果与未完成边界见PROGRESS。
