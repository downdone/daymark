# Daymark VI使用规范

品牌调性为清晰、可靠、轻盈、适度亲和。图形以D形两段记录轮廓、左下留白和右上短笔表达记下与标记；名称由定制小写daymark字标呈现。不把抽象图形解释成进度、固定分类或完成状态。

| 项 | 标准 |
|---|---|
| 主体 / 字标 | 浅色#1C1C1E；深色#F2F2F7 |
| 短笔色序 | 从主体向外：蓝、绿、橙、紫 |
| 浅色四色 | #287EF0 / #28A680 / #E4A13C / #A783DE |
| 深色四色 | #83BAFF / #83D6AA / #FFC18C / #D0B3FF |
| 图形 / 字标 / 组合画布 | 100×100 / 274×58 / 320×72 |
| 保护区 | 可见轮廓外至少12设计单位；控件内随整体缩放 |
| 小号 | 符号32物理px、载体48物理px起四色；更小单色 |
| 托盘 | 黑白单色，按系统栏选色；macOS使用模板 |
| 高对比 | 单色，使用主题文字色；不以品牌四色表达功能 |

主体、留白和短笔必须整组等比缩放。短笔包络宽约为主体36.6%，中部内白宽约49.5%；正式导出已经包含校准，不凭感觉单独拉长笔画。16/20/24微型为独立像素校准，使用就近资源。

一处品牌组合只有一组四色重心，字标下方不挂四色点或色条。辅助四色带出现时配单色标志/字标。不要改变色序、旋转、压扁、补新线槽或添加液态玻璃材质；系统载体外部阴影由平台处理。载体采用实体浅深底，内图形没有玻璃、阴影或渐变。

品牌字标是原创路径，不用近似字体重打。任务正文、菜单和控件沿产品字体与功能Token，Windows保持中文优先字体策略，macOS沿系统GeneralFont；不要用宣传模板字号覆盖紧凑任务界面。四个分类可选色不绑定品牌四色的固定含义。

模板内文案可编辑，替换后检查字体回退、断行和保护区。PNG仅作预览或平台栅格资源，优先使用对应SVG母版。Windows/macOS真实显示、混合DPI、读屏和系统缓存分别验收；数据文件、证书和个人截图不得进入VI。
